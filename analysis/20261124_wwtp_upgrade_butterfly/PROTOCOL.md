# 下水処理の高度化と蝶の寄主栄養組成:前後比較の凍結仕様 v0.1

2026-11-24 起草。**この仕様は、高度化した処理場の上流・下流の蝶、植物、底生生物の応答を一つも見ないうちに固定する。** 結果を見た後に、閾値、窓、曝露の定義、対照群、モデルを変えない。変えた場合は版番号を上げ、変更前の結果も消さずに残す。

## 1. なぜこの検証か

これまでの結果では、下水指標Wが高い流域ほど、蝶の群集は富栄養の寄主を使う種に寄っていた(景観調整後 β +0.078、予測改善 +8.0%)。しかし上流人口密度を加えると β は +0.031[−0.016, +0.078]に弱まった。Wと人口の相関は0.80である。

Wの元の定義は、HydroWASTEの**モデル化された処理水量**を上流面積で割ったものである。処理水量は人口から推定されているため、Wは構造的に「人の多さ」と分けられない。

そこで、**人口がほぼ変わらないまま、川に出る窒素とリンだけが変わる出来事**を使う。それが処理場の高度処理化(窒素除去やリン除去の導入)である。高度化の前後で蝶の組成が「出た栄養」に沿って動けば、人口とは別の、下水そのものの経路を支持する。

## 2. 推定対象と予測の向き(事前に固定)

**主推定対象**は、上流の処理場が窒素除去を新たに導入したH7流域で、蝶の群集HNS(寄主の窒素嗜好の加重平均、稀薄化後)が導入前の窓から導入後の窓にかけてどう変化したかである。この変化から、まだ導入していない流域と導入しなかった流域での同じ期間の変化を差し引く。

**予測の向き**は負である。窒素除去の導入で、下流の河畔の窒素が減れば、蝶は貧栄養寄主型に戻る。正の推定値や区間がゼロを含む結果も、同じ形式で報告する。

**副推定対象**は次の4つである。
- (a) リン除去の導入
- (b) 植物群集のEIV NUTRIの変化(蝶より先に動くはず)
- (c) シジミチョウ科の内部の対比(第6節)
- (d) 底生生物EQRの変化(陽性対照、第5節)

## 3. 資料

### 曝露:EEA Waterbase UWWTD、処理場単位の複数報告周期

- 2020年周期のGPKG(v08 r00, 21,448処理場, SHA `13060c88…`)には、処理場単位で次の項目がある。
  - `uwwNRemoval`、`uwwPRemoval`:窒素・リン除去の有無
  - `uwwSecondaryTreatment`、`uwwOtherTreatment`
  - `uwwLoadEnteringUWWTP`:流入負荷。人口当量で、受け持つ人口の代理になる
  - `uwwCapacity`、`uwwBeginLife`、`uwwHistorie`
  - `uwwNDischarge*`、`uwwPDischarge*`
- 他の周期(2014、2016、2018、2022)は、項目名と符号化が同じだと**仮定しない**。
- 実測の排出量(`*DischargeMeasured`)は2020年周期でも582排出口しかなく、疎である。そのため**主曝露には使わない**。主曝露は処理方式の旗と流入負荷とする。旗は量ではなく状態なので、欠測と「なし」を区別する。

### 応答:既存の四期間の蝶・植物の面

- 四期間は2014–16、2017–19、2020–22、2023–25とする([FOUR_WINDOW_PROTOCOL](../20261124_earlier_period/FOUR_WINDOW_PROTOCOL.md)と同じ)。
- H7・H6の多角形、分類群の絞り込み、稀薄化(50記録)、品質規則は、元のものをそのまま使う。
- HNSは元の目録とClarke目録の両方で計算する。両方で同じ符号であることを主判定の条件とする。

### 河川網・流域

- HydroBASINS L7/L6はNEXT_DOWNで上流をたどる。HydroRIVERSはSHA `5e6327c6…` に固定する。
- 処理場の位置と排出口の位置は、UWWTDの排出口座標を優先する。

### 陽性対照の水側

- EEA Waterbase Biology 2026の底生生物EQR(`EEA_13-01-4`)を使う。既存の2018・2022年の肯定結果と同じ要素とする。

## 4. 曝露の定義(資料ゲートの中で固定する)

1. **周期と窓の対応**:各窓の曝露は、`repSituationAt`(または同等の項目)が示す基準年が窓の中に入る周期とする。二つ入る場合は早い方を使う。基準年が確認できない周期は使わない。
2. **処理場の周期間の連結**:まず `uwwCode` の完全一致で連結する。一致しない場合の代替は、`uwwInspireIDFacility` が一致し、かつ座標が500 m以内のものに限る。代替で連結した件数は分けて報告する。国ごとの連結率を記録する。
3. **高度化の出来事**:連続する二周期の間に、窒素除去の旗が「なし」から「あり」に変わった処理場を高度化とする。ただし次の条件を満たすものに限る。
   - 両周期で旗が欠測でない。
   - 流入負荷(人口当量)の変化が±25%以内である。これで人口の大きな変化を除く。
   - 処理場の閉鎖や統合がない(`uwwDateClosing`、`uwwHistorie`)。
   - 逆向きの変化(「あり」から「なし」)は報告の誤りの候補として数え、解析からは除く。
4. **流域の処理群**:上流範囲(Wと同じ、HydroBASINSでたどる上流H7)に高度化した処理場が1つ以上あるH7を処理群とする。高度化の時期は、最初の高度化の周期とする。
5. **対照群**:同じ国の中で、次の2種類のH7を対照にする。
   - (i) 上流に処理場があり、全期間で処理方式が変わらなかったもの(主対照)
   - (ii) まだ高度化していないもの(後に高度化するもの)
   - 上流に処理場がないH7は副対照とし、主判定には使わない。
6. **強さの補助指標**:高度化した処理場の流入負荷を、上流の全処理場の流入負荷で割った割合。「上流の下水のうち何割が高度化したか」を表す。
7. **人口**:上流の流入負荷の合計(人口当量)の変化と、GHS-POPの上流人口密度は**必ず共変量に入れる**。

## 5. 陽性対照・陰性対照

- **水側の陽性対照(先に評価する)**:高度化した処理場の下流50 km以内で、高度化の前後の年に底生生物EQRがある地点で、EQRの変化を見る。これまでの結果からは改善(正)が期待される。
  - **この陽性対照が、予め定めた向きと条件を満たさない場合、陸の結果を「下水の効果」と解釈しない。** 高度化の旗が、実際の排出の変化を表していない可能性があるからである。
  - その場合も陸の結果は報告するが、「曝露の妥当性が未確認」と明記する。
- **下流の偽曝露(陰性対照)**:H7の下流だけで起きた高度化。川を通る経路なら効果はないはずである。
- **時期の偽曝露(事前傾向)**:高度化の前の二窓の間の変化。2020年周期以降に高度化した群でのみ評価できる。ゼロと区別できないことを期待する。
- **逆方向**:蝶の変化が、後の高度化を「予測」してしまうか。予測するなら、高度化の場所が蝶の傾向と絡んでいる(選択の偏り)ことを示す。

## 6. シジミチョウ科の内部対比(副判定)

事前に、次の二つの型を寄主目録だけから固定する。応答は見ない。

- **富栄養寄主型**:主な寄主がタデ科(ギシギシ・スイバ類)で、HNSが上位3分の1のLycaena属など。
- **窒素固定寄主型**:主な寄主がマメ科のPolyommatus、Plebejus、Cupido属など。

予測は、高度化の後に富栄養寄主型の出現(稀薄化後の記録包含)が対照より減り、窒素固定寄主型は減らないことである。主な検定は二つの型の差の差の差である。

これは、人口だけでは作りにくい「同じ科の中の逆向きの動き」を見る検定である。元の目録とClarke目録で型の割り当てが変わる種は、両方の版で報告する。

## 7. モデル(固定)

- **主モデル**:H7×窓の差分で推定する。
  - 応答は ΔHNS(導入後の窓 − 導入前の最後の窓)。
  - 説明変数は、処理群の指示変数(高度化の割合を使う版も別に示す)、Δ上流流入負荷(log)、上流人口密度、元の景観共変量(農地、都市、河川流量、自然域、面積)、元の観察条件、国×窓の固定効果。
  - 推定はOLSで、95%区間はH6クラスタ・ブートストラップ(2,000回)とする。
  - 時期が段階的なので、二方向固定効果の単純な回帰は使わない。高度化の周期ごとに「導入前の最後の窓→各導入後の窓」の比較を作り、まだ導入していない群と導入しなかった群を対照にして、群ごとの推定値を処理H7の数で重み付けして平均する。
- **予測による補助評価**:既存の様式に合わせ、H6でグループ化した5分割交差検証を行う。Ridge alphaは10とし、H6は等重みにする。処理群の情報を加えたときの、留保した平均二乗誤差の改善を報告する。
- N除去とP除去は別々に解析する。両方を同時に導入した処理場は両方に入れ、その重なりを報告する。

## 8. 判定条件(固定)

**主判定(下水の陸への経路を支持する)**は、次をすべて満たすこととする。

1. 水側の陽性対照が正の向きで、H6クラスタ95%区間がゼロを含まない。
2. 窒素除去の主推定値が負で、95%区間がゼロを含まない。これを元の目録とClarke目録の両方で満たす。
3. 下流の偽曝露の区間がゼロを含む。
4. 事前傾向の区間がゼロを含む(評価できる群で)。
5. 人口の共変量を入れた後も、1〜4が成り立つ。

**部分支持**は、1を満たし、2が片方の目録だけ、または区間がわずかにゼロを含む場合とする。結果の文章では「方向は一致、確証なし」と書く。

**不支持**は、1を満たし、2の点推定がゼロ付近か正の場合とする。「処理の高度化は、測れる範囲では蝶の組成を変えていない」と報告する。

**判定不能**は、1を満たさない場合とする。

## 9. 資料ゲート(応答を開く前、満たさなければ停止)

1. 二つ以上の連続する周期で、窒素除去の旗の欠測が国ごとに20%以下である国が、4か国以上あること。
2. 蝶の面の中で、次を満たすこと。
   - 処理群が**30 H7以上、15 H6以上、4か国以上**ある。
   - 主対照が**60 H7以上**ある。
3. 水側の陽性対照に、高度化の前後でEQRがある地点が**50以上、4か国以上**あること。
4. 2を満たさない場合、主判定は停止する。数を報告し、閾値は下げない。リン除去での同じ数も記録する。

ゲートを通過する前は、蝶、植物、底生生物の数値の応答を一切読まない。読むのは、処理場、流域、地点の位置情報と、資料の可用性だけとする。

## 10. 限界(先に書いておく)

- 高度化は無作為ではない。富栄養化の敏感地域の指定に沿って行われるので、高度化した流域は「もともと栄養の問題が大きい」流域に偏る。同じ時期の農業政策(硝酸塩指令の実施)が同時に効いている可能性もある。対照を同じ国に限ることと、事前傾向を検定することで一部を扱うが、取り除けるわけではない。JRCの面源窒素(NUTS2)の変化は共変量の感度解析に入れる。
- 旗は状態であり、実際の削減量ではない。除去の効率や運転の状況は分からない。
- 窓は3年で、四期間しかない。植物から蝶への遅れが一窓より長い場合、効果は見えない。
- 蝶の記録は市民科学による。稀薄化と観察条件の調整で効果の偏りは減らせるが、記録者の行動の変化は残る。
- この検証で正の結果が出ても、川の水から河畔の寄主へ(経路A)と、汚泥から農地へ(経路C)は区別できない。区別は現地調査(河畔と汚泥施用地の対比)の役割とする。
- 2023–25の蝶の結果の一部は、別の予測の目的ですでに開いている。そのため、最後の窓を使う比較は完全な未見データではない。結果の文章では、2014–22だけでの推定を主とし、2023–25を含む推定を副として示す。

## 11. 実行の順序

1. 各周期のUWWTDの原資料を取得し、SHAで固定し、項目と符号化を点検する。結果は `SOURCE_GATE.md` にまとめる。
2. 処理場の周期間連結、高度化の出来事の一覧、流域の処理群と対照群を作る。応答は読まない。
3. 資料ゲートを判定する。停止の場合はここで終える。
4. 水側の陽性対照を評価する。
5. 蝶と植物の主・副推定を評価し、判定条件に照らす。
6. すべての結果を、否定の結果も含めて `RESULTS.md` に残す。主ブランチには統合しない。
