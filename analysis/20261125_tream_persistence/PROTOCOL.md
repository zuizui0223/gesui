## Primary spatial persistence diagnostic
For each site-window vector x, exact orthogonal projection B: replace each family coordinate by mean within its native order over fixed family universe; W=x-B. B encodes order shares; W deviations from equal family allocation within orders. B+W=x, B orthogonal to W. This is an additive Euclidean projection on normalized incidence, not ordinary order richness or a phylogenetic measure; coarser/finer variances and ratios depend on this weighting. For each component subtract the project mean across retained sites separately at each window; equal project weights, equal sites within projects. For early mean E=(T0+T1)/2 and late L=(T2+T3)/2, compute signed reproducibility ratio 2*sum(w E·L)/(sum(w||E||²)+sum(w||L||²)); Pearson-like cosine as descriptive companion. Also ratio of mean six cross-window covariances to mean four within-window spatial variances, not latent ICC. Use same weights and fixed cohort; report raw all-space and within-project, per-project values, total/ B/W variance shares and exact covariance additivity. Primary contrast between minus within order reproducibility, nominal descriptive 95% intervals from 2000 positive exponential PROJECT multipliers (seed 20261125), same draws for all metrics, re-evaluate weights, no claim of frequentist confidence coverage; report leave-one-informative-project ranges. Primary joint interpretation: persistent finer component if W lower95>0; greater coarse persistence only if paired B-W lower95>0. Report all outcomes. These quantify persistence, not environmental mediation or population changes. No p-value search.
