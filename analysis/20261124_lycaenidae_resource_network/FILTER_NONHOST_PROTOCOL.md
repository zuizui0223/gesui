Remove from the plant-community mean all 990 original host keys plus every reliable Clarke matched host key (all five families), then remove all observed plant taxa in those hosts' genera. These are catalogue-unlisted plants, not proven nonhosts. Recompute plant N from the remaining EIV-scored species (same reference scale); require >=30 scored remaining species in every retained H7-period and >=80% of original paired H7 plus >=20 H6; otherwise STOP that diagnostic; do not change cutoffs. Compare same cohort for all three plant predictors (full, removed host species, removed host genera) to both equal-species HNS after W (EU), TP and W (FR). Same existing blocked model and fixed-loss intervals, report all. If correspondence persists it is not simply reusing the exact observed host species' EIV scores; trait reference, broad geographic structure, taxonomic and observation confounding remain.
