## Decision
Do not claim a catalogue-independent water→plant–butterfly network signal. Adding 186 new plant keys did not restore it; original quality cohort is already uncertain. This is not proof of zero ecological relation. Remain cautious about source taxonomic and evidence heterogeneity and missing links. No reason to keep tuning this same endpoint for a positive result. Stronger existing same-source water-quality/benthic and terrestrial trait-composition associations can be retained as separate, source-specific results; no causal wastewater cross-compartment link. No new country or measured TP tests were run. All new outputs are local numeric/source verified, remote replay of these exact outputs not yet checked.
