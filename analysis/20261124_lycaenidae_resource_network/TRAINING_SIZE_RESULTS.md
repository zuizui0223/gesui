# Fixed-target training-size audit (2026-11-24)

**Exploratory old-catalogue diagnostic, not an independent ecological replication.** The Clarke source is not available in the current working directory. The previous paired H7 results motivated this sensitivity. Use the same original six SHA-verified input archives, original 454 rows, common 40 accepted butterfly keys, two paired cohorts (173 and 222 H7), original H6 folds and early-training-only geographical reference. The common support gate uses both periods and is retrospective. For each fold, build the reference using all eligible training sites, compute the same target for all regression alternatives, and evaluate only the held-out H7 with >=80% shared catalogue inclusion mass in both periods. The held-out H6 are excluded from reference and regression training. Baseline and EQR-added ridge10 models are fitted independently.

## Training restriction experiment

Compare all eligible training sites, actual >=80% support restricted training sites, and 200 random training subsets. Each random subset uses exactly the restricted training H7 count and exact multiset of H6 cluster sizes; no replacement, largest cluster capacity allocated first among randomly selected eligible parents. This is a descriptive sampling algorithm, not uniform sampling over all legal subsets. The draws are not independent field samples or a formal randomization null. Country composition and other training features are not fixed. Geographic reference stays fixed across regression alternatives, hence the estimated target is identical within each fold. The reference uses full training geography even when the regression sample is reduced; this deliberately isolates regression training effects rather than simulating the entire restricted pipeline.

The previous complete restricted-pipeline gain was +3.21% and +2.36%, respectively; do not equate that estimand with the current fixed-reference diagnostic. A full explanation of attenuation is not identified. The observed restricted regression gains are ordinary relative to the matched-size draws; the reduction in training data is compatible with much of the attenuation. Reference-definition and geographic composition effects remain possible. No proof of no selection bias, no measured sewage dose, biomass, realized host use or new field data.
