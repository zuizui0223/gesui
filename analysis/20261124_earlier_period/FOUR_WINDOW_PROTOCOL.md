## Scientific test to implement after source gate
Use first three windows for geographically blocked training: changes in plant inclusion from 2014–16 to 2017–19 predicting butterfly inclusion change from 2017–19 to 2020–22. Apply fixed coefficients and transforms to plant changes 2017–19 to 2020–22 to predict butterfly change 2020–22 to 2023–25. No new outcome-dependent tuning. Exclude target H6 from historical training; use original fold assignments. Use original accepted fixed species keys, all recorded keys retained in denominators, audit new source keys and coverage. Historical-only model training before scoring later species outcomes; old and Clarke common 46 Lycaenidae primary, five original families exploratory. Evaluate on matched common geographic and species support and preserve nulls. Source outcome novelty limited because prior third-period outcomes were opened in earlier work.

For each host graph and butterfly species, let d_j = change in rarefied plant inclusion for host j, weights equal over catalogued host keys. Distinguish mean signed change D=mean(d_j), magnitude V=mean(abs(d_j)), and signed pair concordance C=((sum d_j)^2-sum d_j^2)/((sum abs(d_j))^2-sum d_j^2). C ranges -1 to 1 for supported pairs; undefined when denominator zero, including single-host species. Never code undefined as perfect synchrony. These are indexed compositional changes, not demographic growth, abundance, or time-series correlation. Test signed mean beyond baseline and structured shuffled host graph, then additional signed coherence interaction D*C on common identifiable support (degree>=2 and nonzero denominator in both predictor windows and both graphs), with V, degree and resource level controls. No positive claim from C alone. Null matches original plant family, early training occurrence bins and geographic clusters; also consider degree-matched random-sign diagnostic as descriptive only. Fixed Ridge10 and H6-equal loss, report same-support contrasts, fixed-loss paired intervals. Require both common catalogues improve on heldout score, separate magnitude/coherence added-value test, reverse direction as distinct control. Exact feature and missingness specifications to be frozen in code before evaluating change-on-change predictions. EQR 2018 and 2022 as historical covariate, not exposure mediation. The existing 2016 EQR result PR #56 is a different grain; no same-H7 2016/2024 EQR yet mapped. Do not merge main or equate new source acquisition with biological discovery.
