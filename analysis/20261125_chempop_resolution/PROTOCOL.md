Frozen before this new computation, after all earlier PR135 results opened. This is a retrospective extension on the same English cohort, not a new field validation. Only incidence weights (not estimated abundance codes).
Question: is chemistry–BMWP association after EDF distinguishable at the within-order family-score resolution, or predominantly order-level? Use same prior site-year family-incidence matrix A and same score reference, with each observed scored family assigned to its unique source order or individual singleton if ambiguous/missing. Total y=A*s; between=A*order_mean(s); within=A*(s-order_mean). Exact additive reconstruction. Fit same original weighted full design (site equal, geography, monitoring, EDF, three log1p chemistry window means). Report all 3 standardized chemistry slopes plus EDF across three responses, clustered descriptive intervals; verify coefficient additivity via independent weighted least squares. No significance voting across analytes.
Primary test 1: within-order exchangeability null. Preserve observed family set and score means by order; permute residual family scores within original order groups 4,999 times, seed 20261125. Statistic = weighted partial R² of the joint three-chemistry block beyond the identical geography/monitoring+EDF baseline for the within-order response. Compute from residualized family-incidence matrix and weighted QR, independently verify observed partial R² by direct fit. Empirical upper-tail Monte Carlo p with +1 correction, not causal or phylogenetic null. Do not treat p<.05 as confirmatory.
Primary test 2: use exact region-and-site-disjoint folds and train-only transformations with Ridge10 as prior PR135. Reuse all four nested predictor blocks (B,B_EDF,B_NUTRIENTS,B_NUTRIENTS_EDF), separately for total/between/within responses. Report region-equal fixed-error bootstrap (2000, original seed), all regions and contrasts. A within-order chemistry association is only supported under this diagnostic if both label-null p<.05 and within-order nutrients-after-EDF heldout gain lower95>0. Null failure is not equivalence or absent family-level biology. Relative MSE improvements are response-specific, not additive or directly comparable biological effect sizes. No source-specific wastewater causality, no EQR species-level reinterpretation, no biological mechanism claim, no new field data. Original PR135, synthesis PR161 and main unchanged.
