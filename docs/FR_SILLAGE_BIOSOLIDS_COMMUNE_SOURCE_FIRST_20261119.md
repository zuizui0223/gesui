# 2026-11-19｜フランス汚泥施用自治体：経路CのSOURCE-only取得・適格監査

**状態：生物アウトカム未使用、公開元資料の取得可否・位置・時期・曝露定義のみを評価。** 旧2018水域×2017–19陸域のNUTS2版2×2は25地域/6国でSOURCE-STOP、JRC native平均からH7への別地理照合も独立土壌源35<100でSOURCE-STOP。これらの条件や結果は変えない。本件は汚泥の真の施用経路を検査する別の事後探索。

## 一次資料と区別する場所
フランス政府のROSEAU/SILLAGE汚泥公開輸出ページ：
https://www.assainissement.developpement-durable.gouv.fr/pages/data/basededonneeboue.php
「boues urbaines épandues」のCSV/GeoJSONに処理場の汚泥乾燥重量・品質・施用先自治体（communes d'épandage）が含まれると政府が説明する。ただし、提供がどの年・地域・粒度をカバーするか、実施用か施用計画か、真の圃場座標かは未検証。2,000人口当量未満の収録品質は低い。処理場所在地、施用先自治体、実際に施用した圃場を決して同一視しない。SILLAGEでは計画・実績・圃場が区別されるが、行政の保有データが全件公開されている保証もない。

## 固定段階
**STEP 0：フォーム・元データ取得経路監査。** 公的なHTTPSのページ原本HTMLを取得し、フォームmethod/action、必須年/流域/処理場規模/出力形式、選択可能な年、関連同一originのJS、直接ダウンロードの存在を記録。原HTML・JSレスポンスのSHA、HTTP status、optionの全選択肢を保存。認証やCAPTCHAが必要、元HTMLが取得不能、公開URLを確認できない場合はACCESS-STOP。推測エンドポイントへの連続リクエストやログイン・権限制御の回避を禁止。

**STEP 1：本物の元CSV/GeoJSONを確認した場合のみ。** 2017–22年のうち公式公開フォームで選択可能な年だけを同じ区分で取得し、元SHA、行数、列、年、施用先自治体のINSEEコード、処理場コード、施用量（t乾燥重量/年）、施用計画か実績かを監査。出所の主な年次を結果を見るまで変更しない。

**固定SOURCE適格条件：** 2017–19と2020–22の各期間に、少なくとも1年、元の施用実績が区別できる；真正な施用先INSEE自治体コードが適格な元行の90%以上；独立50自治体以上かつ5県以上で施用先実績を確認できる。量が単なる処理場生産量、プラン/出荷で、実際に施用した農地を同定できない場合は機会情報のみに分類し、生物の処理比較をSTOP。

**STEP 2：SOURCE-STEP1合格時のみ別GIS。** 元フランス139 H7×期間（72 H7、24 H6）の真正H7 WKTと施用先自治体の公式INSEE境界を元年次でGIS重ね合わせ。自治体のいずれかで実施用された事実があっても、H7内の河岸・寄主個体が直接暴露されたとは言わない。元施用自治体30以上、H6親10以上、実施用支持ありのH7が20以上かつ元GBIF観測期間との重複をSOURCEだけで確認。未記載自治体は「汚泥施用ゼロ」ではなく情報欠落の可能性。陽性だけを使った単純な曝露対非曝露は行わない。

## 論文1/2との関係
汚泥肥料の陸への輸送は、河川への処理水放流とは別の潜在経路。元JRCの農業有機N投入は下水汚泥に限らない。このSOURCEゲートに合格しても植物のNUTRIや蝶HNSは現地での窒素同化を測らないので、効果・媒介の推定は別仕様。δ15Nの高値だけで処理水/汚泥/家畜ふん尿を区別できない。最終的な野外同位体検定には汚泥製品の実施用圃場・施用日と対照源の記録が必須。
