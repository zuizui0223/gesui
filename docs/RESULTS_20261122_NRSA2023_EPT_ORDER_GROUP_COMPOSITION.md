# EPA NRSA2023–24：EPSではなく EPT目別の元実測個体数を分解して、観測履歴別の群集差を反証

**Date 2026-11-22 JST | POSTHOC exploratory observational source-domain audit.**

## 結論（大きな肯定を探すための分類群選択は禁止）

EPA2023–24の底生原本`TOTAL300`を使い、カゲロウ目 Ephemeroptera (E)、カワゲラ目 Plecoptera (P)、トビケラ目 Trichoptera (T) の底生動物**総計数**に占める比率を分解した。**同じ生態地域と元の粒径等で1:1対応した流域群では、いずれの目も旧期SOURCEに出現した流域と未出現の流域の間に統計学的に明瞭な差を確認できなかった。**

従って「新規流域ではカワゲラ等の大きな目の置換があるので旧年学習の河床情報が役に立たない」という**単純な目レベル群集組成仮説は支持されない**。一方で個々の科・属・種の違い、相対比率と元のXEMBEDの関連の変化、検出・サンプル選択は依然あり得る。**未検出を「同じ生物群集」とは解釈しない。**

## 生物原本`TOTAL300`による厳格な集計

- 元BERWの各native UIDで有効な原本`TOTAL300>0`の全タクソン行を集計し、**E/P/T目に該当する元`ORDER`をそのまま採用**。未分類や非EPTの目も分母に残す。
- **全1,165 UIDで`(N_E+N_P+N_T)/N_total`が元の第4期外部予測モデルの`ept_fraction`に絶対誤差≤1e−12で一致**。勝手な個体数変更はない。
- 原本計数分母`TOTAL300`のUID中央値は300個体、10–90%位は98.4–300個体。原本総計数のうち`ORDER`が空欄の個体割合は約**0.707%**。EPTがゼロの原本native UIDは65/1,165、EPT陽性UIDが一つもないHUC8は35/693。
- 主解析は各UIDの元個体数比率を算出し、HUC8内で平均する。**HUC8の元UID数が異なっても各HUCを1票**として214/209 HUC8ペア差を取る。混合sample typeのBETBは使わない。従ってこれらの割合は羽化昆虫のバイオマスでも種数でもない。

## 背景の独立した研究／新規性の限界

英国・豪州・ニュージーランド・ブラジルを比較した[e17084の2024年GCB論文](https://doi.org/10.1111/gcb.17084)は、淡水底生動物の細粒堆積物への応答が地域と多様性ファセットにより異なることを実証済み。つまり「分類群により底質への応答が変わる」という仮説そのものは新しくない。

現在の解析の独自性は、EPAの本当の**4回の観測期**の原本で、学習時に使わなかった流域への予測移植の境界を可視化し、**環境条件・粒径組成・水理規模だけでなくEPT目レベルの個体割合でも、そのギャップの単純な説明ができない**と数値的に反証したこと。ただし観測履歴そのものが予測差の原因とは断言できず、科・属・種レベル、集団史、環境と群集の関係変化、検出過程、source-population選択はなお残る。

**重要な下水との非接続**：これは元EPAの河川内実測TN/TPと底生動物。上流の下水処理場由来の実測リン曝露でも、河川から陸へ流れる栄養フラックスでもない。WWTP DMRの観測数制約SOURCE STOP [PR #139](https://github.com/zuizui0223/gesui/pull/139) を変更しない。
