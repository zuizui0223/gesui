# 2026-11-21｜2018年の許可・採水点IDを原公開表で照合する

## 目的と位置づけ

PR137の固定された930地点候補について、WQE採水点と正式な排水許可の対応を検証する。既存のEEA 2018放流口との250 m相互一意対応は地理候補であり、正式ID対応とは分ける。本作業は探索的なSOURCE監査である。原資料のスキーマと全国件数を確認した後、930候補との照合結果を計算する前に規則を固定する。生物指標、個別TP値、効果の符号、P除去回帰を使わない。

## 一次資料

1. Ofwat公開 `Water-company-phosphorus-discharge-data-2011-2021.xlsx`。原公開URLと英国国立公文書館が保存した同じ公開URLのバイト列を来歴に残す。SHA256 `b7699aa3202366b15baab4c415e0702a5fb8f0401249b415903b8e763939b3c4`。2枚のデータシートから2018年を抽出する。表のタイトルを互いに排他的なP許可群と仮定しない。重複ヘッダー、重複行、シート間の重複を検査する。
2. Ofwat/Jacobs, *Water Quality Performance Commitment Review*, 9 June 2023, §2.3.2。原分析は採水日に許可版を割り当てるが、公開年次集計は年内の最新有効許可を選び、以前の許可を省く。この年次対応だけで全採水日の許可を確定しない。
3. EA `Consented Discharges to Controlled Waters with Conditions` 2026年公開ZIP。含まれる `consents_all`、`consents_active`、`Effluents` の正式キーと日付を二次照合する。データベースSHA256 `d664ea13da990c064006c6bfe32b3f76bc682c8b188bca55be33a3c8077136a7`。現行の公開抽出にある過去の日付は、完全な2018年台帳の保証ではない。Conditional Licenceの原個票は公開しない。
4. 原EEA 2018 CSV 3表の既存SHA256とWQEの現行SA台帳。原 `repCode=UK5` の1,799処理場・1,809出口を既存解析母集団として維持する。これを英国提出全行と同一視しない。WQE台帳は5,722 SA、固定930地点集合のSHA256は `d55a7773bd85c59bf137dda4dac835cd0a1f77d8912a1164a422ac48ee7cee07`。完全な組合せのSHA256も既存結果と照合する。

## 対応規則

- 主証拠はOfwatの同じ2018年行にある `sample_samplingpoint_notation`、`EA_REGION`、`permit_number`、`version`、`outlet_number`、`effluent_number`。元の完全な採水点notationがWQEと一致し、地域が一致するものだけを採用する。名称・近接座標・接尾辞のみでは結合しない。
- 地域コードは原Ofwat表と現行WQEの整合を検査する。EA `MI` とWQE `MD` の対応は原Ofwatの完全notationで確認された地域表記差であり、他の文字列を推測して修正しない。他6地域は同じ接頭辞。
- 許可番号は前後空白以外を変更しない。版・出口・排水系統の番号だけは非負の整数表現を正規化する。生の文字列表現による照合数も残し、ゼロ埋め正規化の寄与を明示する。
- 同じ採水点に複数の正式キーがある場合、勝手に1つを選ばない。元行数、異なる対応組数、異なる採水点数、完全に一意な採水点数を区別する。
- EA補助照合は地域＋許可＋版＋出口＋排水系統の全5キーで行う。`Effluents.EFF_SAMPLE_POINT` は、その地域と原Ofwat完全notationとの対応を検査する。日付・排水区分など必要な原列が同一キー内で矛盾する場合は除外数を残す。
- 年内重複の暫定日付判定は `[EFFECTIVE_DATE, REVOCATION_DATE)` と2018暦年の重なり。日付欠測・不正・逆転を別扱いし、空欄の失効日を完全な履歴の証拠にしない。年次Ofwatキーの現行台帳による裏付けであり、採水日ごとの版の確定ではない。
- `consents_active` だけを用いた時に失われる過去の対応も数える。複数の許可版・出口・排水系統を単一施設に集約しない。
- 原EEAコードから正式許可への明示対応が未確認なら、今回SA↔許可が成立しても、EEA放流口↔SAの完全なID対応は未成立と記載する。

## 流量と質量の境界

EEAの `uwwWasteWaterTreated` と `uwwMethodWasteWaterTreated` の記入数は監査するが、空欄を0にしない。許可DWF、最大値、設計容量、Ofwatの計算列を観測流量として使わない。年間濃度中央値×年間流量から実測P負荷を作らない。N/P質量、BIO効果、下水由来の因果効果を推定しない。

## 公開物・停止条件

コード、合成データによるテスト、集約件数、フィールド名、出典URL、ファイルと集合のハッシュ、再現手順、結果解釈のみ。元の施設名、許可番号、採水点ID、座標、濃度、個別流量は公開しない。ハッシュ・必須スキーマ・5,722/930集合が変われば制御されたSTOPを出し、例外本文を出力しない。main・PR124には統合せず、既存PR137をDraftとして更新する。
