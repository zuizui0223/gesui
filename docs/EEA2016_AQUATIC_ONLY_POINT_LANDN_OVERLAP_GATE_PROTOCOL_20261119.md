# 2026-11-19｜2016底生EQRのみ：源データの独立地域重複ゲート（新しい別モジュール）

共通水陸2×2（2018河川＋2017–19植物）が公式GISCO2016で25地域・6か国のため事前SOURCE-STOPになった事実は変えない。今回、**2016年河川底生動物の水域単独**で、同じNUTS2に水への点源Nと土壌への大気沈着・鉱質/有機N施肥がそろうかを、2016 EQR数値を読まずに検査する。既存2016点源N/EQR結果は既知なので、独立確認的研究ではなく事後探索的な新規対照の可能性監査。

既存の2016 EEA底生のSOURCE-only固定台帳（79 NUTS2、13か国、元観測サイトIDをEQR値の前に凍結）を用い、2026年11月18日に厳密照合したJRCモデル点源+陸域投入269 NUTS2/28国source-only CSVと国/NUTS2原コードで一対一結合する。元の生物計測の年2016は固定、JRC点源はGREEN 2014–18平均（家庭＋産業由来を含む）、EMEP大気Nは2015、DAYCENT肥料Nは2010–19モデル。海域を含む行政区に由来する曝露は受水水質の実測値ではない。

**事前SOURCEゲート：** 共通の独立NUTS2 >=55、共通国 >=8、国に3以上の対象NUTS2があり点源N密度と大気N沈着の国内変動が双方確認できる国 >=5、5つの元凍結NUTS2独立foldがそれぞれ8地域以上、元2016監視地点の計測方法メタデータと全SOURCE IDが復元できること。どれか未達なら、その水域単独の新しい点源対陸投入比較を**数値EQRを読まずにSTOP**。

通過した場合のみ検討する別途の水域対照は、既存2016底生EQRを対象にB0（国・評価方法・地理・面積）、BP（点源N密度）、BD（大気沈着・鉱質/有機N施肥）、BPD（両者）という**同一標本・同じ元2016 NUTS2独立fold**。追加予測誤差を国等重みと地域等重みで比較する。水陸間の生態連鎖・蝶効果・下水の因果媒介は検定しない。今回のゲート実施ではEQRの値を一つも開かない。陰性になった場合も元の2016点源EQR結果を改変せず、source-onlyのSTOPを記録する。
