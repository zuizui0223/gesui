## Genuine source and measurement
Source: Impact Observatory / Esri / Microsoft **10m Annual Land Use Land Cover (9-class) V2**, original Sentinel-2 yearly classified maps, **CC-BY 4.0**, collection `io-lulc-annual-v02`, [Microsoft Planetary Computer public STAC](https://planetarycomputer.microsoft.com/api/stac/v1/collections/io-lulc-annual-v02), publisher [Impact Observatory Maps for Good docs](https://docs.impactobservatory.com/lulc-maps/maps-for-good.html), public [AWS `io-10m-annual-lulc` bucket](https://registry.opendata.aws/io-lulc/). Both years **2018** and **2022** are in the same updated V2 release, 10m output, nominal Sentinel-2 UTM grid.
- Native original integer class codes: 0 NoData, 1 Water, 2 Trees, 4 Flooded vegetation, 5 Crops, 7 Built, 8 Bare, 9 Snow, 10 Clouds, 11 Rangeland (grass and shrub). Original source **class is not continuous tree cover percentage or physical biomass**. Map class changes can reflect cloud contamination, compositional classifier noise, or land-use dynamics, not all are real vegetation change.
- No location/image selected on sign of EQR/land cover. Original true **381 French same-EEA physical sites and 2018 RZ source** (3-degree regions 14 / five source folds 122,58,48,33,120), old/source methods exact; restoring cohort before reading 2018/2022 EQR numeric is mandatory. ## Frozen source-only two-stage gates
1. Public STAC `/collections/io-lulc-annual-v02` must respond 200 and explicitly identify original publisher, 10m raster, original class code dictionary and V2 annual 2018/2022 scope. Query a **fixed, non outcome-selected** 1° geographic example of France in 2018 and 2022. Each returned source Item shall carry actual year 2018/2022 and a raw COG `data` asset. Check original item ID/year/asset href; do not guess tile filenames. Verify actual TIFF byte range per year over a *legitimate* public URL with HTTP206 or 200/valid TIFF header. SAS tokens issued anonymously by the publisher API are allowed, since they are legitimate publicly supported source access, **not secret/access bypass**. Fixed source [AWS public no-auth S3](https://registry.opendata.aws/io-lulc/) is also legitimate. **GO only on actually readable native unstyled TIFF, not style-mapped PNG**.
2. Recompute 381 real France original source-only `site_key` IDs and their frozen fivefold from true EEA+RZ artifacts (no numeric EQR yet), find native actual LULC V2 2018/2022 product tiles covering every site ±500m, verify year, projection, grid, original pixel schema, source NoData and cloud code, and spatial alignment 2018/2022 via reprojected exact circles. Do not silently interpolate raster class by bilinear (use nearest categorical). Source labels and 2018/2022 class integer values examined for quality **only after** source tile identity, never biological response.
3. Source eligibility must be **>=300/381 full year-paired sites**, all five original source geo folds **>=30** sites, >=10 original 3° blocks, each ring 0–250m **≥200** valid original 10m terrestrial 2-year pixels, 250–500m **≥400**, exclude cloud(10), nodata(0), water(1) and snow/ice(9) at **either year**; same original geographic pixel location in two years (no mismatched resampling). At least 95% of eligible year-paired pixels retained after cloud/nodata mask in each ring; no GIS topology errors or original cloud-driven selective loss. All **381** sites and reasons for exclusions go to source QA. Source threshold fixed before results. An absent 2022 tile, failed COG download, major cloud holes → **STOP**, never treat as an ecological null or fill with 0.
4. Distinguish original source "Trees" `2` fraction from "Rangeland" `11` and "Crops" `5` area fraction. Primary predeclared **∆TreeNear−∆TreeFar**, where each tree fraction is pixels with original class=2 among valid terrestrial pixels in a year within same 0–250m vs 250–500m **source-original nonwater terrestrial support**. Additional original land classes reported descriptively without optimizing a group based on significance.
5. The supplied CC-BY 4.0 source is annual 10m **class labels**. Do not describe `∆TreeFraction` as actual field growth/biomass, high-resolution TCD, or all forms of terrestrial riparian functional change. Original RZ2018 class mask might constrain valid vegetation pixels but is from a different product and remains STATIC.

## Only after source GO, single fixed exploratory ecological model
Same method-stable France EQR2018 and EQR2022 original true site values. Response **∆EQR = EQR2022 − EQR2018**; baseline B = original 2018 EQR + 2018 lat/lon/log river Q/log area + static original 2018 RZ outer natural/urban/crop fractions. Add **one new ∆TreeNear−∆TreeFar** predictor. Compare **fixed 5 geofolds**, original 14 region block-equal MSE and site-equal MSE, 2,000 source-block bootstrap of fixed OOF error differences (description, not confirmatory CI). Model train-only standardized original numeric predictors with **Ridge alpha10**, no alpha/radius/outcome/fold adjustment based on p. A secondary prespecified ∆TreeFar alone (not a stronger selected subgroup) to show whether local spatial contrast adds beyond broad tree change. Keep all negative and positive regardless of direction; geography+2018 status may absorb cross-sectional landscape signal.
- This is still **simultaneous four-year land cover and EQR change**, cannot establish temporal ordering, terrestrial→aquatic selection, buffering or causality, and **not sewage-derived nutrient** or measured water→land trophic flux. Source WWTP both-year reporting-positive only 14 of 409 RZ repeat sites, so no nutrient-specific mediation.
