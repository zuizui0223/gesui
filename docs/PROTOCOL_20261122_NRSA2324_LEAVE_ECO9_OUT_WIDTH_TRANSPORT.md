# Regional transport falsifier for EPA 2023–24 field width signal (2026-11-22)

This is a **posthoc geographical falsifier** defined after the main HUC8-heldout result of positive width information beyond modeled mean annual flow and watershed area. The base outcome sample, source SHA, physical method strata and all covariates are frozen in `scripts/gesui_nrsa2324_flow_area_width_stress_20261122.py`. We do NOT change them or search alternative significant outcomes.

**Prediction:** If field width captures a transportable aquatic habitat axis beyond NHDPlus modeled hydrology, then adding log field width after log modeled annual flow, log drainage area, original ambient TN+TP, canopy, geography, urban status and field season should improve prediction in ecological regions not present during fitting. If gains are confined to HUC8 heldout within known regions and fail leave-entire-region-out, the national generality claim is downgraded. Neither condition implies a manipulative effect of width.

## Strict transport design
- Use unchanged four source cohorts (BERW/WADEABLE and BETB/BOATABLE, original EPA MMI and counted EPT fractional responses), original SiteInfo/WaterChem/PhysicalHabitat/Count/MMI SHA.
- Include original field-site covariates from source model `B_NC_FA`: state + ecoregion + lat/lon, Strahler stream order, season/year, log measured conductivity, ambient observed TN+TP, field canopy (appropriate to protocol), log modeled NHDPlusHR mean annual flow (cfs), log upstream catchment area (km²), original `URBN_NRS23` label. Compare `B_NC_FA` vs `B_NC_FA_W` (adds original measured log channel width) and ONLY this paired contrast. No new response transformations or interactions.
- **Nine leave-one-AG_ECO9-out folds**, not random site or HUC8 holdout. To avoid HUC8 leakage, exclude from training any HUC8 present among the target eco9 test sites, even if it also contains an observation assigned to another region. No train/test HUC8 overlap. At least 10 test visits and 5 independent test HUC8 in each region; at least 250 train visits and 100 train HUC8; otherwise flag the fold as ineligible and report without concealing.
- Train-only StandardScaler for all continuous, train-only OneHotEncoder for state, ecoregion and urban labels (unknown heldout categories mapped to all zero). Ridge alpha10 as in prior code. Fixed original output collection; no sign-based tuning.
- Report all 9 original AG_ECO9 region heldout MSE changes, number of regions whose improvement is positive, site-weighted MSE gain, **nine-region-equal MSE gain** and 2,000 region-resampled fixed-OOF bootstrap95 for the region-equal gain; bootstrap is descriptive (n=9 regions) and not a causal confidence interval. Independently reproduce each prior exact HUC8-heldout reference MSE before the regional analysis.
- Also calculate a **purely descriptive whole-source OLS standardized log field width coefficient** in the full flow+area+urban+nutrient+canopy model with HUC8-cluster robust interval in each group, for effect sign only; do not replace transport test with significance.

All 4 outcomes must be reported, including failed predictions. Substantive claims about width effects, human channelization or rivers versus streams **remain observational and posthoc**. This is not an effluent sewage study, aquatic-to-terrestrial transfer assay or global meta-analysis.
