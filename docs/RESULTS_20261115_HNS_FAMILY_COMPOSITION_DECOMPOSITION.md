# 下水関連地理と蝶の寄主N選好：科間 vs 科内の源データ分解

**2026-11-15 / 事後探索・非因果・同一H7マクロ記録のみ / Draft**  
対象：2017–19・2020–22年の元データ **454 H7×period, 232 H7, 90 genuine H6, 15 countries**。独立した現地採集や生物間相互作用測定は追加していない。

## 何を検証したか

蝶の幼虫寄主植物について既存の種固定HNS（habitat nutrient-affinity scores）を使う。「下水地理が好窒素性寄主を使う蝶の記録組成に関連する」という既存の同一H7関連を、以下の恒等分解で検査する：

HNS_total = HNS_between_family + HNS_within_family.

- **科間成分**：各科の全原本対象種の基準平均Nスコア × その科のGBIF記録比率。
- **科内成分**：科内の記録種組成 × 寄主Nスコアの基準平均との差。
- 第1項+第2項はソースデータ454/454行でHNS記録重み付き総量と厳密に一致。異なる独立データではなく、同一HNSの数学的分解。

## 主要結果：科間と科内の同一W関連の分解

国・水文地理・記録努力等を調整するが**蝶の科比率を調整しない**モデル：

| 同一原本の応答 | W β / +1 SD | H6 cluster 記述95%区間 |
|---|---:|---:|
| HNS記録重み付き総量 | +0.13284 | [+0.03271,+0.23296] |
| HNS **科間**成分 | +0.00575 | [+0.00134,+0.01017] |
| HNS **科内**成分 | +0.12708 | [+0.02827,+0.22590] |
| HNS種均等（incidence equal） | +0.06998 | [+0.02911,+0.11085] |
| **記録重み−種均等**の差 | +0.06286 | [−0.02407,+0.14978] |

総量の係数は**科間 + 科内**に厳密分解される。この同一線形モデルでの点推定比 **0.12708 / 0.13284 = 95.668%** が科内成分に対応する。この95.7%は分散説明率、安定した因果寄与率、生態学的な媒介割合ではない。比の信頼区間を推定していないので不確実性の幅を断定しない。

同じ共変量に**4科の記録比率をさらに追加**すると、W→HNS記録重み付き総量 β=+0.14482 [0.06497,0.22468]、W→科内 β=+0.14482、W→科間 β≈0。この科間β≈0は科間成分が科比率の線形結合だから**代数的に生じる恒等式**であり、生態学的な科間影響なしを示す独立検証ではない。+0.14482は元PR #88の同一モデルを再現する。

種均等重みではβの点推定は小さいが、両重み付け係数の差の区間はゼロを含むので、「記録の偏りだけが正の関連を生んだ」とも断定できない。より強い地理的な共変量調整を用いた既存PR #87では種均等HNSの区間がゼロを含む結果もある。仕様依存性を保持する。

## 生態学的示唆とパス解析の接続

1. **科の入れ替わりだけでは説明しきれない**：この観察モデルでは、Wに沿ったHNSの調整後関連の主成分は、**同じ科の中でのGBIF記録種組成差**である。「シジミチョウ科など特定の科が一律に増える」という説明より細かい分類群・寄主特性の検証動機になる。科内成分は種の記録・地理・観測努力・HNSの完全性に依存し、進化的適応や実際の寄主利用量を測定していない。
2. **幼虫寄主経路（仮説）**：処理水量・栄養・根圏水分 → 現地寄主植物の被度／葉N → 幼虫占有・摂食 → 蝶種組成。HNSは最後の記録代理にすぎず、前段の野外測定は454 H7にない。
3. **成虫の有機物／塩類経路（別仮説）**：処理水・湿潤地・河岸腐肉のNa／有機態N → 種×性×行動の吸汁 → 成虫集積・繁殖。シジミチョウ科のタンパク質系誘引源選好の実験（Beck et al. 1999 Oecologia https://doi.org/10.1007/s004420050770）は機構的先行知見だが、下水現場への外挿は未確認。腐魚は自然腐肉・魚類死亡・排水汚染のいずれでも生じ得るため、腐魚＝下水とはしない。
4. **水生→陸生捕食者経路（別仮説）**：処理水 → 藻類・底生機能群 → **実測**羽化バイオマス → クモ等捕食者。EEAのEQRは羽化質量ではない。処理水操作実験は一次生産・植食と総エネルギー移行が異なる方向に変化し得ることを示す（2023, https://doi.org/10.1016/j.jenvman.2023.118510）。河畔無脊椎動物への排水起源の同位体移行例もある（2025, https://doi.org/10.1016/j.envpol.2025.125948）。

**禁じる解釈**：+0.127を「下水由来N→寄主植物→シジミチョウ」の間接効果と呼ぶこと；科内比95.7%をSEMの媒介割合と呼ぶこと；GBIFレコード比率を蝶の個体数・バイオマスと呼ぶこと。Wと都市化は相関し（旧ソースρ≈+0.78）、FRは299/454行を占め、H6外挿の元モデル予測利得の95%区間はゼロを含む。
