# Global WWp × ALL Plantae: cross-kingdom recording controls (2026-11-10)

**Explicitly posthoc, after the all-Plantae 1,055-port result was observed.** Aim: distinguish whether 2015 modelled wastewater generation is especially associated with GBIF *plant* recording, versus a more generic concentration of biological records. This is NOT an unaffected biological negative control: Animalia and Fungi may respond to urbanization and pollution, too. It is a cross-kingdom **recording comparator** only.

## Frozen source geometry, sample and query scope — no response-based site selection

- Original WPI source 1,055 ports across 42 countries, and exactly 752 original 2011–24 all-Plantae speciesKey source-quality-supported ports across 38 countries, as frozen in `results/global_all_Plantae_WWp2015_20261110/ORIGINAL_ALL1055_42COUNTRY_WWp2015_BEFORE_NEW808_GBIF_SOURCE.json` and `.../ORIGINAL_ALL1055_42COUNTRY_GBIF_PLANTAE_2011_24_50RECORD_RAREFACTION_SOURCE.json`. Do not re-fetch or replace the 1,055 Plantae responses or recruit other ports.
- 2015 Jones modelled **wastewater generated** within 25km, original 2021 ESA WorldCover built/crop, original HydroWASTE WWTP counts, original 2011–24 GBIF all-Plantae record count/richness/50record-rarefaction. Initial 752 site selection depends on GBIF quality and historic host inventory; not random sampling.
- Query GBIF `GET https://api.gbif.org/v1/occurrence/search` with `limit=0`, `taxonKey=1` (Animalia) and `taxonKey=5` (Fungi), **same year `2011,2024`, exact original WPI port coordinates and `geoDistance=5km`, `hasCoordinate=true`, `hasGeospatialIssue=false`, `occurrenceStatus=PRESENT`**. Only read the *total indexed occurrence record count* for each source port/taxon; do NOT use speciesKey facets, identify organism species, or claim standardized animal/fungal biodiversity. Record full request URL, response SHA256, query timestamp and errors. Rate-limit at **≤1 request per 0.8s per runner**, retry 429 and transient errors, do not turn failed query into 0 records. Use 4 deterministic 1055 port shards by port ID ordering, 264/264/264/263 rows, each querying exactly TWO taxonomic kingdoms. Do not scrape GBIF website or run more than these predefined queries.
- Source-cohort **feasibility gate set before responses**: >=95% (≥1002) original 1055 sites with both Animalia and Fungi counts successfully fetched; and among the previously 752 plant-quality sites, ≥700 both-count-supported source sites from >=30 countries, including ≥25 countries with ≥2 distinct 2015 WWp source values. When fail, report source availability only, **STOP** cross-kingdom coefficient fitting; do NOT relax radius/time/API quality to chase direction.

**Decision interpretation:** If Animalia and Fungi also show positive WWp relationships, generic record concentration/urban ecological co-gradient remains a serious alternative for plant raw-richness positivity; if not, a plant-specific signal is possible but not established. If plant raw richness weakens after comparator counts, that is *suggestive of shared recording*, not proof of confounding versus biological response. Rarefied50 plants already weak (+0.01256, country CI includes 0); do not inflate the coefficient by choosing favorable taxa/ports.
