# 元EPA分類群×環境×形質：多分類群の条件付き構成モデル（2026-11-15）

## 目的・機構仮説

旧PR #98の個体数重み付き/分類群出現等重みCWMの3調査期河床埋没勾配を、同じ真正EPA元**地点×原TAXA_IDの計数行列**に戻して検定する。事後探索であり、CWMの単なる再計算でなく、**観測した複数分類群の共通の条件付き記録組成予測**が改善するかを新しい判定軸にする。

- H1：河床埋没度が高い場所では、**同じEPT目の中でも**固着習性の高い分類群の相対構成が低くなる。予測モデルの `XEMBED × CN` 係数は負。
- H0：同じEPT目・栄養塩・季節・空間・他の河床/河畔変数を使えば、`XEMBED×CN` は未知流域の**分類群構成の予測**に追加の情報を与えない。
- H2（副）：計数個体を等分した条件付き組成と、出現分類群を等分した条件付き組成の両方で改善する。これは真の密度/種の生存率や、種内進化を測るのではない。

## 真正原本と分析対象

前PR #98のEPA 2008–09 BERWW, 2013–14, 2018–19 BERW `TOTAL300`で、元`TAXA_ID + ORDER`、2018の原受理名までEPA形質元原表と一致するデータを使う。元EPA m200 サイト2,209件から、**厳格形質スコア条件**を適用：
- 固着型（HABIT CN）の個体数・分類群割合とも形質対応80%以上
- 形質付きEPT >=3分類群、観察EPT >=10個体
- 処理水濃度と個体群密度は観測していない。独立な場の処理水影響は推定しない
- 厳格の元PR #98の対象は2008 **377サイト/313 HUC8**、2013 **767/526**、2018 **624/423**。この元コホート数と形質CWM数値が一致しなければ停止。

## 新しい条件付き多分類群モデル（完全な潜在JSDMではない）

各地点で形質採点可能なEPT`TAXA_ID`の元計数が与えられたときの**相対記録構成** `F_ij=count_ij/sum_j count_ij` または `F_ij=1(present)/count(scored taxa)` を応答にする。

`Pr(taxon j at site i | total scored EPT) = softmax_j[ log(p_j_train) + Σ_k Σ_m X_i,k * B_k,m * Q_j,m ]`

- `p_j_train`：訓練流域だけの各分類群記録構成から推定、微小事前平滑化付き。形質・元sourceで定まったtaxon roster以外のtest応答を学習しない。
- `Q_j`：EPA公式固着スコアCNを**同じEPT目内平均から中心化**した形質と、EPT目の2指標。3目間の構成差を交互作用で調整。
- `X_i`：実測`XEMBED`、河川`logTN/TP`、緯度経度、電気伝導度、河川次数、年・季節、河床・河畔の他の5項目、EPA原生態地域のダミー。全数値は訓練地点だけで標準化。
- **基準M0**：形質×栄養塩/他の環境/地理＋EPT目×全環境（**XEMBED×形質だけを除外**）。
- **追加M1**：M0+ `XEMBED × CN_within_order` 1項。最適化は条件付き多項対数損失＋固定L2=0.025正則化。カテゴリの訓練時点で未知はダミー全ゼロ。応答は個体総数重みではなく、HUC8均等な**地点平均の条件付きcross-entropy**を用いる。
- 欠測形質の分類群は母集団として推定しない（本条件は高品質限定で、真のEPT全体ではない）。
- クラスタ誤差：独立真HUC8を4foldへSHAで割当、2,000回固定保持HUC8誤差再標本化の記述95%。テスト流域は一切訓練へ入れない。
- 結果はlog-loss平均nats/記録構成、MSEでも真の野外生産でもない。**強い主張には3期とも留保CE改善が0を超え、係数方向も合致すること**を必要とする。失敗・nullは保持。

## なぜこれがCWMの繰り返しではないか

CWM回帰は予め要約した**1個の平均形質**を地点に割り当てるのに対し、このモデルは元の分類群記録**全体**に確率を与える。`XEMBED×CN`が同じEPT目内の分類群分布の未知地点予測に有効かを直接検定する。既知のCWM傾向と新モデルのOOS符号が食い違えば、前者が一部形質だけ/高次変動に依存した可能性を明示する。

ただしこれは測定誤差・系統共分散・潜在種間相互作用を推定しないため**厳密なHmsc/JSDMとは呼ばない**。統計的なモデル化Fourth-cornerアプローチ（Brown et al., 2014, doi:10.1111/2041-210X.12163）に準じた縮約型モデルと位置付ける。

## 重要な制約

- 空間・生態地域/河道による未観測交絡、数値の小さい実測XEMBEDの精度、形質コーディングの一般化は残る。
- 旧3期のEPAサイトは一部HUC8が再訪/重複するが、**単一調査期内のHUC8独立CV**は守る。他期の検証は別に監査する。
- 観測はEPAの標準採集標本における分類群カウントで、真の現地絶対個体数や真の検出確率ではない。
- この新モデルは**下水処理場の方向・実測排水量の因果効果ではない**。EU蝶HNSのGBIF記録と値を混ぜた1本SEMは組まない。比較するなら形質×環境の再現性・欠測耐性を別々に評価する。
