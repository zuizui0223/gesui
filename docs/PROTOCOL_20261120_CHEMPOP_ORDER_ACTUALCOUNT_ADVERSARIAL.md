# 2026-11-20｜ChemPop EDF→BMWPの分類目階層・真の個体数・独立地点感度監査

**2026-11-19原ソースと前日の主係数を知った後の事後探索であり、新しい確認的検定ではない。** [原本source-gated run #44548177752](https://github.com/zuizui0223/gesui/actions/runs/44548177752) は2010–2018年、7地域・707実地点・3,884地点×年の科均等BMWPに対し、モデル化された推定下水混入率EDF (+1元標本SDのlog1p EDF) のWLS係数**−0.0911057**、site cluster記述区間[−0.13360,−0.04861]、全7地域LOOで地域等重みMSE改善+4.52% [0.59,8.35]、5/7地域で改善を報告した。しかし科BMWPスコアを**同じ目内**で999回交換した帰無はp=0.206で、科特有の帰無を支持しなかった。元2つの曖昧な多目コード科を恣意的に交換可能な目へ配属しない。

## 今回の四つの検証と採択基準（実行前固定）

1. **目間と目内の寄与の同じWLSでの代数的分解**。元BMWPスコアを、原分類群目ごとの得点済み科の単純平均+同目内偏差に分ける。科の目分類が2以上の曖昧原票は属/目の推測で埋めず独立単一群として扱い、未知目も同様。元科等重みCWMの恒等式及び元EDF βが「目平均β＋同目偏差β」に誤差1e−9未満で一致しなければSTOP。各成分に元調整項を持つ地点クラスタWLSと七地域留保予測を適用する。元999回目内形質ラベルnull p=.206を維持し、今回の分解係数が有意でも「目内の形質ラベル検定を通過した」ことにはしない。
2. **1河川地点を1行に集計する感度解析**。元3,884地点×年を707地点の各期間平均へ統合し、EDF・土地利用・河床など同地点で元データを再照合する。地点を時間反復の独立下水処理とみなさず、EDFの地理的関連が長期反復による重みの偏りでないかを検証する。各河川site均等、同じ地域・元環境調整、全地域留保。
3. **1地域まるごと除外のEDF係数**。7回それぞれ残る6地域でBMWP科均等のWLS係数・地点クラスタ記述95%区間を出す。初回の地域外MSE改善は5/7であってすべての地域一致ではない。国全体（英国1国）の再現を「国を越えた」証拠に格上げしない。
4. **真の個体数記録法への限定**。前日raw source onlyでは7,836原適格sampleのうち6,166件が `Estimate of the log abundance (scale as  BT001)`、1,641件が`Actual abundance of taxa in the sample`、28件が`Estimate of abundance (locally defined scale)`、1件が珪藻の前処理法だった。対数推定階級は**個体数そのものではない**ので記録重み付き指標を真の個体CWMと呼ぶことを停止する。正式な`Actual abundance of taxa in the sample`だけを抽出し、得点つき科の全BIO_ABUNDANCEが正の実数として与えられるsourceサンプルだけ同じ科均等CWM・実個体数重みCWM・差を比較。結果を見る前の支持基準：300元試料、200地点×年、100真正site、少なくとも4地域にそれぞれ5真正siteかつ5つ以上の元EDF値が揃う。未達ならreal countの解析はSTOPし、全元試料のコード値を個体数へ読み替えない。

## 一貫したモデルと重要な識別境界

同じEIDC ChemPop v2版UUID 23f194b0-1e21-4f14-be9c-6eabdcc1feb7、原ZIP SHA256 cc42df5ea777f5c7f59e31b097435d5caf72be21fc7e6bc08f3ce13cde83bc51、英国`biotic` 2016参照原RData SHA256 4f9be755ce6d24e645b46705dbec9c0367bc71a9ce6b335d3bf2657d8c10ac5a を必要条件にする。元「707地点・3,884地点×年・7地域」の本解析主係数を再現しない場合は計算を停止する。

全モデルはEDFをlog1pし主解析の標本内1SDで標準化、都市・農業・河床・河川幅・標高・観測年・月・原観測方法・得点種数／coverage・地域を調整したまま使う。WLSのsite均等重み、cluster site区間、region独立out-of-region Ridge10(train-only encoding)を変えない。結果の固定予測誤差・地域ブートストラップは新しい全国独立研究の推定区間ではない。

**実証していないこと：** EDFは静的なモデル推定処理水混入率であり、同年の実測処理場N/P質量や現地植物・蝶への媒介ではない。BMWP高値は科の汚濁感受性（一般に高いほど敏感）であり、真の種内の進化・機能的生理応答、同一サイトでの加入／消失、バイオマスではない。別の河川水質元データも後付けで都合よく選ばない。
