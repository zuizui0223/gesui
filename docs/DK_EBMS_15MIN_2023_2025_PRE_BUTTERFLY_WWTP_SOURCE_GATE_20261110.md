## Source-only Event and geography rules

- Valid Event date in 2023, 2024 or 2025, original latitude/longitude inside DK public envelope W7–E16, 54–58N, and explicit original coordinateUncertaintyInMeters <=500m. Missing uncertainty is missing, **not implicitly 0m**. Also report a separately labeled less strict metadata-availability sensitivity for events with unknown original uncertainty but not flagged >500m; never use this to silently replace the strict primary.
- Define 15-minute counts as **event-level observation opportunities**, not identical independent biological units. Within each year classify events by Haversine distance from original reported EEA source: near <=2km, near<=5km, intermediate 5–10km, remote>=10km from all 203 qualifying registered outlets. Any source-eligible event nearest exactly one original outfall hash for grouping. No claims of downstream nutrient delivery or untreated remote controls.
- To mitigate close-spatial pseudo-replication, also report **approximately 1km coordinate grid cells** by fixed floor(lat/0.01),floor(lon/0.01) (explicitly variable physical dimensions due longitude), repeated visits in each grid, **unique near outfall clusters** and 1° geography (floor lat/lon). A source with 100 nearby events is still *one source*.
- The repeated-site 107 transect cohort is entirely separate and never mixed into any 15-minute count inference. The 15-minute dataset need not reuse precisely identical sites across years because route/location is nonfixed.

## Fixed stop/go before opening source Occurrence extension

**Primary 5km cohort**: in at least **two of 2023, 2024 and 2025** there must be >=100 strictly accurate 15-min Events within 5km, >=200 remote >=10km Events, **>=10 distinct registered outfalls** represented by those near Events, >=20 independent ~1km cells near, >=30 independent ~1km remote cells, and >=3 original country×1° regions containing both near and remote Events. Entire original cohort, source hashes, year-by-source counts and repeated geography are frozen first. If this gate fails, **no butterfly taxon individualCount data from this archive shall be opened**.
**Narrow 2km sensitivity**: source-only thresholds >=50 near Events, >=200 remote Events, >=8 distinct near original registered sources, >=10 near ~1km cells, >=30 remote ~1km cells, and >=3 shared 1° blocks in at least two years. If not, STOP for this 2km analysis even when 5km passes. Do not re-tune radii/sample years after seeing biological responses.
- If Event source spatial accuracy is absent for all rows, preserve a full source-quality failure and seek verified spatial precision metadata instead of assuming uncertainty is zero. The separately reported missing-uncertainty sensitivity is *not* an outcome test license.
