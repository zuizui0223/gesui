- Full multi-country GO only if **>=150 stable-method independent site IDs, >=5 distinct countries and >=10 3deg spatial blocks, >=90% method agreement of eligible RZ-retested original site keys**, with each >=5-country source group having ≥10 stable sites. Biological EQR numeric results not read before this gate.
- If multi-country gate fails but **France** source has >=150 stable-method sites, >=5 3deg spatial blocks, ≥3 heldout spatial blocks each with >=20 source sites, France-only descriptive within-country **GO**. This is a **source-specified fallback** because all-site original repeat cohort is already France-dominated (1,073/1,167 common), not a response-selected positive subgroup. For any other country do not rescue result by finding a favorable subgroup.
- Otherwise **SOURCE STOP**; archive matched source metadata and point estimates from 2018 but no new outcome regression.
- No claim of 2018→2022 change in sewage load for sites selected on WWTP presence. Last cross-year original EEA sampling showed only **17/1,167** reused benthic sites with eligible upstream reported WWTP sources in both years, and report-eligible transitions 7 and4, far short of identifying a sewage change.

### Biological tests only if GO
**Primary** tests whether mapped terrestrial context at 2018 predicts **future 2022 EQR conditional on actual 2018 same-method EQR**, i.e. beyond prior ecological state and river geography/physical size. Same fixed training-only data processing and geographically held-out ridge hyperparameters to reduce overfit. This does **not** identify causal green-bank recovery or actual changes in riparian habitat.
- B = prior `EQR2018` + log original Q + log area + lat lon, country and country×method only if multi-country. L = B + 2018 far outer ring natural, urban, cropland fractions; D = L + near minus far natural fraction. Fixed Ridge alpha **10 on train-only standardized numeric fields**, use *whole 3-degree block out* geographical folds fixed only by source geoblock labels, without changing fold composition from target y signs. In a France-only source fallback use original regional blocks as fold groups. Report **original target 2022 EQR** OOF errors and gains relative to B.
- Additional **change-only** D=EQR2022−EQR2018 correlation with original 2018 land context *posthoc secondary*, including baseline initial EQR and geography. Positive in forecast conditional on EQR2018 does not entail causal changes. Report null or negative.
- Evaluate site-equal and block-equal MSE, fold-wise signs, 2000 whole-geoblock fixed OOF error resamples as descriptive95. If lack ≥5 outer regional blocks, STOP OOF. No 2018/22 independent-site p-value/causal mediation. Stratify by 2018/22 EQR method if unavoidable.
- Original upstream WWTP N/P 2018 vs 2022 reported source **not a differential treatment** (only sparse repeat eligible). Mention source status without fitting positive→negative transition response model.
- No new plant EIV, butterfly host HNS, foliar P, emergence mass or aquatic→land material flux. No claim of downriver WWTP source effect even though exposure ledger exists. Keep true WWTP/source STOP from [PR #139](https://github.com/zuizui0223/gesui/pull/139) and riparian PR123 no-P×near-far interaction.
