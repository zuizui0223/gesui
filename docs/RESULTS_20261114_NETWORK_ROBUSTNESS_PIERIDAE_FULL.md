# 同一流域の候補寄主ネットワーク：集中度・地域依存とシロチョウ科の追加検証

**2026年11月14日／PR86後の探索的再解析。独立した野外再現・メタ解析・下水の因果効果ではない。**

## 今回実行したこと

前回の署名済みGBIF原本・寄主目録をそのまま用い、454流域×期間、232 H7流域、90 H6上位流域群を維持した。記録時期は2017–2019年と2020–2022年。主な下水予測比較は6生物群すべての種ID同定率80%以上を満たす390行、217 H7、83 H6であり、390の独立流域ではない。

Clarke (2024) の欧州寄主資料の説明・メタデータは確認したが、原データ本体の取得は成功していない。**国別・証拠水準別の新しい寄主関係は未統合**であり、この文書の計算は前回のFerrer-Paris寄主目録とGBIF原本だけを用いる。GitHubへの新規書き込み・PR作成・main/chocho変更は行っていない。

## 1. 寄主対応の超過は時期・フランス以外でも残る

蝶20記録・植物50記録への超幾何標準化による候補リンク指数を使用。植物科、出現頻度階級、H6内出現パターンの6クラスを保った499回の植物ラベル置換と比較する。種数・植物科・大まかな分布が似ていても、目録で知られた寄主の組合せに対応が残るかを評価するものであり、実際の採食を観測したネットワークではない。

| 同じ標準化の比較 | 置換平均より多い候補リンク指数 |
|---|---:|
| 全454行 | +16.80% |
| 種ID同定率80%以上390行 | +16.32% |
| 2017–2019年 | +16.31% |
| 2020–2022年 | +17.38% |
| フランス報告行を除外 | +13.36% |

2期間は同じ流域を多く含む。異なる時期の同方向という感度分析であり、独立調査として二重計上しない。地域の共通環境と記録偏りを完全に取り除いた結果ではない。

## 2. 一種だけではないが、高寄与の食草群への集中は強い

除外対象は前回保存された候補リンク寄与順位から固定した。除外した植物は観測グラフと置換候補の両方から除き、元の記録総数と20/50記録の標準化深度を変えていない。残った植物間だけで同じ層内置換を行った。

| 除外 | 観測指数 | 置換平均 | 相対超過 | 置換分布95%範囲 |
|---|---:|---:|---:|---:|
| なし | 5.4393 | 4.6568 | +16.80% | 4.3259–5.0135 |
| 上位1種 | 4.9168 | 4.2060 | +16.90% | 3.9026–4.5462 |
| 上位5種 | 4.0899 | 3.6358 | +12.49% | 3.3578–3.8953 |
| 上位20種 | 2.6975 | 2.5855 | +4.33% | 2.4510–2.7303 |

上位1種は *Urtica dioica*。上位20種は元の候補リンク指数の50.41%を担う。上位20種除外後の観測指数は置換分布95%範囲内に入り、置換値が観測以上となる有限回数診断は(31+1)/(499+1)=0.064。これは結果に基づく対象除外を含むため確証的p値ではない。

H6再標本化での相対超過区間（+2.47〜+6.27%）は、**置換平均を固定した地域のばらつきだけ**を表す。グラフの割当て不確実性を表す上表の置換分布と異なる。前者がゼロをまたがないことだけを根拠に、除外後も頑健に帰無を超えたと主張しない。

食草削除は生態学的な消失実験ではなく、指数がどの植物に依存するかの計算上の診断である。

## 3. シジミチョウに特有の寄主対応ではない

全454行での科別の相対超過は、シジミチョウ+18.02%、タテハチョウ+15.51%、シロチョウ+10.14%、アゲハチョウ+30.78%、セセリチョウ+41.61%。ただし、科ごとに寄主目録の充足度と置換可能な植物群が異なるため、これを科の本質的な専門化や下水感受性の順位と解釈しない。シロチョウ科ではこの構造指標は置換分布に対して明確ではない（有限回数診断0.126）。

## 4. 新しい探索的肯定結果：シロチョウ科の寄主サポート指数

寄主サポート指数は、記録された蝶の既知寄主が同じ流域・期間の植物50記録相当に含まれる見込みを、蝶側の20記録相当の構成で重みづけた0〜1の指標。幼虫生存率、採食量、蝶個体数ではない。

従来の基準モデル（地理・記録量・土地利用・流量・種数・目録充足度など）に静的な下水インフラ指標Wを加えた。H6を学習と検証で完全に分離し、同じH6の全H7・両期間を同じ検証分割に入れた。Ridge alpha=10、学習側のみ標準化とカテゴリ定義、H6均等重みを前回から維持。

| 応答／同じ390行 | H6外予測MSE改善率 | 固定予測誤差のH6再標本化95%区間 |
|---|---:|---:|
| シジミチョウ科寄主サポート | −2.25% | −9.86〜+5.03% |
| タテハチョウ科寄主サポート | −2.82% | −6.53〜+0.73% |
| **シロチョウ科寄主サポート** | **+12.96%** | **+3.41〜+20.15%** |
| アゲハチョウ科寄主サポート | −5.17% | −9.44〜−1.75% |
| セセリチョウ科寄主サポート | +1.04% | −8.70〜+10.14% |

全454行のシロチョウ科結果も+11.95% [+3.54,+18.45]。正は予測改善、負は予測悪化であり、生物学的な正負の効果量ではない。5科の探索後に見いだした結果で、多重比較保護済みの確証的主張ではない。

### 種の入替わり・記録偏りで説明されるか

シロチョウ科の科内記録数と科内寄主目録充足度、さらに記録された33種キーのHellinger種構成を基準モデルに加えた。結果を見てから設けた機構候補の感度診断であり、独立確認ではない。

| 追加診断 | 予測MSE改善率 | 95%診断区間 |
|---|---:|---:|
| 科内記録量・目録充足度を追加 | +14.55% | +3.86〜+22.45% |
| **上記＋33種キーの構成を追加** | **+12.17%** | **+3.90〜+17.79%** |
| 種構成補正後、フランス報告行のみ（253行） | +0.17% | −1.24〜+1.69% |
| 種構成補正後、フランス報告行を除外（137行） | +12.55% | +1.18〜+20.49% |
| 種構成補正後、2017–2019年（208行） | +23.82% | −3.14〜+37.06% |
| 種構成補正後、2020–2022年（182行） | +11.66% | +0.39〜+20.64% |
| **種構成補正後、国を除外した転送（支持条件を満たす6か国を均等重み）** | **+0.94%** | **−9.87〜+9.76%** |

最後の区間は国ごとの固定予測誤差を再標本化した記述値。国の数が少なく、一般的な国際転送性能の確証にはならない。国を除外する際は同じH6も学習から除去した。

記述的な調整済みW係数は種構成補正後+0.0309／Wの1SD（H6クラスタ区間+0.0116〜+0.0502）。Wは流域出口に関連づけたモデル下水指標であり、植物や蝶が受けたNa/N/P/DON、排水比率、栄養塩の実測量ではない。都市化その他の交絡が残る。因果的な植物資源増加、実際の幼虫利用、繁殖改善を意味しない。

蝶構成を全454行のH6平均構成に固定した植物側の機会指標では+9.27%だが区間−1.21〜+18.16%であり、植物を介した媒介効果は確立していない。この標準構成自体も同じ資料に基づくため、独立予測試験とは呼ばない。

## 5. 全ネットワークへの下水効果は支持されない

地理制約付き置換を超えるリンク量全体に対するWの追加予測力は、主390行で−1.12% [−3.06,+0.57]、全454行で−0.61% [−3.17,+1.94]。シロチョウ科の選択された指標で見えた信号を、全ネットワークの増強や下水特有の生態系成立へ拡張しない。

## 数値・原本検証

- 5つの元ZIPを既存の署名SHA256と再照合。
- 2,808の元流域×期間×生物群IDに重複なし。保存行列の蝶・食草カウントを元JSONから全454行で再構築し、完全一致。
- 元の1,630 API応答のSHA256を再照合。
- 元解析の7テストと、新規8テストを実行。
- SciPy超幾何分布＋疎な辺の直接合計による独立計算の最大差は8.6×10^-10未満。
- NumPy正規方程式とscikit-learnの重み付きRidgeの予測差は6×10^-14未満。
- 元の+16.80246%の地理制約付き結果を再現してから追加診断を行った。

これらは独立した計算の確認であり、新しい生態学的サンプルや独立研究を追加したという意味ではない。
