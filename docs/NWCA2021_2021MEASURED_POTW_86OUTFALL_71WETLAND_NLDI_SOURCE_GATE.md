## Official network and technical meaning

- USGS [Network Linked Data Index](https://api.water.usgs.gov/docs/nldi/) (NLDI) v3 and NHDPlusV2 flowline directed network. Query position using official `/nldi/linked-data/comid/position?coords=POINT(lon lat)&f=json` (catchment assignment, not a stream contact measurement). In a separate API call, `/nldi/linked-data/hydrolocation?coords=POINT(lon lat)&f=json` returns a linear-ref hydrolocation (nearest stream within 200m or model raindrop trace otherwise); retain **distance between original location and returned stream/hydrolocation geometry** in metres. Treat the latter as **model-derived** when it is not a direct ≤200m snap. Do not classify a mere catchment match as actual wastewater delivery.
- Conservative **direct-flow candidate** requires a point-source and wetland **both within 200m of returned NHDPlusV2 flowline location**, distinct source and receiver COMIDs, with wetland COMID explicitly on the downstream **DM / DD** navigation set of the source COMID at an a priori **50 network-km maximum**. NLDI may include only whole NHDPlus reaches and must not be treated as an exact water transfer distance or contact with wetland vegetation. **Same COMID** is excluded from directed inference because the within-reach upstream order is unresolved without both hydrolocation measures. Network result must be backed by official USGS response source URL, SHA256 and returned COMIDs. Nav request always bounded at 50 km; no arbitrary large routing.
- **Sensitivity ONLY**, clearly model-assumed: both sites within 500m of NLDI modelled hydrolocation (200m strict source is primary), and catchment assignment without true hydrolocation, all separately reported. Do not use sensitivity to replace failed primary gate.
- Source-2026 registered outfall coordinates potentially substituted for true 2021 physical water release point, and NWCA 2021 plots may be **wetlands with no river connection**, at separate coastal/tidal channels or groundwater/sheetflow. Hydrolocation to a river centreline does not by itself prove effluent reached a wetland.
- NLDI official source documentation says COMID position query is a **catchment lookup**; DM traces downstream mainstem, DD includes diversions, flowline navigation returns **whole reaches**. These are meaningful network constraints but still not route-specific delivery of effluent to wetland ecosystems.
