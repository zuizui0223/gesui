## Two component definitions (new adversarial tests)
For each accepted plant species `s`, `g(s)` is the exact original accepted genus string, and published `F_s` the source EIV MOIST score. Define unweighted original-scorable-species `Fbar_g = mean(F_s | g(s)=g)`, **not** site-conditioned means.
- `F_between,H7 = mean(Fbar_{g(s)} | species s observed in H7-period and EIV N/F double scored)`.
- `F_within,H7 = mean(F_s - Fbar_{g(s)} | same eligible observed taxa)`.
- Assert every H7-period `F_between + F_within == original source community Plant_F_incidence` exactly (numerical tolerance).

Also report both joint H6 cluster descriptive coefficients scaled to each component's own 1 SD, design rank/condition, and in-sample residual partial associations.
