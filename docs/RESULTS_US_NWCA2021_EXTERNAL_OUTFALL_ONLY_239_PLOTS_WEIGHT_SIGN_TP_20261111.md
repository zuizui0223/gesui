# US 全国湿地239地点 × 真のExternal Outfall限定：下水への近さと植物多様性の符号は調査重みで反転

**2026-11-11／米国27州・32の州×生態地域／新しいSOURCE ONLY型検証、標準化植物指標、独立数値監査まで完了。** 以前の全Permitted Feature近接係数（調査重み付きH_ALL +0.18062、地点等重み−0.12043）を見た後で実施した**事後的な出典型訂正**であり、因果的な排水影響や確証的な再現性研究ではない。

## 1. なぜ訂正が必要か

EPA公式ECHO [ICIS-NPDES Discharge Points Summary](https://echo.epa.gov/tools/data-downloads/icis-npdes-discharge-points-download-summary) によると、`LATLONG_TYPE=Permitted Feature` は**外部放流口**だけを意味しない。`SUB_TYPE_DESC`には実際に`External Outfall`、`Internal Outfall`、`Influent Structure`、`Monitoring Well`、`Receiving Water (Ambient)`、`Land Application Site`、`Sum`、`Other`などが混在する。したがって先行研究の「下水放流口10km以内」は**一部の内部施設等を源として数えていた**可能性があった。

**生物応答を一切見ずにSOURCE先行で訂正：** 公式2026年11月8日更新NPDES登録地点ZIP、元のSHA256 `f0d1310b1c07085c42527e2ede5cf97ab83d517d50548b7dadb7621a44aa6160`、元の568 NWCA2021標準化湿地の原本SITE_ID+VISIT_NO、2021年に許可が存在した可能性のある日付条件、SIC4952またはNAICS221320、Permitted Feature座標を維持。外部放流口のサブタイプ `SUB_TYPE_DESC='External Outfall'` のみ追加し、同じNPDES許可・特徴番号・緯度経度への一対一結合を全58231行で確認。名前や植物結果で出典を選別しない。

## 3. 真の外部放流口×2021標準化植物の新しい比較

EPA NWCA2021の元の2021年確率標本、州・生態地域の同一層、植生タイプ、湿地水文タイプ、緯度を調整。下水登録外部放流口から**10km以内99湿地と20km以上140湿地、計239湿地、27州**。試験区当たり植物Shannon（`H_ALL`）、在来植物`H_NAT`、外来植物`H_ALIEN`、植生品質`FQAI`を元の実測値で比較。係数は「近接−遠隔」、標準化指数の元の尺度。元の2021年の真の排水曝露ではなく単なるSource位置関係。

| 指標 | EXO限定 β | 州クラスタ95%CI |
|---|---:|---:|
| **H_ALL地点等重み** | **−0.15183** | **[−0.28261,−0.02105]** |
| **H_ALL原NWCA調査面積重み付き** | **+0.14505** | **[−0.02806,+0.31816]** |
| H_NAT在来植物Shannon地点等重み | **−0.14141** | **[−0.25341,−0.02942]** |
| H_ALIEN外来植物Shannon地点等重み | −0.06417 | [−0.20533,+0.07699] |
| FQAI_ALL地点等重み | −0.99950 | [−2.63550,+0.63651] |
| FQAI_NAT地点等重み | −1.05529 | [−2.53855,+0.42796] |

**旧全Permitted Feature標本（240湿地）ではH_ALL面積重み付き+0.18062 [0.01038,0.35087] と区間が正にあったが、EXO限定すると +0.14505 [−0.02806,0.31816] となりゼロを含む。** 一方、地点等重みは −0.12043 [−0.25058,+0.00971] から −0.15183 [−0.28261,−0.02105] とより負方向へ移動。**調査重みで符号が逆転**する一方、登録された外部放流口の近くで植物多様性が普遍的に増えるという頑丈な正の相関は確認されない。

## 4. 調査面積重みと州別の感度

元の239地点のNWCA WGT_TP_COREは非常に不均等。Kish有効標本数は**239地点に対し60.42**、近接99地点では**24.12**、遠隔140地点では**37.09**。近接群の重み上位5地点だけで**36.4%**を占める。

| 元の239地点H_ALL、EXO限定 | 近接−遠隔 β | 95%CI |
|---|---:|---:|
| 元の設計重み | +0.14505 | [−0.02806,+0.31816] |
| 重み上位1%を上限に制限（事後的な感度） | +0.14336 | [−0.02987,+0.31659] |
| 重み上位5%を上限に制限（事後的な感度） | +0.09151 | [−0.08134,+0.26436] |

どの1州を除いても、地点等重みの係数は**27/27負**（範囲−0.17547〜−0.12257）、調査面積重みの係数は**27/27正**（範囲+0.07811〜+0.17131）。これは州1つによる偏りでなく、**推定対象（等地点・調査重みを使った湿地面積側）の違いと重みの強さ**を表す。ただしこの部分集合の単純WLSは、EPA完全複雑標本設計による正式な全国湿地面積推定量ではない。

## 5. 204地点の同じ湿地における実測TN/TP

元の499地点の水質・植生クオリティを維持してEXO近接定義を適用すると**204湿地（近接81・遠隔123）**。州・生態地域・湿地類型・緯度の固定効果調整後、元の現地**実測**TN (mgN/L)の対数差は+0.10767 [−0.11255,+0.32789]、TP (mgP/L)は**+0.24854 [＋0.00990,＋0.48717]**。これはTPが近接地点で高い方向という新しい**実測水質の肯定的な地理的相関**（倍率10^0.24854≈1.77）である。ただし実測TPが「下水由来」である保証がなく、放流口から湿地への水文的連結もない。**下水がリンを増やしたと断定しない。**

この204湿地のH_ALLについて、水質TN/TPを共変量にした近接−遠隔差は−0.18963 [−0.35878,−0.02048]。これは事後的な条件付き観察比較であり、媒介因果・毒性の検定として解釈できない。元の2011/2016/2021時系列の正のWLS係数を使って下水効果の正を普遍化することもできない。2016年の源側の許可年代を厳密化すると正負反転する（既存PR #51）。

## 6. 真の2021年外部放流口からの実排水データとの接続限界

既に実行済みの独立ソース検査では、実際のEPA FY2021＋FY2022 DMRから2021暦年の数値EXO報告と元の登録Source特徴IDを照合し、当初の近接128湿地のうち**26湿地**だけが、正確に同じ近接特徴番号の全窒素と全リン両方の数値報告を持っていた。先に固定した≥30湿地という栄養曝露比較ゲートに失敗。EXOの型を制限しても、この生物側不足が解消することはなく、新たな**実際のN/P排水による植生効果モデルは実行しない**。参考：[EPA FY2021/22 DMR SOURCE only Draft PR #50](https://github.com/zuizui0223/gesui/pull/50)。

**全球主線との接続：** 元の1,055港・42か国でのモデルWWpと全Plantaeの記録種数・記録件数の正の関係は再現可能（それぞれ+0.22884、+0.31556）。しかし50件に希薄化した植物種数では小さいWWp係数でCIはゼロをまたぎ、植物・動物・菌類のGBIF記録の共通の集中がある。今回の標準化された実測植生は、位置が登録放流口に近いだけでは**一貫した正の植物多様性応答を示さない**ことを、より正確なsource定義で示した。
