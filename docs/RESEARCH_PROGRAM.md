# 研究主線：Wastewater-mediated ecological reassembly

## 問い
都市化・農業・記録努力の影響を分離しても、**下水の放流先・量・処理段階が植物群集と水域の生態学的連結性に対応するか**。単に港が多い都市ほど植物記録が多いかではなく、受水環境を地理的に定義した比較を主検証とする。

### H1 — 上流／下流と植物群集（最優先）
同一流域の上流、下水放流口の下流、放流のない対照河川で、植物相の組成・富栄養性形質・外来率・時間的入れ替わりを比較する。水生植物、河岸陸生植物、内陸の陸生植物は曝露経路が異なるため別解析。生物記録0と非観測は分離する。

**下水曝露**を、(a) 施設数、(b) 発生・処理水量、(c) 排出口から受水河川を流れる経路、(d) 独立した実測N濃度と流量の積によるN負荷、に区別する。(a)・(b)を(d)と呼ばない。

### H2 — 栄養供給か都市化か
WWTP・WWp・受水N・農地N・市街地・人口・気候・土地利用・植物記録努力を別変数として、同じ流域または同じ島内で比較する。全植物を母集団とした応答を採用し、蝶の寄主候補だけに絞った選別を主解析にしない。国・流域・生物地理地域の階層差、空間自己相関、標本の重み付けを監査する。

### H3 — 下水が「回廊」になる条件
水生植物や水中を輸送される栄養塩は**下流方向の河川ネットワーク**に沿う。一方、河岸に生える陸生植物は河岸の生息地の配置と実際の植物記録に依存する。海上の島間のAIS航路・風・Circuitscapeはchochoへ残し、下水を海の移動抵抗面に混ぜない。

Omniscape/Circuitscapeで「下水沿いは低抵抗」を置く前に、(1)放流水が実際にその地点まで届く、(2)対象生物がその媒体に沿って移動・定着する、(3)通常の河川・道路・都市化を超える増分がある、の3つを検定する。河川の上下流方向が重要なら無方向の有効抵抗だけを使わない。

### H4 — 河口・沿岸とその他の分類群
河口や海へ直接放流される場所では、潮汐・海流・塩分・水質と藻類／水生植物／底生無脊椎動物の関係を別の受水生態系で検討する。植物の結果が支持されたら、植食性昆虫等の資源と群集の応答を接続。チョウの候補寄主の記録をそのままチョウ定着と見なさない。

## 検定の順序

1. HydroWASTE 58,502施設と HydroRIVERS の放流口・河道・下流接続をソース固定する。元論文では58,278が河川網に結合、224施設は小島・沿岸で海へ直接放流と推定。施設から推定放流口まで平均6.5±3.1km離れるため、近いだけで陸上植物への曝露と扱わない。
2. 全植物（種×地点×時期）、Ellenberg等の形質、観測レコード数と種数、帰化・在来の分類、植生の水生・陸生区分を、流域と時期に一致させた表にする。中欧のEllenberg Nは全球で測られた土壌Nと等置しない。
3. 上流／下流・非放流河川・同一市街化層での対照を事前に固定。農業N、人口、降水、土地被覆、流域、独立植物観測努力を同時に検証。
4. 負の対照：水文的に接続しない近傍地点、非放流河川、予測的に無関係な分類群。記録レベルと種レベルの2通りの希薄化、NoData、0/0標本、沿岸の位置ずれをチェックする。
5. 流域外・島外・期間外でベースライン予測に下水曝露を追加した増分を評価。**正の相関だけで栄養媒介や回廊を結論しない**。

## 現状
世界の港とモデル下水の相関、および欧州6島の植物記録構成の一部のみが解析済み。**直接受水河道の植物群集・流域外予測・水中N・多分類群検証は未実行**。研究スコープと初期仮説はこの文書で定義したが、新たな実測検定は行っていない。
