## Source-only strict taxa matching

- Exact original butterfly `accepted_name` canonical binomial, casefold normalized whitespace; GloBI source `Lepidoptera Name` or exact `sourceTaxonName` as specified in original metadata. DO NOT harmonize historic synonyms to modern accepted names silently or GBIF-key imputation. Preserve missing count of names separately.
- Only unique **binomial** original host-plant names, casefold and normalized whitespace; genus-only, species aggregates, hybrids, infraspecific, vernacular, and uncertain host names excluded (not reinterpreted as true nonhost).
- Original EIV file normalizes binomial names with strict exact match; N and F numeric and in their published valid ranges **N 1–9 / MOIST 1–12**, no x/NA/0 imputation. Ambiguous EIV duplicate-name conflicts on either N or MOIST excluded before looking at ecological effects.
- For each of the 290 accepted butterflies, original exact HOSTS edges to **same** original host plants with both NUTRI and MOIST numeric. Compute paired-host `N_paired` and `F_paired` using **identical underlying host taxa and equal species weights**, n_pairs, original found and unmatched host concept count, paired coverage, original HNS/F difference, potential double-score coverage quality. No source dynamic butterfly GBIF or wastewater values opened.
- Predeclared **SOURCE FEASIBILITY** threshold: at least **40** ACCEPTED alias-clean butterflies with >=1 exact paired-host species, spanning ≥**4** butterfly families. Treat species with only 1 source matched host as low-quality sensitivity (not automatically full coverage).

All source row counts and missingness to be retained.
