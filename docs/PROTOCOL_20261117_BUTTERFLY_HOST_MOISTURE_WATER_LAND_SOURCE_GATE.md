# 水陸の横経路：寄主水分嗜好の既存原本監査と同一観測単位への接続仕様（2026-11-17）

## 図の再解釈

ユーザーの図では縦方向が「点源の圧力 → 河川TP（実測） → 底生動物の状態」と「面源の圧力 → 植物の窒素嗜好 → 蝶の寄主窒素嗜好」、横方向の破線が新しく検定する水陸間対応を表す。**破線を一つの媒介・物質輸送経路として確定済みと読まない。** 水域・陸域のスケールや年次、記録の種類が異なると、単に共通のH7流域や栄養圧で相関するだけかもしれない。

とくに図下の「寄主の水分スコアを同じ手順で作れる」は、既存ソースの段階ではすでに実装されている。現mainの `results/20261115_sync/GESUI_303_HOST_NUTRIENT_SCORES.csv` 原本303蝶キーに `host_nutrient_mean`, **`host_moisture_mean`**, `host_light_mean` があり、Ellenberg型指標は植物の生育環境の嗜好である。MOISTは植物自身の窒素含有量や幼虫の栄養摂取、水際での産卵、湿地占有や下水からのN吸収の実測ではない。

## 試行前に把握している固定ソースの条件

- 現mainの303蝶キーには原本のACCEPTED分類と使用異名競合フラグがある。粗く空欄でない水分平均は188、N平均は190（非受理を含む）。厳密な`taxon_status==ACCEPTED` かつ実際に使用した別名の競合なしで両方の数値があるのは**180種**；水分スコアのみ184、Nのみ186。5科で受理された両スコアの数値種数：Lycaenidae 44 / Nymphalidae 85 / Hesperiidae 23 / Pieridae 18 / Papilionidae 10。
- 便宜的な湿潤指標 `host_moisture_mean >= 7` は**14/180種**、そのうちLycaenidae**2種**。この閾値で「湿地利用種／それ以外」へ二分する検定を主解析にしない。連続的なMOIST利用を事前固定し、必要に応じて水分嗜好の非線形性を感度解析とする。
- 既存の `trait_coverage` と `n_scored_hosts` は寄主Nの数値化を主体に作られた値で、MOISTとNUTRIが**各蝶の同一寄主植物**から計算されたことを自動的には保証しない。蝶レベルで両スコアがある180種をそのまま同一寄主ペア検定に流すのは禁止。元の寄主植物×種EIVスコア原本を復元し、EIV NとMOISTの両方に数値を持つ**同じ寄主植物集合**から二つの平均を再推定する必要がある。
- 植物側における真正EIV NとMOISTの共通EIV数値accepted speciesKeyは**3,722種**（先行ペア比較の原本ゲートを通過）。先行解析では植物NUTRIはMOIST一つを調整しても、蝶HNSのH6外予測に正の追加情報を持った。一方、MOISTをNUTRIに追加したH6外予測増分は+1.46%（記述区間に0含む）、もともと6形質同時コホートはSTOP。これは**蝶の寄主MOIST**の指標を実際に検定した結果ではなく、植物群集のMOISTであることを厳密に区別する。

## 次に行う本物の水陸接続検定：source/quality → 同じ流域 → 交互作用

1. **源形質の監査のみ**：main原303蝶と原454 H7×period（232 H7、90 H6）をハッシュで凍結。ACCEPTEDかつ異名競合なしでMOIST/NUTRIが両方数値の蝶の重複を明示、5科と未採点を記録。今回の原本源ゲートは**蝶数値の取得可能性**であり、湿地蝶の増減や下水生態を示す係数ではない。
2. **寄主種レベルの厳格ペア形質**：元の固定HOSTS寄主リストと原EIV v2/EIV sourceから、同じ寄主植物がNとMOISTとも数値を持つ場合だけN/Fを両方採点。寄主数、全寄主分母、欠測、地域寄主バイアスを出し、正しく測れた蝶集合に限定する。科間・科内のスコア違いを分離する。全対象蝶のGBIF source種キーの起源と元454 H7×period /232 H7 /90 H6の数を復元する。少数の14種高MOISTに後付けで閾値を当てない。
3. **同じH7×periodの種均等蝶群集**：NとMOISTの両スコア厳格対応蝶種集合を揃え、蝶群集の季節固定、記録種数/記録努力/寄主対応率/5科構成、期間、国×手法を調整し、H6外部留保と国内親H6内H7差を分けて評価。一次式：蝶群集の寄主MOIST `~` 上流地理／川辺連結性+蝶群集の寄主N+植物群集EIV MOIST/EIV N（共通植物種、共通記録努力）。河川が実際に現地測定されたTP/EQRと**同じ空間・同じ年の記録**であるサブセットを先にsource-onlyで確認する。
4. **最重要の横経路反証**：水域TP、EQR、河畔浸水/水分環境が蝶の寄主水分嗜好を予測する場合でも、低N/高Nと低MOIST/高MOISTの交絡、標高・湿地割合・降水・河川地理・歴史的な蝶種分布、国別記録努力の差を除去する。図の左上「下水点源P」と右側の「蝶寄主N/MOIST」を**直接因果的に接続する媒介SEMは禁止**。湿潤植物を使う蝶が記録されやすいことは下水に依存する証拠でも水中のPが蝶へ輸送された証拠でもない。
5. 生態作用のGO：同一年同一区間の受水実測N/P、有意義な非下水参照河川、現地寄主植物被度/真の幼虫利用・採卵、または羽化昆虫・河岸消費者の資源移動を確認する必要。既存のHNS/F（寄主生育地嗜好）は生物相互作用の*潜在的な環境指標*としてのみ扱う。
