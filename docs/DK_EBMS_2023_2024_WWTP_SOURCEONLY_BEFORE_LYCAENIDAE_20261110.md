## Fixed source-distance and geographic support gates

- Near primary is distance <=2km to closest qualifying source, secondary <=5km. Remote >=10km from every original **qualifying registered** outfall. 5–10km intermediate is neither near nor remote. Remote is not pollution-free.
- Primary: >=8 near <=2km and >=8 remote repeated-visit sites in >=3 original 1-degree geographic cells each containing both statuses.
- Secondary: >=12 near <=5km and >=12 remote repeated-visit sites in >=3 original 1-degree cells containing both statuses.
- If either radius does not meet its full criteria, STOP butterfly outcomes for that radius. No retuning or widening of radius after results. If both fail, archive source gap with zero butterfly outcomes read.

Then require >=6 site-year occurrence count visits per source band in both years and >=5 distinct sites per source band with Lycaenidae/Pieridae/Papilionidae recorded each year before family-response coefficient interpretation, else STOP with explicit sample gate failure.

## PRE-OUTCOME IMPLEMENTATION FIX 2026-11-10: site coordinate rounding (recorded before any butterfly Occurrence read)

The first full-Denmark 203-outfall Event-only replay [42757221092](https://github.com/zuizui0223/gesui/actions/runs/42757221092) successfully verified the original Denmark v1.4 archive (SHA256 2cc64ec...) and public 2022 EEA 203 outfalls. It counted 735 coordinate-defined source sites and **107** public sites meeting the protocol's 2023+2024 **>=2 distinct visit dates per year**. However, the implementation incorrectly added an undocumented *raw floating-point coordinate exact-equality* filter to the previously specified **five-decimal-rounded public site coordinate** identity. Just **9 of 107** passed that artificial raw-coordinate bit-for-bit requirement. Variation within the same 0.00001-degree rounded coordinate does not mean that the same public site has shifted by 500m; at Denmark latitude it is within about 1m. This was a QC implementation bug, not an ecology-informed threshold change.

The repair retains the predeclared five-decimal site identity and the exact original numeric 500m source coordinate uncertainty ceiling. Instead of requiring raw coordinates to be bit-for-bit identical, original within-rounded-bin scatter is calculated in metres and an extra guard rejects coordinate groups with scatter greater than 2m. Source-only preliminary computation, with **no butterfly species counts read**, showed that among the 107 repeated sites, 5km has 23 source-near vs 38 remote >=10km across exactly 3 shared country×1-degree cells, while 2km has 0 source-near. The 5km original gate is therefore potentially feasible and must be independently re-executed with an immutable new output before any butterfly response analysis. The original failed strict raw-float code and its 9-site output are retained for audit. No source radius, control radius, visit threshold, 1-degree group threshold or WWTP source membership was changed in this correction.

If the 5km gate passes independently, commit the 107-source-site membership and all original hashes, perform duplicate visit/parent-event audits, then stage the separate original Occurrence-based Lycaenidae test. Do not use 2km as a positive test if its 0 near sites remain unsupported; 5km indicates landscape proximity, not directed river exposure.
