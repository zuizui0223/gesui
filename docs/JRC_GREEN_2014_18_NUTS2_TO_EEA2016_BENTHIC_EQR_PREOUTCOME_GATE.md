# 2016年の標準化河川生物EQR × JRC GREEN 2014–18点源N/P：NUTS2地理・曝露SOURCE先行

**2026-11-11、全て事後的探索。** 2018/2022年の実測WWTP年排出N/P × EEA底生EQRの既知の予測改善結果が存在し、それらを見た後で2016年を選択した。独立年の事前登録・因果検証と称してはならない。旧2016年UWWTD実測負荷は取得できず、公式2019–2020 GPKGを独立検査しても**2016報告行ゼロ**。したがって本研究は**別の曝露尺度**、すなわちJRC GREEN 2014–18年平均の家庭排水＋産業排水を合算したモデル地域別点源N/P負荷を利用するのみである。

## 生態学的問い

> 生物学的な観測年が2016年である河川で、地域の家庭・産業由来のモデル点源窒素・リン負荷密度は、元の河川底生無脊椎動物EQRと対応するのか。2018/22年のWWTP上流の**実測負荷**に関する予測改善は別の測定対象として保持する。

国別のJRC PsN/PsP (44国)、NUTS2 PsN/PsP (337地域)は、JRC公式[2014–2018年平均MapServer](https://water.jrc.ec.europa.eu/arcgis/rest/services/inmap/Losses_to_water_MIS/MapServer)の国レイヤー3/32、NUTS2レイヤー4/33の全ObjectIDを取得、重複なし。N/Pとも337/337 NUTS2で数値が存在、336/337で正（残り1は実際のモデル0であり欠測ではない）。全2016 EEA底生13報告国とも国IDで重なる。元の71779河川流域レイヤー5/34は**件数のみ記録・原数値未取得**であり、代表流域を恣意的に選んだ解析をしない。

## 新しい独立の空間結合を結果の前に固定

- 2016年の元のEEA Waterbase Biology2026で、すでにEQRを読まずに確定した**2496底生無脊椎動物地点・13か国・49地理3°ブロック**。2016年同時の付着藻類2272地点・12か国は追加応答の可能性を保持する。魚類1055地点・3か国は国数不足で効果推定を行わない。
- 2016年のEU統計分類を同年に一致させるため、Eurostat GISCO公式[**NUTS_RG_01M_2016_4326_LEVL_2.geojson**](https://gisco-services.ec.europa.eu/distribution/v2/nuts/geojson/NUTS_RG_01M_2016_4326_LEVL_2.geojson)を原本SHA固定してWGS84点内包含で結合。NUTS2境界内を含む河川モニタリング地点のみ。境界線上や複数ポリゴン重複は曖昧（NA）とし、結果から任意に選ばない。1:1Mの簡略化境界は河道そのものではなく、境界から近い点の帰属に誤差がある可能性。
- JRC NUTS2の公式`cntrCode|Nuts2`とGISCOの`CNTR_CODE|NUTS_ID`を厳密一致させる。国ID・地域IDを推測して対応付けない。NUTS2の面積はGISCO面ポリゴンをEPSG:3035に投影してkm²で計算（緯度経度度²を面積と解釈しない）。2016年EEAの調査年が2014–18モデル平均に含まれることを明示。
- SRC-only門前条件：底生2016年**最低900地点**, **最低8か国**, **60独立NUTS2以上**, **15地理3°ブロック以上**が、正確なGISCO2016同年NUTS2×JRC GREEN両方のN/P値へ対応し、**最低5か国でNUTS2間にN/Pモデル排出負荷密度の変動がある**。一つでも不達なら2016年の生物EQR値を開かずSTOP。2016地域や近接条件を変更して正の関係を追わない。

## SOURCE通過後にのみ許される実測生物応答の探索的分析

元EEA河川底生の2016年元の`resultNormalisedEQRValue`（国別評価手順ごとの正規化生態学的健全度、種数や個体数ではない）を、事前固定した全てのSITE_ID×NUTS2へ結合。2000年代以降の現地観察でも、2016生物EQRに一切選別を行っていない2016ソース標本のみを使用。

- 元のNUTS2平均モデル点源強度を`log1p(PsN_t per km²)`、`log1p(PsP_t per km²)`に固定。PsN/PSPは家庭＋産業のモデル発生源であり2016の個別WWTP実測ではない。0は実際のモデル0のみ使用、NUTS2領域内に2016実排水がないとは主張しない。
- 主比較は2016底生河川EQRへの**年をそろえた観測関連**。ベースラインには緯度経度、国と国別EEA生物評価手法を含める（2018/2022実測WWTPモデルと地域曝露の粒度が異なるため係数やCV増分を厳密に直接比較しない）。モデル点源PまたはNを追加したときの3°地域ブロック5分割の予測MSE差を、先にSOURCE固定したブロックで評価。元NUTS2地域別サンプル数の不均衡は別途等NUTS2重みとクラスタ復元の記述的感度。**どの結果（正・負・ゼロ）も報告し、NとPのどちらか有意な一方だけを主結果にしない。**
- 事前に決めた偽相関診断は国単位/地域単位の集計の差、元のJRC PsN-PsP相関、同一NUTS2に多数の生物地点がある疑似反復、2016年の評価手法と国差（global biological condition indexではない）、農業・人口共変量不足。2016と2018、2022を同年のWWTP排出量で時系列回帰したと呼ばない。

**真正な下水由来栄養塩の生態学的効果が明らかになったという主張は行わない。** 既存のsPlotOpen, NWCA, JRC FileGDB CDF出力の失敗と、元の2018/2022 WWTP実測負荷の肯定的MSE改善はそのまま保持。`gesui/main`／`chocho`を変更・マージしない。Draft PRのみ。
