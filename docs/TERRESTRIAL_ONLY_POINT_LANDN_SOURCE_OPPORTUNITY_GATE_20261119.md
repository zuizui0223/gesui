# 2026-11-19｜陸域単独植物EIV-NUTRI対点源/陸N投入の事前SOURCE-only機会検査

既存の2018河川×2017–19陸域の共通水陸2×2は公式1:100万GISCO 2016で25 NUTS2・6か国のため正式SOURCE-STOPした。今回はその条件を緩めない**独立した陸域単独モジュールの機会監査**であり、生物NUTRIの数値や蝶HNSは読まない。元のSOURCE 451/454 H7×期間のEIV品質判定のうち2017–19年を固定し、元GBIFでリクエストした真正H7 WKT（original 2,808 facetsのSHA固定）を用い、2016 GISCO公式1:100万NUTS2のただ1地域に面積90%以上が含まれる流域を採用する。水に入るJRC GREEN 2014–18年平均の点源N（家庭＋産業）と、EMEP2015大気N沈着およびDAYCENT2010–19農地鉱質/有機N投入の原source269 NUTS2と地理コード完全一致させる。JRCの河川向け拡散源は陸植物への曝露とは扱わない。

**SOURCE検査基準（陸域のNUTRI値を開く前に固定）**：独立NUTS2>=55、国>=8、真正H6>=40、国内に3つ以上の共通NUTS2があり点源N密度と大気N沈着に双方変動のある国>=5、H6とNUTS2の結合した独立地理成分>=20、固定5foldに各4成分以上。どれか未達なら陸域側の点源/陸入力と植物NUTRIの生態比較は実施せずSOURCE-STOP。元の水陸共通2×2を見直さない。

結果を見る前の追加解析の機会を数えるのみ。もし陸域単独のSOURCEゲートが通っても、点源Nと植物NUTRIの地理的関連は実際の処理水が葉に届く物質経路ではない。主体は農地・都市化・気候・種の検出努力・属組成などの交絡と区別できない可能性が高い。元論文の証拠としては数値の独立地域外検証が別途必要であり、本sourceだけで結論を書き換えない。
