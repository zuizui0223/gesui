## Source-only algorithm, before reexamining EQR/plant/butterfly results

1. Read the original entire 938,544-reach SHX/DBF/SHP from publisher original ZIP only for authoritative native identifiers and segment geometries. Derive a source-only list of EEA stations and HydroWASTE outfall points sharing the *exact original HYRIV_ID*, and the corresponding next-downstream reach geometry.
2. For each unique same-reach receiver segment, use the next-downstream neighbor's original line endpoints to infer which endpoint of the receiver segment is downstream, by smallest projected endpoint distance. **No automatic assumption** about which array vertex is downstream. A receiver with no next-downstream neighbor, multipart geometry, or ambiguous endpoint is **indeterminate**.
3. Require inferred receiver downstream endpoint nearest downstream segment endpoint **≤500 m** and the other receiver endpoint's distance to the downstream segment ≥150 m greater. Require network endpoint separation >250 m. Record orientation and rejection frequencies before checking biological associations. Distances derived from WGS84 with locally metric equidistant azimuthal projection, not directly degrees.
4. For each same-reach original WWTP/station point, snap to that exact original river polyline. Require point-to-polyline distance **≤500 m** separately for both source outfall and receiving monitoring site. Project positions along original river polyline. Distances between positions need **≥500 m and ≥2× (sum of original station and outfall snapping offsets)** before labeling source **strictly upstream of station** or strictly downstream. Smaller separation is **unresolved**. Record raw local reach geodesic path metric and original point snapping offsets. No fabricated `WASTE_DIS` dilution, source quality or plant operating status.
5. Same-reach source status is classified as confirmed upstream, confirmed downstream, or indeterminate **per registered plant×site pair**, rather than per unique site without its candidate count. Never classify zero observations from a failed API/shape join as biological absence. Keep original source inventory as static.
6. Before rerunning any ecological regression, require at least **50 original station-years with valid position-ordered same-reach WWTP candidates**, ≥25 distinct EEA native site IDs, ≥5 countries, and ≥20 confirmed upstream source-site pairs if testing the added source pressure. If the original physical quality gate fails, keep a source-only report and do not fit an opportunistically chosen statistical alternative.
