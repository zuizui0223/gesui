# 南チロル93地点：植物Ellenberg栄養指標と蝶の属内HNSの独立個体数検証（2026-11-22）

## 要約と判定

**独立した調査地・個体数データでは、元のGBIF流域解析の「植物NUTRIが高いほど同属内のHNS高値種が相対的に優位」という正の関連は頑健に再現しなかった。** 土地利用を調整しないモデルでは方向が負、土地利用調整後は点推定が正に転じるものの区間は極めて広く、観測のなかった地点への予測改善は確認できない。さらに*Pieris*属を除外すると調整後点推定はほぼ1になる。**普遍的な栄養選別の確認ではなく、結果が土地利用調整と属構成に依存することを示す探索的検証**である。

元の[gesui Draft PR #138](https://github.com/zuizui0223/gesui/pull/138)で見つかったH7・H6のGBIF記録の正の係数を上書きしない。新しいデータは独立した蝶の**個体数**と植物群集由来の栄養嗜好（EIV N）だが、HNSの種別値だけは元のgesui採点表を再使用しており、形質スコア自体の完全独立再測定ではない。

## 原研究・出典・先行知見

原著：[Guariento et al. (2023), *Biodiversity and Conservation*, doi:10.1007/s10531-022-02498-3](https://doi.org/10.1007/s10531-022-02498-3)、Springer補足XLSX `10531_2022_2498_MOESM3_ESM.xlsx`。出版社の元バイトSHA256 `e0774f313c5e008e7d37cef7d20d9f822f1cc02d7d0ba9f0b3301d5a9cf9202c`。第三者の元XLSXはこのリポジトリに再配布しない。取得・シート監査は[Actions #45017500460](https://github.com/zuizui0223/gesui/actions/runs/45017500460) SUCCESS、種名・EIV N・HNSの適格性監査は[Actions #45017821749](https://github.com/zuizui0223/gesui/actions/runs/45017821749) SUCCESS。

原論文は**植物Ellenberg Nと蝶の寄主利用幅の正の関連（fourth-corner p=0.01）をすでに報告**。したがって広食性と栄養環境の単純な関係は「未発見の原理」として主張できない。今回の別の問いは**同属蝶種のHNS差が同地点の植物EIV Nと対応するか**である。これは原論文の既知の解析結果を追認したものではない。

## 仕様とモデル

効果推定前に[固定仕様](PROTOCOL_20261122_TYROL_INDEPENDENT_BUTTERFLY_NUTRIENT_SOURCE_GATE.md)をGitコミットし、[ソース照合コード](../analysis/20261122_butterfly_within_genus/tyrol93_source_gate.py)で93地点×10属の最低ゲートを通した。これは以前の主結果を知った後の**探索的設計**であり、事前登録や完全独立の確認試験とは呼ばない。

[独立解析コード](../analysis/20261122_butterfly_within_genus/tyrol93_independent_fit.py)は、同一site×butterfly-genus内で個体数を条件づけた多項ロジットを用い、種別のベースライン個体数を分け、植物EIV N（93地点で標準化）と同属HNS差の共通勾配を推定した。光、気温、標高、土地利用、調査年の感度を用意し、サイトクラスタ標準誤差を計算した。**93地点のそれぞれの調査年は一度だけ**であり、同一地点の時間的追跡でも種ごとに個体群を観測した長期系列でもない。定量的個体数を使うが、標準化調査でも種ごとの検出確率が完全に既知とは言えない。

数値モデル・CVが先に完了した**後**に追加した除外診断であり、確認的検定でも属別効果検定でもない。全10属を1属ずつ除外して**残った9属全体**で同じ2つのモデルを再推定。全て収束。

## 生態学上の判断

GBIFマクロでは、調整に敏感ながら正の属内記録対応があった。一方、南チロルの独立した種別個体数・植物EIV Nでは、調整で符号逆転、広い区間、未使用地点への予測悪化、*Pieris*の大きな寄与が揃った。したがって**広域で普遍的な同属種内栄養選別は支持されない**。必ずしも生態学的な効果が0とは言えず、測定地域・生息地勾配・同属種の構成・寄主スコアの誤差・モデルの検出力は異なる。

原論文の実証した栄養環境と広食性の関連が、同属内HNS選別を保証するわけではないことが重要。機構を強調するには、同地点での**真正の寄主植物種・生育量・幼虫の資源利用**と、調査努力を揃えた追跡が必要。**下水から植物・蝶への物質の直接移送は何も測っていない。** 本結果を下水汚染による栄養影響の因果説明に転用しない。
