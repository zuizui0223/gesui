# Source-only same-river, before/after WWTP monitoring station pairs — 2022 WISE6 TP

Date 2026-11-09. Designed **after** all 2022 WISE6 directed WWTP source vs TP broad-station prediction tests and their mostly negative results. This is a genuinely **POSTHOC new sampling contrast**, not preregistered validation of the prior WWTP P signal. Existing original results remain unchanged.

**Goal:** determine whether original 2022 WISE6 TP monitoring stations themselves can be paired **on the SAME downstream-directed HydroRIVERS path** closely enough to compare the *change* in real 2022 measured river TP across a qualifying WWTP outlet between original monitor reaches, without comparing unrelated catchments.

## Immutable sources, no TP magnitudes yet

- Previous directed official EEA WWTP 2022 source-only registry of **187** original 2022 TP monitoring stations with official country+siteID+scheme hashed IDs, **174** uniquely snapped within 500m of the HydroRIVERS Europe v1-derived network. Original source-only record at `results/lycaenidae_2022_measured_river_P_bridge/2022_WISE6_187_TP_STATIONS_DIRECTED_ORIGINAL_EEA_WWTP_SOURCE_ONLY_QC.json`. It includes TP dates/months, reach, snap, original reported source count/P/N strictly upstream or downstream placebo. It has **NO TP measured concentrations**. Do **not** open original 184-site numeric QC in the first pair search; stage A is independent of both WWTP source loads and water concentration magnitudes.
- Pinned independent third-party HydroRIVERS Europe GeoParquet SHA256 `5e6327c6dd34a81bd7768d840f25c0569d4361b7e078065a97214563bd01b32f`, URL `https://huggingface.co/datasets/cassini-team-todo/hydro-rivers-europe/resolve/d43804121071d6693ec545fa43c27addbd686cad/HydroRIVERS_v10_eu.geoparquet`. **Not independently verified against official HydroRIVERS shapefile**; no such verification implied.
- Original Hyriv path `NEXT_DOWN` and reach `LENGTH_KM`; original source station reach ID is authoritative only as a **source-based assignment**, not a known point-along-reach location. No interpolated position within reaches or fabricated along-stream distances.
- Same country **DE or AT** required for a pair in this first comparison. Cross-country same river pairs are reported separately as excluded; they are not assumed to share sampling methodology.
- A valid ordered potential pair is `siteU reach -> one or more NEXT_DOWN steps -> siteD reach`, strictly different reaches, and **sum of original full segment lengths traversed from the upstream reach start to downstream-reach start ≤50 km**, with minimum traversed segments **1**, no cycles, and full original directed graph available. This is an *approximate reach-length conservative route metric*, not measured exact distance between specific monitoring points. Reject sites with ambiguous or failed ≤500m original snap. Original sample-date design is ≥4 dated TP events over ≥3 months per site from earlier source-only gate; no TP values, concentrations or absolute differences inspected.
- Stage A inventory includes **ALL possible directed same-country station pairs** and explicit reach lengths/IDs, source-only upstream P count difference **for diagnostics only**, never claimed as proof of an outlet between stations. Source exposure counts are truncated at 50km; differences may arise from upstream-window trimming, tributary inputs or same-reach unknown order.
- To allow stage B exact WWTP intervening-source reconstruction: require **≥10 site-disjoint potential pairs (without reusing stations)** across **both countries (≥3 disjoint pairs each)** and ≥**4 original country×2° geography blocks**. For reproducible support, greedy pair order is shortest original route then SHA256 of station hashes; pair selection never looks at TP numeric values. Freeze full candidate panel, total available disjoint support, country/2° diversity *before* any new water chemistry modeling.
- If raw same-path station pairs cannot support stage B, **STOP** and do not expand maximum 50km to rescue count.

## Stage B — conditional, actual outlet *between* station reaches

Only if stage-A above passes: query original official 2022 WWTP 5,492 both-measured-positive N/P facility rows/24,416 discharge points and one-FW-outlet matching, hydrologically snap original sources within 500m to the pinned river, and tag each candidate station pair with actual WWTP origin reach lying on the **strict internal reach path after upstream-monitor reach and before downstream-monitor reach**. Same upstream reach and same downstream reach excluded from "intervening" because original along-reach ordering is unknown. A source on a tributary joining between monitor reaches is a **separate predeclared secondary set**, not a source located on the exact shared trunk; these can be reconstructed by graph routing if necessary. If ambiguity, label unknown not zero. For a no-source comparator, zero qualified original EEA registered outlets on *both* exact intervening trunk and any branch reaching the downstream station within original 50km, depending on registered outlet completeness; record both definitions distinctly.
- Require **≥8 disjoint pairs** with at least one strictly intervening verified original source, **≥8 disjoint pairs** with no such source, 2 countries and ≥4 original 2° blocks, no site reused. If insufficient, STOP before any water TP before/after contrast. The 8/8 gate is a *new* exploratory source feasibility criterion, not an altered threshold from the prior 171 station-sample study.
- Stage B cohort frozen before inspecting numeric WISE6 TP concentration within a pair. If eligible, original pair-year effect defined as log1p(downstream TP mg P/L)−log1p(upstream TP mg P/L), with observed 2022 site TP median-of-daily-median strict original LOQ/date QC. Compare source-intervened versus same-river no-registered-source pairs, adjust upstream drainage/flow/country and paired river/catchment structure; uncertainty clustered by distinct river corridors/2° blocks. Downstream water TP relative to upstream is not necessarily causally driven by WWTP because tributaries, geology, phosphorus retention and local agriculture matter.

## Scientific limits

Even a supported source-to-river TP before/after difference **cannot** demonstrate adult Lycaenidae protein/sodium puddling, larval survival or wastewater benefit. Neither iNaturalist photographed butterfly-family proportions nor WWTP annual reported P loads are directly measured at butterfly substrate surfaces.

Report successful sampling source recovery, negative/no-pair support and true WWTP path support without selecting based on concentration effect sizes. Preserve original aquatic benthic EQR positive predictive results, 2021–2023 butterfly/photo source geographical confounding and `chocho` 22/25 introduced-host potential resource geographical expansion independently.
