# 2026-11-17 frozen prospective-for-new-covariate, *posthoc-study* model: common-site 2018 bank habitat and benthic EQR

This design was written after the RZ2018 source-only pilot 14/28 GO, **before** the full 2639 source outcome support was known and before reading the numeric EQR values **for this new bank habitat cohort**. However the original 2018 EQR annual predictor associations (PR17) are already known, so this is **not an independent confirmatory preregistration**.

### Primary same physical water-station source and new terrestrial predictor
- Original one exact 2018 `site_key` join (original official fixed source n2639; original 2018 numeric EQR n2634, no imputation), original fixed original geographical fold 1..5 (no new splits based on terrestrial outcome), country, assessment method, original actual 2018 WWTP reported annual *measured* P/N mass upstream and hydrologic downstream placebo, logQ/area/lat/lon; see original PR17.
- 2018 official EEA Riparian Zones status per exact station center in EPSG3035 in near 0–250m and far 250–500m. Class-coded Level1 `CODE_1_18` over classified polygons, min 0.5ha MMU, 10m MMW. `3` woodland/forest, `4` grassland, `5` heath/scrub, `7` wetland **vegetated-natural class prespecified**. Note this classification mixes anthropogenic management and natural habitats; never literal leaf biomass. `8` water bodies excluded from **terrestrial fraction denominator**, `1` built/urban and `2` cropland covariate. Other original codes retained in denominator rather than labeled natural. Both original annuli must have >=70% classified coverage, no NoData imputation; at least 200 sites,6 countries,10 3deg source regions,20 source-positive sites. Parent original 2018 sample EQR source source-quality eligibility unchanged; report full denominator and selection/missingness by original up-source eligibility, country/method and region.
- Per ring, define `T = sum(classified polygon area CODE_1 in {1,..,10} EXCEPT 8)` (area in m²); required T>0 and >=10% full-circle area. `NatNear = area_{3,4,5,7}/T_near`; `NatFar = area_{3,4,5,7}/T_far`; `DeltaNat = NatNear - NatFar`. These are mapped terrestrial **habitat composition** proxies, NOT direct 2018 changes, ecological service, riparian hydraulic transport or plant production.

### New model comparison, source-year and fold frozen
- 2018 benthic normalized EQR response as provided by separate original EEA source. Original reference model `B = original 2018 PR17 hydrogeo+country+country-method`; add `NatFar`, `FarBuilt`, `FarCrop` to define landscape-adjusted `L` (train-only standardization, original Ridge alpha10).
- **Primary ecological predictive test:** `L→L+DeltaNat`, original 5fold fixed geographical-region-out MSE gain. Positive improvement suggests recorded river-near land habitat contains predictive information about aquatic community condition beyond wider 250–500m context; not a causal vegetation→stream biological mechanism.
- **Source-specific environmental-context test:** `L→L+upstream_reported_2018_P_tons`, then `L+upP→L+upP+DeltaNat` and reciprocal `L+DeltaNat→L+DeltaNat+upP`. Compare upstream P versus downstream P source as negative-control predictor on same site sample and exact observed EQR, but don't interpret the placebo alone as causal direction.
- **Interaction hypothesis** (secondary, only if both main predictors supported, predeclared now): `L+upP+DeltaNat→+upP×DeltaNat`; distinguish source × riverbank context modification from covariate synergy and preserve all nulls. Treat interaction effect as observational and exploratory.
- Original N and P are highly correlated in WWTP reports, so N-vs-P chemical specificity cannot be claimed. N additional reported load is a secondary collinearity stress only, no new nutrient-specific mechanism inference. No ecological SEM or river→terrestrial resource transfer claim.
- Use **train-only standardization**, existing original 5 fixed spatial folds, and report country/region-only external transport, nulls, sensitivity to no-source-report zeros, and descriptive fixed-error uncertainty (not CI from independent trials). If fixed original folds become invalid under 2018 RZ mapping, source model STOP, no ad hoc grouping change to rescue.

### Key alternative explanations
River naturalness/geomorphology and land use may jointly determine WWTP siting, habitat cover and EQR; this cross-sectional 2018 model does NOT identify wastewater-induced vegetation, biologically observed aquatic emergence, spider trophic subsidy, butterfly local larval feeding or an ecosystem service benefit. Need physical bank flow/exposure and true trophic responses for that manuscript. A strong within-water source prediction plus habitat context is a narrower environmental mosaic question.

This study is a new posthoc extension of existing source and PR17 EQR, not a new independent validation; preserve full source outcomes and old original source STOPs.
