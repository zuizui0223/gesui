# 下水関連地理×蝶5科の寄主HNS：元speciesKeyまで戻した科内マクロ解析

**2026-11-15 / Draft・事後探索・観測記録の組成、非因果 / 未査読**

## 結論

**同じ欧州232 H7流域・454 H7×2期間のもと、静的モデル下水関連地理指標Wと、シジミチョウ科（Lycaenidae）内の既知幼虫寄主植物の好窒素性（HNS）で要約したGBIF記録組成に、正の条件付き関連がある。** 科別記録数・記録種数・得点対応率を追加調整し、真正H6流域を留保した予測でも関連が残る。ただし**国丸ごと留保の転送は不確実**、また**記録済み寄主の未数値スコアの範囲を最悪方向に割り当てるとβの符号が逆転しうる**。下水による葉N・幼虫摂食・蝶の豊富さ・成虫吸塩・腐肉利用・適応・生態系サービスの実証ではない。

## Original-source gate and design

- 真正原本：従来の[GitHub Actions #43593227162](https://github.com/zuizui0223/gesui/actions/runs/43593227162)、保存アーティファクトID **14113695873** に含まれる GBIF 234 H7×2期間×6 facet＝**2,808 facet** の JSON。展開したSOURCE JSONのSHA256 **251f8514684fe8ea62d94ddc8c6eeefb59976471d84d7389b682aff6637144e4** を固定して再実行した。中身は直接のソース別 occurrence count であり、個体数・繁殖数ではない。
- 既存303 taxa fixed HNS score table SHA256 **00c1a36a9237a3d1a6d77334aa8baa5dc8b329a49925c2e31f033fa2d302ecdb**。受理種・実使用名の衝突なし・数値HNSがある**186 speciesKey**のみ平均を計算。117欠測・未受理はゼロにしない。
- 同一比較の元パネル SHA256 **1296d1ded7f1ee185854cad6d1ece1dbb1f94b4e2f48856c8c487a3f3d002fca**。**454 H7×period / 232 H7 / 90真正H6 / 15 EEA国ラベル**。5科合計のGBIF元記録 **4,400,147**、speciesKey付 **4,318,269**。454行すべてで元HNS、科の記録比率、科間・科内HNSの再現誤差が数値許容値内。科内成分を5科に分解した原係数の加算誤差は約2.8e−17。
- 全流域の科別成分モデルはPR #94と同じ H6均等WLS、静的モデルWを+1 SD、流量・土地利用・面積・国×評価法・期間・EEA/GBIF記録努力とHNS得点完全性を調整した。90真正H6クラスタの正規近似95%区間。真正H6を5foldごとに完全留保するRidge10で追加WのH6均等MSE改善を検証（2000回の固定予測残差H6再標本化による**記述95%区間**、モデル再学習の不確実性ではない）。
- 各科の**内部平均HNS**は、元の当該科で「スコア付き10記録以上、2種以上、当該科全記録の70%以上がスコア付き」を満たすH7×periodのみ（支持を確認してから検定する事後コホート）で計算。国丸ごとの留保は検証国の真正H6親流域を学習からも除外した。6評価国（FR, HR, IT, LT, NL, NO）を同等の重みで集計する。これは6独立研究のメタ解析ではない。

## 4. 選択・種影響・欠測の感度解析（すべて事後）

### シジミチョウ科の1種除外・科別記録努力

- 固定した同一426行で数値HNSのある**47種それぞれを1種ずつ除外**。全47条件でβが正（範囲 +0.08764〜+0.17980）、それぞれの記述95%区間の下限もゼロより上。これらは47の独立検証ではない。
- 科のスコア付き記録数log、スコア付き種数log、当該科のスコア対応率を追加すると β **+0.11937 [+0.04317,+0.19556]**、H6外挿W追加改善 **+13.62% [+2.09,+23.34]**。国丸ごと留保は **+10.42% [−10.51,+21.00]** でゼロを含む。追加する科の記録数は曝露の結果でもあり得るので、**調整後βを「直接効果」と呼ばない**。
- 1種除外で最も係数を変化させるのは Polyommatus icarus （除くとβが+0.0593増）、Cacyreus marshalli（除くとβが−0.03285減）など。観測後に選んだ高影響3種を同時除去しても、β **+0.15515 [+0.07675,+0.23356]**、H6外挿 **+14.64% [+4.56,+23.25]**。後付けストレステストであり選択された種を主要機構と同定していない。

### **最も重要な限界：寄主HNSスコアの誤差**

数値スコア付きシジミ47種について、記録された寄主の未数値Nを元の種別下限／上限の内側で、W傾きが最小または最大になるよう各種別に割り当てた固定デザインで、βは **−0.08590〜+0.31923** を取り得る。**ゼロをまたぐ**。これは95%CIでも事象の確率でもない。もともと数値スコアがない117 speciesKeyや、報告自体のない寄主を補った範囲ではない。

他の科も、既存の支持と欠測に依存し、H6・国ごとの予測改善は均一ではない。HesperiidaeとPieridaeの一部speciesKeyではhost-bound sourceが欠け、同じ範囲を計算できない場合がある。**計算不可＝変動なし**と扱わない。

## 生態学的解釈とパス解析へのルール

支持されるのは、下水関連**地理指標**Wと**既知寄主植物の栄養生育地適性で重み付けした蝶記録の種組成**が、シジミチョウ科内でも関連すること。Wと都市土地利用は元データでρ≈+0.78。自然の河岸・都市園芸地・高山地・記録量・空間気候・市街地の種プールが交絡する。

**未識別の機構は別分岐**：
1. 排水負荷 → 局所土壌水分／葉N／寄主被度 → 実際の幼虫摂食・密度 → 変動；
2. 局所湿地・塩類／腐肉のNa・有機N → 成虫の種×性ごとの吸水・吸汁／行動 → 集積；
3. 水生生産 → 羽化昆虫バイオマス → 河畔捕食者。EQRは羽化量ではない。

同じ454流域表には、処理水が幼虫寄主・成虫ミネラルへ届いた**実測化学経路がない**。下水→寄主→シジミチョウの媒介パス解析・因果SEMを適合させるのは禁止。実測地理源を分けた放流口近傍比較、葉・根圏と成虫行動、独立施設の反復が必要。
