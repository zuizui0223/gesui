## 学術的な意味

**実際に支持される横方向：陸域の植物相 ↔ 陸域の蝶類既知寄主の生育地適性**。Nと水分の指標を同じ植物／同じ蝶種集合に揃えても、同じH7の記録組成は植物―植食者で水分環境上の対応を示し、別の真正親流域・別の国に外挿できる。元GBIF出現記録の空間共変動であり、植物被度やその流域での実際の幼虫摂食・蝶の個体数ではない。植物EIVと寄主EIVは**同一EIV資料**から算出したため、独立の水分実測や生物間相互作用の強さの証拠ではなく、種組成を媒介した機能的な生育地対応の記述。

**支持されない横方向：水域底生EQR → 蝶の寄主F**。同じH7地理・期間の実測EQRを入れてもH6外予測の増分はほぼ0、国外へ移ると負。元216流域の期間変化でもEQRや植物Fと蝶寄主Fの増減は連動しない。したがって提示図の「底生動物EQR⇒蝶寄主栄養／水分嗜好」という破線を機構経路として確定するのは不適切。これは真の水陸連結が生態学的に存在しないことではなく、特定の粗い広域指標・期間で**水生群集の状態から蝶の潜在寄主環境指標への追加予測を支持しない**結果。

**下水圧との関係**：元Wはあくまでモデル化した静的下水地理・流域環境の代理であり、同一河畔に届けられた下水由来N/P実濃度ではない。蝶寄主Fへの独立追加説明は不足。元オーストリア2022年同一水域68/67地点の上流報告N/Pと実測TP/底生EQRに関する肯定的な予測結果は**水域側**の別地理・別サンプリング単位であり、元欧州447 H7×期間の蝶hostFに直接混ぜない。先行フランス2018/22同一現地TP–I2M2も別の水域pop。下水が河川のPと生物状態に関係することと、水陸間の栄養輸送・植物・蝶への依存は別の問いである。

**一本化判定**：「人為的な点源・面源圧はどの生物区画まで予測でき、どこで結び付きが切れるか」というコンパートメント選別の観測的多層研究の一部としては利用可能。点源下水が実際に水陸の共通食物網を変えたという媒介論文にはNO-GO。次に必要なのは本当に河岸の侵水・地下水接続・土壌や葉N/P・現地寄主植物の資源量や蝶の幼虫摂食等を、**同じ上流・下流と対照河川、同じ年・同じ生息域**で測ること。現行Austria67の自然土地被覆の2022 Sentinel2河岸NDVI先行source-smoke 5/10<6/10はSTOPのまま維持、RiverATLASの上流域農地等0/67、上流50km河道source 59/67<60もSTOP。
