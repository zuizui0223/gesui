# 2026-11-19｜ROSEAU汚泥の施用先「候補」自治体とフランスH7：2018年のみの地理的機会スクリーニング

**独立した生態解析ではない。** 2017–22年の政府ROSEAU元汚泥CSV、各年の歴史的INSEE COG照合で130自治体コードが候補になった（[元source-only Action #44465289468](https://github.com/zuizui0223/gesui/actions/runs/44465289468)）。ただしこれらは**実施用の圃場／日／自治体別の施用量を直接記録しない**。本比較は自治体位置と植物の元H7流域が地理的に重なるかを調べる、**野外調査候補の抽出用GISスクリーニング**に限定する。

## 元のハード条件と変更しない判断
- 元2018年候補は72自治体（2017–22年全候補130自治体の部分集合）。**歴史2018年の行政境界をこの72にだけ適用する。** 2019–22の候補コードを2018境界に当てて都合よく補完しない。
- 2018年の歴史的自治体ポリゴンは [Etalab / data.gouv.fr行政境界2018年・communes-50m.geojson.gz](https://etalab-datasets.geo.data.gouv.fr/contours-administratifs/2018/geojson/communes-50m.geojson.gz) を利用。これは2018年行政単位の公開境界の**一般化された形状**であり、圃場の座標ではない。元URL・元ZIP/GeoJSON SHA・元行政コード名を保存。コードが見つからない場合は歴史的合併・境界/収録の不一致として記録し、未施用としない。
- 元植物H7は、2017–2019年の元454 H7×期間から451/454 EIV品質可否（**形質スコアは非読取**）を照合した適格H7だけ。地理の元WKTは2014/11ではなく2026-11-14に元GBIFクエリで使った[2808 source facets成果物](https://github.com/zuizui0223/gesui/actions/runs/43593227162)をSHA固定で復元。FRの元countryラベルを持つsource-only流域だけを対象にする。ここで得るFRのH7はフランス水域実測139 H7×期間の**共有72 H7と自動的には同じでない**。
- 実際のH7と自治体ポリゴンの空間交差をLambert-93/EPSG3035で計算。自治体の部分がH7を横切る場合は交差面積ha、自治体面積の比、H7面積の比を保存。1ha未満など境界generalizationによる極小重複を区別し、0面積の点接触を施用候補地点の重複としない。結果の数値を見てGIS境界や閾値を変更しない。
- 主な出力は、①正の面積交差を持つ歴史2018年INSEE候補自治体数、②FR品質適格H7のうち自治体と面積交差を持つ数、③真正H6親流域、④どの時期の記録があるか、⑤元境界や元WKTの品質である。保守的な参考閾値は自治体との交差面積10ha以上とし、0ha/1ha〜10ha/10ha以上を並列報告する。**どの値も汚泥施用による曝露を表さない**。
- このSOURCE-only機会スクリーニングが成功しても、事前の「実圃場施用履歴を持たない限り生物処理モデルはSOURCE-STOP」を解除しない。未記載自治体を汚泥施用ゼロ対照にしない。汚泥正値のSTEU年間合計tMSを自治体やH7へ割り振らない。

## 科学的な次の意思決定
H7との候補地理の重なりが実在すれば、当該元ROSEAUの処理場SANDREコードと対応する行政DDT(M)のSILLAGE「bilan d'épandage」**実施用圃場・日時・実施量**への合法的なアクセス・共同研究照会候補に使える。フランスの1998年1月8日省令第20条は、生産者が実施用データをVERSEAU/SILLAGEへ報告することを求めるが、これが**公開されているという意味ではない**。[公的法令](https://www.legifrance.gouv.fr/loda/article_lc/LEGIARTI000042419149)。元のマクロ論文の水陸2×2やJRCの独立source不足を改善したことにはならない。

**植物NUTRI、蝶HNS、河川EQRをこのスクリプトで一切読み込まない。mainおよび草稿PR124、旧STOPのPR125/126/128は未変更。**
