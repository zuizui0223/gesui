# EPA 3期の分類群×機能形質モデル：州・流域完全留保、正則化、未知分類群の反証（2026-11-15）

## 前提と判定基準

既存[PR #99](https://github.com/zuizui0223/gesui/pull/99)で得られた「元の同時観測 EPA EPT TAXA_ID 構成は、同じEPT目内の固着習性CNと河床埋没度XEMBEDの交互作用を追加すると真正HUC8未観測サイトでわずかに予測改善する」という事後探索結果を、**より厳しい州・流域の二重留保**で反証する。元PR #99の正負/標本選択を変更しない。

これは元PR #83・#98と同一の実測EPA個体カウント。州をホールドアウトしても元原データの別実験ではない。観測下水由来TN/TPを特定していない。河床埋没度は下水処理場排水の代理とは限らない。

## 元データの再構築と原本ゲート

真正EPA NRSA2008–09/2013–14/2018–19の元の署名・source-QA済みの事前sourceスクリプトを無改変で使用。元の200個体分類群品質標本 n2209から、「個体/分類群のEPA公式HABIT固着習性コードがそれぞれ80%以上既知、既知3分類群以上、観察EPT10個体以上」の既存PR #98の**事後**厳格条件を使用する。原本 expected **2008 n377/313HUC8/44州、2013 n767/526/47州、2018 n624/423/46州**、以前のsite×taxon count-CWM照合が不一致なら停止。元の元データ・真正SHAは[PR #98の解析コード](../analysis/20261115_ept_fourthcorner/fourthcorner.py)を参照。

新しい出力は、同じ元分類群名簿/形質で、訓練地点に一度も出ない分類群について推定値を極小確率として扱うことを区別し、**評価用の結果から意図的に消さない**。

## 新しい保持分割

- 同一調査期に存在する州を、元の州ごとの適格地点数が均衡するよう**決定論的に5つの州ブロック**に分割（n大順、州コード文字列でタイブレーク、少数foldへ貪欲配分）。同じ州が訓練・検証に跨らない。
- 検証州に含まれる**あらゆるHUC8は他州の訓練標本からも除外**する。HUC跨州の場合にも共有流域はゼロ。
- 元の調査期ごとに独立して5fold。新検証は州レベルの未知地域移植であって、3調査期をまたぐモデル移植ではない。調査期全体留保は先行PR #83, #98で別の予測量を検証済みだが、このPRでは**混同しない**。
- 折ごとの訓練N/州/流域数・purge除外N・未知分類群の情報を必須記録。独立HUC8 70未満などの支持ゲートに失敗した場合は結果を捏造しない。

## モデルと固定した頑健性パラメータ

先行[PR #99の厳密な条件付き多項分類群構成モデル](../analysis/20261115_joint_trait_env/joint_multinomial.py)を**無改変**で再利用。各分類群のsource ID・EPT目・EPA HABIT CN形質、河床埋没度・実測河川TN/TP・河川/河床環境・eco9・地理・季節を固定し、「XEMBED×同目内中心化した固着習性」1項の有無のみ比較。

正則化L2係数は、旧PR99 **0.025** とそれを挟む **0.005／0.100** の計3個を、当該データの結果を確認する前の固定感度グリッドとして全表示。州留保に最適なλを選んで**成功したモデルだけ報告しない**。train-only標準化・訓練州/流域に基づく分類群基準組成を適用。事後の複数モデル比較で補正していない。

## 2つの結果量を混同しない

**Primary：全得点可能分類群の条件付き交差エントロピー**
- 各州ブロックの真正元標本個体記録組成と、分類群出現を等重みした組成の両方を評価。訓練標本には現れない分類群も**テスト側に保持**する（訓練のみで推定したごく小さい事前確率となる）。
- HUC8均等の保持log-loss差（基礎M0−交互作用M1、単位nats/site）と保持MSEではなくCE減少率[%]を報告。
- 固定した予測誤差に対する真正HUC8の2000再標本化の**記述的95%**。正則化選択・データ生成過程・州間ばらつきの完全推測を反映しない。

**Secondary：訓練で観測された共通分類群に条件づけたlog-loss**
- 各ブロックの訓練で1度以上観測された元分類群だけを共通集合として採用し、**検証地点のその集合に属する記録割合で正規化**して対比する。同じ元sourceでも新規分類群は予測評価から明示的に除外されるため、必ず**新規分類群割合と該当地点数**を対として報告。次の生態研究の外挿主張にはprimaryが優先。
- 全結果について元の厳格EPA地点数と、unknown taxaの除外を伴う条件付き結果を別名で保存。両者の同じ変数を『改善』だけで統合しない。

## 生態学的解釈ルール（先に固定）

- **支持**：州＋HUC8留保で主要な3期すべて、元のλ=0.025、分類群出現等重みの保持CE改善区間が正で、交互作用係数が全fold負。他λでの異質性も明示して頑健性を評価。
- **不確実**：州留保全体で区間がゼロを含む／一部で負に転じる／未知分類群の比率が高く、共通分類群条件付けでしか改善しない。元のPR99のHUC8留保結果はそのまま残すが地域一般化を下方修正する。
- **反証**：旧HUC8のみの結果と対立し、多数の州ブロックで改善が負、負の交互作用も維持できない。未調整のモデル結果を変えず、「群集平均に留まる/地域依存」の解釈へ格下げ。
- どの結果でも「下水が引き起こした適応進化・種絶滅・水域→陸域栄養フラックス」とは呼ばない。
