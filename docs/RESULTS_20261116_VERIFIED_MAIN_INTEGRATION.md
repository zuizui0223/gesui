## 同時に採用すべき否定・不確実性・STOP

- **水→植物→蝶の因果的な連結は未確認。** 元454 H7で水域EQR―蝶HNS残差相関r=−0.1300 [−0.3024,+0.0579]、ゼロを含む。EEA監視局と陸域GBIFは必ずしも同じ河岸位置ではない。
- **時間の同期は確認されず。** 元219反復H7/86 H6におけるΔ植物NUTRI→Δ蝶種均等HNS β=+0.0039 [−0.0227,+0.0305]、H6外予測増分−0.70% [−4.16,+3.10]。静的Wから時間効果は識別できない。
- **同一H6内のW効果は不確実。** 新183 H7でW→植物N β+0.0509 [−0.0183,+0.1202]、植物N調整後W→蝶HNS β+0.0331 [−0.0118,+0.0780]。Wはモデル排水関連位置/量proxyであり、河岸の実際の処理水N濃度・流入質量ではない。
- **属内での種特有のNUTRI選別は未確認。** 全4,011植物種のNUTRIラベル入替p=0.0012だったが、同属内ラベルのみ入替p=0.6864。属平均をモデルへ入れた後の属内成分による追加標本内SSE改善はわずか0.193%。属・系統地理的プールを明示。
- **新10 H6への独立ペア予測、主指標は不確実。** 元30 H6を学習、新10 H6を検証した主の蝶種均等HNSのMSE改善+36.8% [−32.2,+61.3]はゼロを含む。副次の記録重みは+26.5% [18.6,35.6]だが10ペア固定誤差の記述区間。
- すべての植物EIV6形質を同じ植物種集合で同時比較する原sourceは**41 H7×期間/16 H6**で、固定100 H7×期間/40 H6に届かず**STOP**。個別5組の結果でこの制限を置き換えない。
- 米国のEPTは河床物理特性XEMBEDであり、欧州蝶は排水関連地理W／植物EIVの生育地嗜好。**共通の下水栄養曝露効果量ではない**。単純平均した「下水メタ解析」は不適切。

## 次の検証の優先順位

**元の受水域に実際に届いた下水由来栄養塩曝露を確認する source-only gate** が優先。EEAの年別報告施設ごとのN/P排出質量、河道・距離・流量／希釈、真のEEA測定地点と植物／蝶GBIF元位置・期間を一致させる。初めに各地点の地理・時刻・観測値の有無を完全に検査し、結果を見ずに比較候補数を固定する。下水由来を識別できない場合は、既存の植物―蝶の属レベル栄養嗜好共変動を**下水の効果**と記述しない。
