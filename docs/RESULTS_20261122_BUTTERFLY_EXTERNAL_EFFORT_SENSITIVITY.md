# 蝶の属内栄養対応：焦点蝶の記録を除いた努力代理と親流域外予測の追加診断

2026-11-22。**探索的・事後的な感度解析**。新しい独立標本ではない。Draft PR #138 の元の353比較層・34 H6・29蝶属・96種を一切変更しない。

## 結論

**元の13変数モデルの OR 1.413 は、記録から計算した調整変数への依存が大きい。** 蝶5科以外のAnimaliaの記録件数を使った場合は OR 1.162（95% H6区間 1.003–1.347）に縮小する。焦点2蝶種を除いた残りの蝶の記録件数で調整すると OR 1.116（0.947–1.314）。親流域を丸ごと抜いた予測では、植物NUTRIの追加による一貫した改善は確認されなかった。

## 元ソースの再検証

- 原始CSV：[Actions #43202839926](https://github.com/zuizui0223/gesui/actions/runs/43202839926) の artifact 13935433410 にある 1,219 H7 × 2期間 Animalia/Plantae/Lycaenidae source master。CSV SHA256 は 3f95d4825455cfab67a41de3ec4dab8778acf97d2804f2148108b65c95225c52。
- 以前のGBIF「5蝶科」種別ソースファセットの **総検索件数** を Animalia 検索件数から差し引いた。非蝶動物の検索件数が負または0になるセルは **0 / 366**。非蝶動物記録件数の中央値 34,809、範囲155–1,416,613。
- 元のAnimalia指標（2期間の log1p 原始件数の平均）を再生した最大絶対差は **1.78×10⁻¹⁵**。
- log(Animalia総件数) と log(非蝶動物記録数) の相関は **0.9982**。したがって、これらの置換は新たな独立の観察努力データを提供するものではなく、既存のAnimalia代理の構成上の蝶自己記録を除いた診断にすぎない。
- もう一つの努力代理では、各小流域×期間×種ペアの蝶5科総件数から、比較している焦点種A・Bのレコード件数を引いた。焦点種の直接の記録は含まないが、それ以外の蝶の群集構成を反映する可能性は残る。

## 親流域をまるごと外した予測

植物NUTRIを含まない同一調整変数モデルと、NUTRIを追加したモデルを、H6ごとに完全に分けて学習・条件付き予測尤度で比較。**正の対数尤度差だけが改善**。

| モデル | 34 H6を1つずつ除外した改善の合計 | 改善したH6 | 10通りの真のH6別5分割のうち改善した回数 |
|---|---:|---:|---:|
| 植物由来8列 | **−3.402** | 16/34 | 0/10 |
| **植物8列＋同期間の非蝶動物記録** | **−2.804** | 17/34 | **3/10** |
| 植物8列＋焦点種除外の蝶記録 | **−3.771** | 18/34 | 0/10 |

非蝶動物記録を使うモデルの5分割10通りでは、改善合計は **−18.117～+0.196**。少数の正値はごく小さく、未使用H6へ予測が改善すると現時点ではいえない。どの結果も、独立した蝶モニタリング、未知の種への外挿、真の検出確率を評価したものではない。

## 科学的判断

- 言えること：同じ蝶属の相対的な**GBIF記録**と植物の栄養嗜好との空間的な対応に探索的な正の係数がある。
- 言えないこと：独立流域で再現する属内種交代、蝶の個体数増加、系統制約、幼虫の摂食量、下水から蝶への因果的な物質移動。
- 現状の優先順位は食性幅との交互作用を増やすことではなく、努力時間と検出が報告された独立の蝶トランセクト調査等で、同じ標本・同じ時空間尺度の検証を行うこと。
