## 統合の実行単位

1. **出所の重複**：PRではなく、元調査・施設・観測局・地点年・個体／区画をキーにする。既存の欧州454/451/426/139行は、解析適格条件で変わる同系列の標本である。分母の違いだけを独立再現の根拠にしない。
2. **効果の互換性**：水域EQRの予測改善、植物立地嗜好の回帰係数、蝶の潜在寄主特性、昆虫繁殖率は別の推定対象。MSE改善率や有意／非有意の件数を共通効果量にしない。
3. **部分経路の統合**：原観測が対応する範囲で階層モデル、処理対照と応答が揃う範囲で経路別メタ解析を行う。対応していない辺の係数積は算出しない。
4. **反証の保持**：国外転送、時間差、属内分解、前年記録調整、下流負の対照を主結果の付随情報として保持する。都合のよいモデルだけを選んで代表効果にしない。

今回完了したのは**PR単位の全件照合とレビュー系列の索引化**であり、全効果量の抽出・標本ID照合・共分散推定ではない。CELLDEX等のActionsのみの結果と外部候補研究は、この129件の件数に含めず、[統合設計](CHAIN_INTEGRATION_PROTOCOL_20261120.md)と原本監査で追跡する。

### 主鎖へ統合する意味

この系列は「下水近接→シジミが普遍的に増える」という解釈を支えず、割合の分母・地理重み・公開記録の欠測を検証する比較となる。一方、欧州流域HNSは既知幼虫寄主の特性で、デンマークの成虫記録率とは応答が違う。両者の正負を同一効果の再現成功／失敗として数えない。受水域水質、現地寄主資源、幼虫利用、成虫のタンパク質利用はこの系列で未観測であり、全鎖の欠けた辺を補うメタ解析には採用しない。
