# 2026-11-19｜下水の陸域経路C：汚泥由来肥料→寄主植物→蝶（一次資料・先行研究と野外研究案）

**科学的状態：新しい文献で経路Cの可能性は確認できたが、現在のgesuiのEQR・植物NUTRI・蝶HNSデータでは汚泥施用地と生物記録の対応が測れていない。経路Cの生物効果と、処理水経路Aとの優劣は未推定。** PR #125の行政区2×2、PR #128のJRC元流域SOURCE-onlyは引き続きSTOP。汚泥肥料と「有機肥料モデル」の違いを厳守する。

## 1. どの道を「下水由来」と呼ぶか

- A：処理後の水→河川→河岸への浸水・浸透／堆積→寄主植物→幼虫→成虫。河岸の実際の水接触・吸収は未測定。
- B：処理水の影響下にある可能性のある湿潤基質→成虫の口吻接触・摂取。幼虫・寄主を介する窒素とは区別。成虫吸水はNa塩や有機質への応答でもあり、採餌写真だけでは成虫N同化を示さない。
- C：処理場の下水汚泥→汚泥由来肥料（乾燥・堆肥・他原料混合・リン回収等は別製品）→農地／周辺の土壌・寄主植物→幼虫→成虫。**処理場からの汚泥出荷先＝同じ自治体の施用農地ではない**ため、実圃場の購入・施用記録が必要。下水道の「肥料利用」には農地直接施用と区別すべき利用も含まれる。

## 2. EU・日本の元報告：量と場所の違い

**EU**：EEA/WISE Urban Waste Water Treatment 2022 profileは、発生下水汚泥6,597,953tに対し**39.9%「農業とその他土壌用途への再利用」**と公表（EU加盟国・関連報告国を含む広域集計）。農業だけの量と区別する。出所：https://water.europa.eu/freshwater/countries/uwwt/european-union/ 。別のEurostat 2025データを使用した2025年末のEU循環経済レポートは「農業利用約232万t、処分経路の約32%」とするが、報告年・分類・分母がEEA/WISEと異なるため2値を同じ比較表に統合しない。出所：https://circulareconomy.europa.eu/platform/sites/default/files/2026-01/2025.12-Assessing-the-potential-to-enhance-the-circularity-of-bio-based-waste.pdf 。

**加盟国間の国差**：欧州委員会の2017/2018頃の加盟国実施状況比較（国ごとに報告品質差あり）では、デンマーク67%、フランス70.8%、ドイツ15.5%、オランダ3%、スペイン83%など。**2026年の各国最新数値ではなく古い調査時点**を明示。出所：https://data.consilium.europa.eu/doc/document/ST-9698-2023-INIT/en/pdf および https://eur-lex.europa.eu/legal-content/EN/TXT/?uri=SWD:2023:157:FIN 。

**日本**：国交省の2024年度（令和6年度）下水汚泥肥料利用率は発生時乾燥重量ベース**全国15.5%**（国交省2026年3月26日付の都道府県表）。例：北海道34%、宮城7.1%、新潟30%、佐賀92%、鹿児島96%、東京0.34%、京都7.6%、大阪1.7%。都道府県の数値はその都道府県で発生した下水汚泥が肥料に利用される割合であり、**農地に施用された場所の占有率ではない**。環境省2026年版白書の2024年度肥料等利用は約34万トン（乾燥重量）。出所：https://www.mlit.go.jp/mizukokudo/sewerage/content/001990852.pdf と https://www.env.go.jp/policy/hakusyo/r08/html/hj26020301.html 。

**絶対の下水由来N量を比べない**：汚泥乾燥t×製品中の全N率×実際の農地施用率×利用可能化割合 と、年排水量×処理水全N濃度（又は元報告TN）には別の母数・過程がある。肥料利用率をそのまま「汚泥Nが陸に入る割合」と呼ばない。リン回収灰肥料などは元汚泥にあったNと成分が違う。家庭＋産業を含む元JRC GREEN点源Nモデルと、農地への汚泥施用先の実地表は同じデータではない。

## 4. δ15NだけではA、Cを分離できない

処理水・汚泥・家畜ふん尿・土壌由来Nは、どれも自然存在度δ15Nが高い/重なる場合がある。USGS WSP2497（https://pubs.usgs.gov/wsp/wsp2497/）は窒素源のδ15N単独による識別が困難であることを示す。2012年Water Researchレビュー（https://www.sciencedirect.com/science/article/pii/S0043135412000760）も人由来下水と家畜ふん尿のδ15N/δ18O–NO3が重なることを警告。δ18O–NO3は水中硝酸の形成起源・変換を補助するが、バルク蝶のδ15Nにδ18O硝酸を足せば自動的に経路が決まるわけではない。

同じ地域・採集日に実際の処理水、乾燥/堆肥化汚泥製品、家畜ふん尿、化成肥料、土壌可給態N（NO3/NH4）、寄主植物の葉、現地幼虫・羽化直後成虫を測り、δ15N・δ13C（必要に応じて水硝酸のδ18O、元素組成、汚水由来化学指標、δ34S等）を源ごとに分ける。各源の同位体分布が分離していなければ、複数源混合モデルで下水由来割合の精密推定を行わない。必要なら少量の**^15N標識汚泥を使う閉鎖・小規模実験**によって経路Cを校正する（実圃場への標識散布を前提にしない）。

昆虫の変態自体でδ15Nが高くなることがある。蝶の翅は一般に羽化後の更新が少なく幼虫期の窒素を反映しやすいが、翅と胴体の差が成虫期の汚水由来N摂取の定量に直結するわけではない。幼虫と羽化直後成虫のペアを飼育で校正し、羽化後の成虫摂取を検定するなら同じ幼虫源の羽化直後対照と摂取後組織・排出物を比較する。出所：
- https://www.uwyo.edu/cmdelrio/site/Publications_files/Tibbets%20Wheeless%20%26%20Martinez%20del%20Rio%202008%20Change%20in%20del15N%20during%20insect%20metamorphosis.pdf
- https://analyticalsciencejournals.onlinelibrary.wiley.com/doi/10.1002/rcm.9126
- https://doi.org/10.5962/p.266522

## 5. マメ科は「効果ゼロ」ではなく窒素固定の機構対照

マメ科も根から土壌Nを吸収し、高い土壌可給態NではN2固定割合（%Ndfa）が下がりうる。ツバメシジミはシロツメクサ・カラスノエンドウ等を寄主に使い、ベニシジミはスイバ・ギシギシなどRumex類を使う。両蝶を異なる植物種・生活史の「厳密な陰性対照」にはできない。寄主マメ科の根粒の活動と、同地点の非固定植物対照を使い、%Ndfa ≈ (δ15N_reference − δ15N_legume)/(δ15N_reference − B) を推定する場合は、各種のB値・根系が同じ土壌Nを取得する仮定を確認する。出所：
- https://acsess.onlinelibrary.wiley.com/doi/full/10.1002/agj2.21032
- https://www2.ffpri.go.jp/cherry/chou/shijimi/beni/6_benishijimi.html
- https://butterfly.itbs-ecopo.jp/portfolio/%E3%83%84%E3%83%90%E3%83%A1%E3%82%B7%E3%82%B8%E3%83%9F/

## 6. 経路別の最小野外検定

**最優先はCの真の施用地確認。** 処理場「肥料化実施」、肥料販売先、実際の畑での施用は別段階。農家の許諾と施用日・製品・N/P分析値・施用量（乾燥重量/ha）・混合原料・別肥料使用を突合し、**実施と未実施を農地単位で真正に確定**するまで同位体研究を開始しない。処理場周辺に肥料施用農地があるとは限らない。日本の地方自治体版ダッシュボードと処理場DBは候補探索には使えるが施用圃場の証明にはならない：https://www.mlit.go.jp/mizukokudo/sewerage/mizukokudo_sewerage_tk_001129.html 。

- 経路A（水→寄主）：放流口の上流・下流の河岸と非曝露の対照支流、流水・土壌・Rumex葉・産卵/幼虫の同季節比較。水文を伴う正の曝露支持を最優先。下流のδ15N上昇だけではCとの共曝露や家畜ふん尿を除外できない。
- 経路C（汚泥→寄主）：**施用記録のある圃場**と同じ土壌・土地利用条件の非汚泥圃場の対比。非汚泥側も化成Nと家畜ふん尿を分ける。畦畔等の同種Rumex、土壌NO3/NH4、実製品と葉のδ15N・葉全N・生長・幼虫利用を記録。圃場の境界・過去の施用履歴・施用後時間経過を優先。
- 経路B（水際→成虫）：目視/ビデオの着地・口吻接触と、採取した湿潤基質のNa/窒素/有機物・流入源を対比。蝶の翅δ15Nは主に幼虫期のNを示し、**吸水＝成虫の窒素同化と判定しない**。摂取成分を測りたければ校正飼育・排出物・組織更新を別試験で評価。
- Rumex–ベニシジミとFabaceae–ツバメシジミは現地で寄主・幼虫が確認できるときのみペアとして採用し、マメ科は土壌N依存性を測る機構対照に位置付ける。

## 7. 論文1で書ける内容と書けない内容

「処理場の影響には河川放流水の**点源**だけでなく、汚泥由来の肥料として**陸域の離れた農地**へ移る別経路がある。両経路は空間的に一致するとは限らず、本研究のW・TP・EQR・EIV・HNSデータは汚泥施用地の実測履歴を持たない。このため河川TPと陸域EIVの低い関連から水陸間の物質移行の不在を結論できず、今後は処理水・汚泥施用・対照を同時に追跡する必要がある」と**仮説として**記載できる。

「Cが陸域の植物・蝶の正の対応を説明した」「陸への汚泥由来窒素が水への放流由来Nより多い」「高い蝶δ15Nで処理水か汚泥かが識別できる」「マメ科の蝶では影響がゼロ」は、観測していないので書かない。
