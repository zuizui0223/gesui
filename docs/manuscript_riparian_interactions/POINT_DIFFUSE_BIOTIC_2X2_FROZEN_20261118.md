# 水域×陸域 2×2：点源Nと陸域窒素投入の条件付き追加予測力 — 凍結仕様 v1.0

**凍結日：2026-11-18。対象：gesui PR #125。** 2026-11-18時点のSOURCE-only（269 NUTS2・28か国）結果および既存の生態研究結果は既知である。この仕様は「これから行う点源×陸域N投入の共通コホート比較」を**実行前に固定する追加探索的検証**であり、完全に独立した前向き事前登録や因果実験ではない。結果を見て閾値・曝露・時間窓・標本を変更しない。

## 1. 問いと主張できる範囲

**問い**：同じ地域の河川底生動物と陸上植物の栄養立地形質について、(P)水へのモデル点源Nと、(D)陸面へのモデル窒素投入は、どちらが**別の環境情報を条件付けた後に**独立地域への予測を改善するか。

主たる2×2は「水域＝底生EQR」と「陸域＝植物相NUTRI」。蝶の潜在寄主HNSは事前指定した**陸域消費者の副次評価**。EQRは生態学的健全度であり、耐性形質の選別そのものではない。EIV NUTRI・HNSは植物や既知食草の立地選好に関する群集構成の指標であり、栄養塩の葉への移行・現地の摂食/繁殖の直接観測ではない。複数応答を一つの因果パスの係数積へ変換しない。

元データの弱い周辺相関（JRC点源Nと陸への4つのN投入指標 r=0.01–0.17）は、同じ地域で曝露しないこと／条件付き独立／生態影響を示すわけではない。国差、集計粒度、人口・土地利用の交絡を調整しなければならない。

## 2. 最初に固定する対象母集団と空間単位

- **主たる比較期間**：水域EEA 2018年の真正底生無脊椎動物EQR（元監視地点と原評価方法）、陸域GBIF 2017–2019年の植物EIV NUTRIと蝶の既知寄主HNS。JRC GREEN点源Nは2014–18年のモデル平均、陸へのN投入はEMEP 2015大気沈着、DAYCENT 2010–19施肥モデル。これは厳密な同日・同年の処理効果でなく**近接した時期の地理的横断比較**。
- **二次期間**：水域EEA 2022年、陸域GBIF 2020–22年を同じコード・空間結合で別に推定する。静的な2014–18年点源と2015/2010–19年陸源から2018→2022年の因果的な時間変化を推定しない。
- **曝露の独立単位**：GISCO 2016公式ポリゴンのNUTS2×国。独立のNUTS2地域数と国数を標本数として報告し、同じNUTS2内の複数生物地点・H7・期間は独立の曝露反復とは数えない。
- EEA底生監視地点は元座標が一意のNUTS2ポリゴンに包含された場合のみ割当。境界上・二重割当・座標不明は除外。H7植物・蝶パネルは元HydroBASINS L7ポリゴンの面積の**90%以上**が単一NUTS2にあり重複先が一意のときのみ採用。NUTS2コード文字列とH7 IDの直接一致、最近傍代理、同名流域の割当は禁止。
- 親H6を同じH7に固定し、H6とNUTS2の交差から連結した独立地理ブロックを作る。train/testに同じNUTS2または同じH6由来のデータが跨がないようにする。各NUTS2のEQR・植物・蝶の観測対象数、国、評価法、年、元記録努力、欠測、地理割当の失敗原因を**アウトカムの数値を開く前に**全行で保存。
- 主2×2標本は**同じNUTS2にEQRと植物NUTRIの双方があり、P/D曝露・事前固定背景共変量がそろう地域**の共通完全ケースとする。蝶HNSはこの共通地域内の記録条件に合格した場合のみ副次推定し、蝶がいる地域だけに水×植物の主標本を絞り直さない。

## 3. アウトカムを開く前の共通生物SOURCEゲート（全条件を満たすこと）

| 条件 | 固定した最低値 |
|---|---|
| 水域EQRと陸域植物が両方存在する完全な独立NUTS2 | **40** |
| 対応する国数 | **8** |
| 生物元データに重なる真正H6親流域 | **30** |
| 国内に3つ以上の対応NUTS2がありPとDの国内変動が両方ある国 | **5** |
| NUTS2とH6の二部グラフで独立の分割可能な連結成分 | **20**、かつ固定5foldで最低4成分/fold |
| SOURCEとして植物・蝶の元GBIF/EIV/HNS/記録努力・水域EQR方法が真正に復元できるか | **すべて必須** |

Dの国内変動は主要変数の大気沈着・鉱質/有機肥料のうち少なくとも大気沈着に対して求める。PとDの分布・完全ケース選択を国別に報告し、0の実値と欠測を分ける。共通標本でP対Dの条件付き多重共線性がVIF>5（各D成分とPを他源に回帰）または数値設計行列が識別困難なら、**点源優位／陸入力優位の結論をSTOP**し、無条件・単純源相関に戻して肯定化しない。

このゲートは既存の「独立H6 >=30、国 >=8、5か国以上で変動」を保持し、曝露単位がNUTS2であるための追加条件を明示したもの。新しい共通生物コホートが足りない場合、2×2の生態モデルは**実行しない（SOURCE-STOP）**。

## 4. 曝露と背景モデル（アウトカムを見て選択しない）

**P：水へのモデル点源N** = JRC GREEN PsN（家庭＋産業由来を含む、2014–18平均トン数）を元GISCO NUTS2面積km²で除し、log1p変換。**WWTP固有の実測N排出でも、受け手に到達した量でもない。**

**D：陸域N投入の固定3変数ブロック** = (D1)EMEP 2015大気N沈着のNUTS2全域平均、(D2)DAYCENT 2010–19鉱質N施肥農地平均、(D3)同有機N施肥農地平均。単位や母集団を維持して**別々の説明変数として投入**し、異なる面積分母の値を加算しない。変換は全てlog1p後、学習foldだけで標準化する。生物的N固定は土壌・植物群集と双方向の関係がありうるため**主モデルから除外し、感度分析だけ**に固定。JRC河川向け拡散負荷を陸上曝露として代入しない。

大気N沈着の約10 km原格子は**存在と地理・年・品質・全流域収録を独立に検証できるまで未採用**。仮に検証できても、NUTS2主2×2の代替として結果を上書きせず、事前定義した感度分析に限る。原格子の利用可否を主効果の符号で選ばない。

**背景B0**：2016 GISCO NUTS2面積、位置、国の固定効果、土地被覆（農地・市街地率）、気候（気温・降水）を両アウトカムで可能な限り同じ原地理尺度にそろえる。水域EQRモデルのみ元EEAの国×評価方法、河川流量/流域面積を追加、植物・蝶モデルのみ観測記録努力/収録率を追加。共変量の元ソースと欠測をアウトカム閲覧前に固定。調整変数の取得不能・欠測でモデルごとに異なる標本になる場合は2×2をSTOP。学習データだけの標準化とRidgeの固定候補alphaグリッド[0.1,1,10,100]を内側CVで選ぶ（内側CVも地理成分を分離）。アウトカムの都合でモデル種・特徴変換を切り替えない。

## 5. 4モデル・2×2の主たる推定量

同一の共通地域、同一アウトカム、同じ外側の地理分割でB0、BP=B0+P、BD=B0+D、BPD=B0+P+Dをすべて推定。**外側5fold（独立H6/NUTS2連結成分単位）**の真のheld-out予測二乗誤差をNUTS2単位へ集計し、国を等重みとして平均する。各国内でNUTS2等重み。人口やGBIF記録数によって同じ地域を過大に重みづけしない。

各アウトカム Y（水域W、陸域植物L）につき以下を記録する：

- U_P(Y)=100×[MSE(BD,Y)−MSE(BPD,Y)]/MSE(BD,Y) ：陸入力を調整した後の点源の**固有追加予測改善**。
- U_D(Y)=100×[MSE(BP,Y)−MSE(BPD,Y)]/MSE(BP,Y) ：点源を調整した後の陸入力ブロックの**固有追加予測改善**。
- C_W=U_P(W)−U_D(W) ：水域で点源の方が相対的に有用か。
- C_L=U_D(L)−U_P(L) ：陸域で陸N入力の方が相対的に有用か。

Uが正の場合は**予測誤差が減少**した意味であり、被説明変数の値が生態学的に増えたという意味ではない。4モデルすべてのMSE、4つのU、C_W、C_L、各国・各地理成分の寄与を公開する。PやDの水/陸への直接の栄養効果、同一人為負荷の因果媒介として読まない。

## 6. 不確実性と合否（主検定1回）

- **一次の2方向仮説**：H_W:C_W>0、H_L:C_L>0。地理成分を単位とする元の外部予測損失の再標本化を事前固定3999回、国内成分の抽出で95%両側記述区間と片側pを出す。fold/国から独立の観測を人工的に作らない。これは固定予測の不確実性の評価であり、モデルの再学習不確実性まで含む確証的検定ではない。
- **強い「異なる負荷源の予測優位」判定**：C_WとC_Lがともに正、両方の片側p<0.05、U_P(W)とU_D(L)が**各+1%以上**で各95%記述区間の下限>0。2つの方向仮説の共通成立だけを主要結論とし、片方だけ成立した場合は**対角パターンの証拠不足**とする。
- **「非対角は予測に役立たない」の別条件**：U_D(W)、U_P(L)のそれぞれ95%区間の上限が+1%未満の場合に限る。ゼロを含むだけなら**不確実**であって「無効果」と書かない。
- **検証安定性**：元の国内地域差に基づく結果を主とし、国を丸ごと外す外挿は国固定効果を使わない別モデルとして感度分析に固定。主要なCの符号が国等重み・地理成分等重み・一国除去の大半（少なくとも全除外実行の70%）で同じでない場合、強い一般化主張を下げる。
- **符号の副次検査**：水域EQRはPが高いほど低い、植物NUTRIはDと正に関係することが機構仮説の予測だが、予測利得と係数方向は別々に報告。水域の「耐性種への置換」には別途分類群別耐性・固着形質の直接検定が要る。蝶HNSの方向も副次、植物との係数積・媒介は推定しない。
- 最初に上記SOURCEゲートを判定し、PASSした場合のみ主要2×2を**一度だけ**実行。主解析後に距離、地域、期間、空間粒度、N指標、閾値を変更しない。失敗・未検出・不利な結果も保存する。P（リン）は元データがあっても**点源Nの主検定の代替にしない**。リン・生物固定・10 km格子・蝶HNS・2022は事前指定の副次評価で、肯定的結果によって主検定を書き換えない。

## 7. 結果の読解マトリクス

| 観測パターン | 許される結論 | 許されない結論 |
|---|---|---|
| C_W>0かつC_L>0、対角Uとも正で判定基準通過 | 「水域状態と陸域植物相に関連する栄養負荷の予測情報は地域間で分化する」 | 「水域は下水、陸域は農業が原因」「水陸が切断されている」 |
| 対角優位、ただし非対角Uも明瞭に正 | 「優位な予測情報は異なるが、共有または交差する地理的関連も存在する」 | 「点源と陸側投入は互いに効かない」 |
| 陸域で点源 U_P(L)>0 | 「水へのモデル点源地理は陸域植物相も予測する」 | 「下水Nが植物・蝶に物質移送された」 |
| 水域で陸入力 U_D(W)>0 | 「陸域のN投入地理は河川底生状態も予測する」 | 「面源だけが河川を悪化させた」 |
| Cの片方のみ通過、区間が広い、または_SOURCE STOP_ | 「源の空間的役割の優劣は識別不足」 | 「非有意＝独立/無作用」 |
| 共通標本で双方U≈0、上限も小さい | 「これらのモデル指標は当該尺度の追加予測に乏しい」 | 「生物学的な水陸連結がない」 |

## 8. 原稿への連動と既存原本の保全

PR #124の要旨は**この新しい生物比較が実測成功するまで変更しない**。図1 A–Cの結果／未観測経路を事実上の因果パスに置き換えない。カナダ・米国の公開研究再解析は序論の先行研究引用へ移し、独立実証として本文結果に入れない。ドイツの6放流口結果は現状の曝露距離のため補足に置く。

必要成果物は（a）SOURCE-only標本数・キーの凍結台帳、（b）共通NUTS2×H6連結成分fold ID、（c）背景／点源／陸入力／両方のOOF予測と損失、（d）国別・空間ブロック別差、（e）有意でも非有意でも一次検定と感度分析の完全な数値、（f）取得原本SHAとActions run URL。SOURCE-STOPなら結果を推定していないことを明記し、GO扱いにしない。
