# 汚泥施用―植食性昆虫：直接証拠の確認と取得データ

確認日: 2026-11-20。新しい生物応答モデルは推定していない。既存の文献一覧に対し、一次資料で確認できた比較、未取得情報、実際に取得した施用データを区別した。

両研究を「別地域で二度再現」と数えない。関連する[2021年の一次研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC8207157/)はバッタ研究をOK Ranchの調査として位置付けており、蛾研究と同じ研究景観である。調査年・個々の区画の重複は別途照合が必要。

**支持されるのは「実際の汚泥施用に続いて陸上の植食性昆虫群集が変化しうる」まで。** 蛾の総数増加、蝶・シジミチョウでの再現、汚泥N→植物N→幼虫という媒介連鎖の識別は、この確認範囲では成立しない。汚泥はNだけでなくP・有機物・微量成分を含み、植生構造や保水環境も変えうるため、施用対照だけではN機序を分離できない。成虫捕獲群集と幼虫の食草利用も同じ観測ではない。

## 新たに取得した施用地由来データ：米国Virginia

[USGS release DOI:10.5066/P13IVMXG](https://doi.org/10.5066/P13IVMXG)（2025-12-09公開、対象2024年）のCSV 2点とmetadata XMLを `data/external/usgs_biosolids_va_2024/` に取得した。公開metadataと実ファイルの確認結果は次の通り。

- 郡・独立市: 133行、施用量正値48行。`County_Applied_FIPS`, `Biosolid_Tons`。
- NHDPlusV2集水域: 1,281行。`FEATUREID`, `Biosolid_lbs`。**正値の集水域だけ**を収録。
- 元資料はDEQの日別圃場施用量。施設の発生量や処理場距離とは異なる。DEQ Control IDで許可区域ポリゴンに結合し、区域内に均等配分、30 mラスター化して集水域に集計している。したがって実施用量に基づくが、域内の正確な散布位置は推定である。
- 元の日別表はUSGSが連絡で受領したもの。公開ダウンロードを確認できたのは集計CSVであり、日別表ではない。公開[許可区域GIS](https://apps.deq.virginia.gov/arcgis/rest/services/public/EDMA/MapServer/207)は、単独では当年の施用実績を意味しない。
- 質量は汚泥の量であり、N量ではない。郡合計117,739.0928 tonsと集水域合計259,547,509.198 lbsの比は約2,204.43。米short tonの2,000とは一致しない。メートルトン換算に近いが、原資料の単位とラスター集計差を確認するまで同一尺度に変換した効果を推定しない。

このデータは「下水処理場周辺」から「実際の施用先」へ曝露を改善する候補である。ただし2024年の植物・蝶の観測との重なりはまだ検証していない。未収録集水域を無施用対照に置くには、母集団・収録範囲とゼロの定義を確認する必要がある。

## 現在の研究に加えられる検証の順序

1. 既存の蝶・植物記録と実施用地・年の重なりを数える。重なりがなければ、既存モデルの追試と呼ばず新地域の外部検証とする。
2. 施用先曝露と河川処理水曝露を同じ観測単位で別々に作り、都市化、農地、家畜・通常の施肥、調査努力との識別可能性を確認する。
3. 種ごとの寄主の栄養嗜好に対応する群集応答を、事前に定めた応答として比較する。葉Nの実測がなければ「植物N媒介」を主張せず、植物相・寄主資源による説明の比較に留める。

既存の「河川水質との関連が非有意」を「河川を通らず陸から来た」の証拠に置き換えない。今回取得したのはその代替経路を直接検証するための曝露データであり、汚泥経路の新しい肯定結果ではない。

## フランス2022年の公式施用先輸出を実取得

[ROSEAU/SILLAGE公式ページ](https://www.assainissement.developpement-durable.gouv.fr/pages/data/basededonneeboue.php)で公開されたフォームと配信JavaScriptを確認し、2022年・全国・全規模・CSVで取得した。896,694 bytes、34列・2,099行、35処理場、135処理場–施用先自治体ペア、123自治体。これは取得できた輸出の範囲であり、全国施用の全件数とはしない。分析項目ごとに同じ施設量・自治体が反復するため、行ごとの量の合計は不可。

35施設すべてに施用先自治体欄がある一方、13施設の報告農業施用量は0だった。自治体欄を当年の実施用陽性と直接解釈できない。日付列は汚泥試料の採取日で、施用日ではない。自治体ごとの施用量・圃場・施用年月日はこの表では確定しない。既存2017–22年の欧州蝶資料と時期は対応するが、生物との地理結合と曝露判定は未実施。元の自治体コード列は引用符内にも区切り文字を含むため、CSVパーサーで読む必要がある。
