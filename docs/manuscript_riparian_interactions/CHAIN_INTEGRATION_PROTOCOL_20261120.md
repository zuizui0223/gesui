# 下水→河川栄養環境→植物資源→植食者：広域統合の検証設計

2026-11-20。ユーザーが指定した目標の実行計画。成立をあらかじめ結論とせず、成立条件・反証・未観測を区別して実証を目指す。新しい効果量の計算はこの文書では行わない。

## 1. 共通の問いと解析単位

主問は「下水による河川栄養環境の変化は、河岸植物資源を介して陸域植食者へ及ぶか。その接続はどの条件で強まる／弱まるか」である。フランスを唯一の標本とせず、比較の基本単位を **排出源または曝露対照のある河川区間 × 対応する河岸 × 調査期間** とする。国・PR・論文の数を独立源の数に置き換えない。

観測鎖を X（自治体下水源・曝露）→M1（河川の実測栄養環境）→M2（その河岸の植物資源）→Y（その資源を利用する植食者）と定義する。河川から河岸への水文接続・土壌をM1–M2の媒介条件として記録する。底生EQR/BMWPはM1の水域側の別応答であり、蝶へ直接資源を渡す中間変数ではない。

M2は植物組成だけでなく、葉N/P・化学／同位体、寄主の現存量・被度・栄養品質・更新を含むが、これらの応答群を混合しない。EIV NUTRIは栄養立地嗜好、NDVIは植生指数、GBIFは記録組成であり、葉Nや摂食可能なバイオマスの代用として同一尺度にしない。Yは幼虫の摂食・生残・成長、植食量、標準化個体数・種構成、潜在寄主HNSを別々に区分する。蝶5科→シジミという探索の経緯を保つ一方、広域探索をシジミに限定しない。

## 3. マクロ解析とメタ解析を分ける

### 原観測を統合できる場合：階層的マクロ解析

同じ意味の変数と曝露対照を持つ観測を集め、地点を流域・源・研究に入れ子にする。地域差を単なるノイズとして消さず、河岸水分、冠水／地下水接続、流量・希釈、処理方式、土地利用、季節、寄主タイプが接続を変えるかという修飾条件にする。源・流域・研究を丸ごと外した検証を用いる。

完全鎖に近い同一地点・期間標本を主解析候補にする。X–M1だけの研究とM2–Yだけの研究をつないで媒介係数積を作らない。部分標本は該当する辺の外部支持として使い、欠けた段階を観測済みにしない。各段階を観測していても、交絡・時間順序・曝露と対照の重なりを確認できなければ観測的経路推定に限定する。

### 研究ごとの比較しかそろわない場合：経路別の多階層メタ解析

まず同じ曝露対照・同じ生態学的応答の群内で効果量を整える。例えば、正の連続量の下流／上流応答には対数応答比、同一構成概念の異尺度測定には適切な標準化差を検討する。ゼロ・負値を含む応答へ機械的に対数を使わない。空間相関、調整回帰、BACI効果、前後差を同じ母数にしない。各比較の分散、対応相関、共通対照の共有、同じ源から複数効果が出る依存関係を保持する。

統合の単位は「どの源の、どの接続について、どの対照との差を測ったか」である。共通研究でM1・M2・Yを測っていれば多変量効果の共分散を使うが、源の異なる周辺相関を寄せ集めたメタSEMで全連鎖を証明しない。MSE改善率、p値、肯定結果の割合は生態学的効果量として平均しない。陽性のみを抽出しない。

パス全体の因果的証拠には、時間順序のある同一鎖測定と、処理場改修・放流変更・対照流域などの識別情報を優先する。観測的な一致、源に特異的な関連、介入・トレーサーによる移行証拠は別の証拠水準として報告する。

## 4. 効果を見る前に作る観測機会台帳

各データセットに dataset_id／原著DOI／版／原本アクセス／study_id／river_id／WWTP_id／site_id／coordinates／year-season／up-down-control／shared_control_id を付す。追加欄は曝露の定義、放流水・河川水のN/P分画、採水と植物・昆虫観測の時差、河岸距離、土壌・洪水・地下水接続、植物種と葉成分、寄主リンクの実測／文献、植食者ライフステージ・採集努力、同位体endmember、分散と独立反復数とする。元データにない欄は不明とし、0にしない。

採用可否は符号ではなく、原本アクセス・曝露対照・接続段階・地理時点・独立源・効果量互換性で決める。各群の有効独立源数と推定可能なパラメータ数を先に確認し、精度・検出力を根拠に適用モデルを選ぶ。過去のSOURCE-STOP閾値を結果に合わせて緩めない。新しい候補研究は過去の不合格を覆す扱いにしない。

## 5. 実行順と完了条件

1. 既存129 PR＋原著再解析の出所と重複を整理する（スナップショット取得済み。個別全結果の監査は継続）。
2. 自治体下水に曝露した河岸の植物・植食者を優先して国際的な一次データを検索する。羽化昆虫–クモだけの検索で主鎖の不足を埋めない。
3. 元データの同一源・時期・地点の対応機会を監査し、統合可能な群と原本未取得の候補を区別する。
4. 採用群と推定対象を固定した後に、十分な支持がある範囲のマクロ／メタ解析を実行する。完全鎖を推定できない場合は部分鎖として報告する。
5. 主鎖の支持・反証・識別不能と、同一元データに依存する感度分析を本文・パス図・再現資料へ反映する。

完了は有意な連鎖を出すことではなく、広域で実証できる範囲を監査可能な形で検証し終えることで判定する。現段階では源の統合設計と探索段階であり、完全鎖の証明は未達。

## 8. 更新された主検証：資源の「量」と「質」、水供給を区別する

検証するのは一律の個体数増加ではなく、下水による河川環境の変化が、植物資源の量・質を変え、植食者の量・構成へ伝わる条件である。栄養環境M1とは別に、水供給・河岸湿潤化Hを記録する。候補経路はX→M1→植物資源→YとX→H→植物資源→Y。両方を観測できない資料から栄養媒介の独立性を主張しない。塩類・有害成分による抑制も別の候補である。

| 証拠層 | 現在の役割 | 次の判定に必要なもの |
|---|---|---|
| 既存欧州・英国等 | 水域内の化学環境応答と、陸域の植物–潜在寄主構成を広域で検証した基盤 | 元標本系列の重複を解消し、河岸・実摂食との違いを維持 |
| Arizona野外 | 同じ研究に全段階が存在する候補 | 水・植物・植食者の共通地点/時期、対照、原数値・分散 |
| 南豪州/Hammond | 水から植物までの部分鎖 | 濃度と同位体を分離し、水文接続・葉資源の測定を確認 |
| ヨルダン/Botswana/Italy、欧州ヤナギ | 処理水–植物–植食者の実験層 | 同量清水対照、処理別平均/分散、同一区画対応、媒介の測定 |
| 一般N添加メタ解析 | 栄養変化に対する植食者応答の広域比較母集団 | 元論文で植物媒介を測った研究を識別、上記と出所重複を確認 |

この層別統合なら、野外の主鎖と実験による部分機構、広域的な既存関連を一つの問いに配置できる。ただし別層の効果を足し合わせた「全鎖の平均効果」は作らない。完全鎖の原データが得られない場合も、どの接続・条件を実証できたかを主結果とし、未観測の辺を有意な他研究で埋めない。

## 9. 最新の源接続監査を踏まえた実行順序

2026年11月20日の [PR136固定資料](https://github.com/zuizui0223/gesui/blob/2d3785c4ee17021105942baa3652134831152ade/docs/RESULTS_20261120_EA_TP_SA_2KM_PRESELECTED_HYDRORIVERS_DIRECTION.md) を追加確認した。既存129 PRの固定スナップショット／依存性台帳は過去時点のまま保持し、#136をその集計に含めたとしない。#136は#135と同じChemPop生物系列を使う源監査で、独立した効果量を追加しない。

実測処理水TP採水点の河道上流側に対応する51生物地点・79地点年は、近接候補367採水点を先に選んだ結果である。英国全上流施設の上限でも、全鎖の適格標本でもない。同じPRには全国5,722現行登録採水点を先に河道上で照合し、過去2017–18年の実測TPを後で確認する別の事前プロトコルがある。本統合時点ではその新しい最終結果は未確認で、旧79地点年を全国的取得不能の根拠に用いない。

優先順位は「有意な辺を増やす」ことではなく、連鎖の同一観測単位を確保することで決める。

1. **野外の全鎖候補を最優先する。** Arizonaの同じ調査に水質・河岸植物・アブラムシがあるが、共通地点・日付・対照・分散を含む原表は未取得。原表が得られれば、最初に地点対応と独立した放流源数を確定し、媒介推定に進めるか判定する。原表なしで抄録の正の方向を係数へ変換しない。
2. **英国の源接続更新は水域側の精度向上として取り込む。** 全国河道先行監査の結果、実放流口、同期河川栄養塩、流量の取得状況を確認する。ただし、植物・植食者がない限り水陸の接点を実証したとはしない。処理水濃度を源別負荷や河川到達量と置換しない。
3. **植物–植食者の処理水実験は独立した部分機構として統合する。** 同量清水対照を持つ処理別平均・分散・独立反復数が確認できた比較から対象とする。直接灌漑と河川経由は別層で、栄養、給水、塩類、菌接種を混ぜない。昆虫の個体数と群集の寄主嗜好は別の応答である。
4. **現時点の主鎖の定量判定はフランス共通139行を維持する。** 13経路の再実行は元結果と一致し、同一H6再標本化の共分散・3,000回の係数を保存済み。W→TP→植物→シジミHNSの積は0.00176［−0.0302,0.0377］で不確実。この結果を別地域の正の係数で補完しない。

将来のマクロ解析は、共通の地点×期間で同じ指標が揃う系列に限定して階層化する。メタ解析は、同一の辺・応答・比較設計を推定した独立研究を単位とし、研究内の複数処理・年・種の共分散を保持する。別研究で得た辺を連結したメタ解析的パスモデルには、研究間の交換可能性、指標の対応、欠測の仕組みの追加仮定が必要であり、現在の資料だけではその条件を確認できない。したがって、現段階の統合成果は層別の証拠体系と共通標本の検証であり、全鎖の統合効果量ではない。
