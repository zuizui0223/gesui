# 下水→水環境→植物資源→植食者：広域公開データの一次探索（2026年11月20日）

## 結論

フランス以外にも、**実際の処理水・受水環境と植物体の栄養／同位体を結ぶ観測**、および**排水を植物に与えて植食者を測る実験**がある。したがって、TPと流域植物EIVの不確実な関連だけを接点の全証拠と扱うのは狭すぎる。ただし、今回確認した候補に「自治体下水→自然河川の栄養環境→その河岸の植物体→現地植食者」を同時に測った複数独立流域の完全データはまだない。未発見は世界に存在しないことを意味しない。

今回の作業は公開一次資料・メタデータ・列構成の調査のみ。新しい生態効果の計算、論文の数値再推定、著者への連絡は行っていない。以下は系統的レビュー完成版ではなく探索台帳で、肯定・非検出の両方を採録した。

## 取り違えてはいけない別経路

- [BrazilのAcaciaと植食性Hemipteraの汚泥施用研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC7430702/)は、下水汚泥→土壌→植物→植食者の候補。今回の河川経由の鎖とは別ルートである。
- [Bow Riverの原著](https://doi.org/10.1016/j.envpol.2025.125948)は水生昆虫→河岸クモ。植物寄主→植食者を測ったことにはならない。
- [Santa Cruzの新規放流後のトンボ定着](https://pmc.ncbi.nlm.nih.gov/articles/PMC7501785/)は放流開始という機会を持つが、水供給効果と栄養効果が混在し、成虫トンボは陸上植食者ではない。
- [水生食物網での生産と植食移行効率](https://doi.org/10.1002/ecy.3587)は、同じ栄養段階を測る点で重要だが、水域内の藻類―消費者を河岸植物―植食者へ読み替えない。

## 統合設計への含意

1. まず独立源・地点・期間の台帳に戻す。表の行は候補研究であり、独立反復の保証ではない。
2. 自然河岸／直接放流湿地／河川水灌漑／模擬排水実験／汚泥施用を識別する。地理が異なることより曝露経路が異なることが、係数を一緒にする制約となる。
3. 水→植物の統合候補は葉N、葉N:P、葉δ15N、成長を別応答で持つ。EIVは植物体Nの代用品にしない。植食者は現地食害・接種個体の生残繁殖・群集記録を区別する。
4. 物質移行の全鎖は同一研究内の接続を優先する。別研究の水→植物係数と植物→植食者係数を掛けても、下水の全媒介効果は識別できない。
5. 原研究が既発表でも、同じ定義で独立源を統合する新たなマクロ／メタ解析には利用可能。ただし既報効果の再現を新発見と呼ばず、同一源・反復年月・共通対照の依存を明記する。

## 探索範囲と残課題

検索群：wastewater/effluent/sewage × riparian/river × foliar nitrogen/isotope × herbivory/herbivore/aphid、effluent-dependent arid streams、処理水の植物取り込み。北米・豪州・欧州・アフリカの上記一次候補を確認した。南米・アジアを含む引用追跡、論文横断の重複除去、登録データベース全件検索は未完了であり「網羅検索完了」とはしない。今は入手可能性と適用範囲の優先づけまでで、正の結果を選んだメタ解析は開始しない。
