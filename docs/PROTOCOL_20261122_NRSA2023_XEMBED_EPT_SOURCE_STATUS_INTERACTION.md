# EPA NRSA2023: Is the within-domain XEMBED–EPT response slope different across historically represented HUC8?
2026-11-22 JST. **Explicit exploratory/posthoc**, chosen after seeing previous EPA four-cycle transport outcomes. This is not preregistered or causal.

## Motivation and fixed design
Original EPA 2023–24 source-matched **214 grain-composition/environment pairings**: each one HUC8 never in 2008/13/18 previously selected EPA source frames, one previously represented original HUC8 **but removed entirely from old-model training**. Source pair identities and distances were frozen without 2023 benthic outcomes, original SHA `8c78c9060e0d512666062760f0467baaa54f6cfabeeaf76867ad609e3f1ea8e2`. Source-matched sensitivity **209 hydrology/urban pairs** source SHA `4d21361aa86707039d4afd62cfa11c70f629c50ea01e1a0663e4c00930f254b2`. The E/P/T order level composition contrast from [PR #144](https://github.com/zuizui0223/gesui/pull/144) was not supported. **This test is not another order-search exercise.**

The historical EPA source status is **nonrandom membership in selected eligible old original source samples**, NOT a treatment or evidence a catchment has never been visited outside these analyses.

## Single primary response-relationship contrast (grain source 214 disjoint pairs)
1. Rebuild old 2008/2013/2018 original source sample 2,648 visits/1,030 union HUC8 and 2023 actual original same-site EPA BERW EPT target 1,165 native UIDs/693 HUC8, original EPA 2023 field/water/benthic source SHA exactly pinned, no UID/site/visit/date mismatch. The original historical training would be 1,185/551 HUC8 after removing all target HUC8; its *outcomes* are irrelevant to the new primary paired difference regression.
2. Average native EPA 2023 `(Ephemeroptera+Plecoptera+Trichoptera)` counted `TOTAL300` proportion **within each HUC8** (1 HUC8 = 1 unit) and original source environment covariates within each HUC8. Exact old `ept_fraction` source 2023 counts must reproduce signed previous 1,165/693 cohort. Model only original EPA BERW/WADEABLE, no boatable.
3. Preexisting source-only 214 grain pairs constructed via within-AG_ECO9 matching on actual lat, lon, Strahler order, in-stream logTN/logTP, original field XEMBED, original log width, plus **PCT_FN/PCT_SAFN/LSUB_DMM** particle composition. **Do not recompute new pairs from biological outcomes.**
4. For each original pair i: `D_i = EPT_fraction(novel HUC_i)-EPT_fraction(old-source-ever HUC_i)`; `M_i = 0.5(XEMBED_n+XEMBED_old)`; `ΔX_i=XEMBED_n-XEMBED_old`. The one primary question is whether the **paired EPT difference changes with matched pair mean XEMBED**.
5. Fit `D_i ~ 1 + z(M_i) + z(ΔX_i) + z(ΔlogTN_i)+z(ΔlogTP_i)+z(Δlogwidth_i)+z(Δlatitude_i)+z(Δlongitude_i)+z(Δstreamorder_i)`. Each z standardized by the same pooled **original source-only all-693-HUC8** SD (original field/source units), and `z(M_i)` centered on pooled original all-693-HUC8 mean XEMBED, not on outcomes. Main estimate `gamma = coefficient z(M_i)` has units original counted EPT **fraction change between source groups per 1 SD XEMBED**, equivalently a contrast between the two groups' conditional XEMBED slopes under the linear matched-pair structural assumption. Report `100*gamma` in EPT percentage points per 1 SD embeddedness.
6. **Primary uncertainty** HC3 heteroskedastic pair robust 95% CI and p (one planned exploratory regression coefficient); whole matched-pair 2,000 nonparametric refit bootstrap 95% for gamma. Also 5fold **whole-pair heldout** prediction of D: train-only standardized predictor features and Ridge alpha10; compare same rows baseline without z(M) vs full adding z(M). Hash novel HUC8 to fixed folds. Report pair-equal MSE gain and 2,000 fixed-OOF paired bootstrap descriptive 95%. This demonstrates predictive transport of moderation, not only an in-sample p.
7. **Source gate** ≥150 pairs, ≥5 AG_ECO9, >1 SD unit of measured across-pair XEMBED spread, no missing original EPT/embeddedness in selected HUC; otherwise STOP without outcome-based relaxing. It already has 214 source matches, but model rank and complete-case matter.

## Only two fixed sensitivity specifications
- Same primary matched pair-difference model on independently frozen **209 hydrology/urban source-matched pairs** (which greatly overlap the original 214, so not independent replication), with same 7 original difference controls.
- On primary **214 grain pairs**, add leftover **ΔPCT_FN, ΔPCT_SAFN, ΔLSUB_DMM** residual grain differences to the paired difference regression as a sensitivity. Because XEMBED is strongly collinear with grain, coefficient instability is an identification limitation, not permission to reselect.
- Descriptive: for each source group compare the unadjusted simple regression of HUC8-average EPT fraction on HUC8-average field XEMBED, in **the same 214 matched pairs**, with HC3 intervals. Unadjusted slopes are descriptive and should not be presented as an independent causal test; one regression of D on matched M and covariates is the primary statistical comparison.

## Inference and non-claims
A positive/negative interaction would mean matched conditional **association**, not biological selection, observed fine-scale depositional mechanism, ecological feedback or human sampling effects. A null with wide interval does NOT prove identical relationships. The 214 pairs were selected using outcome-blind environmental matching, but the research hypotheses were chosen after earlier results, and model covariates are observational and partly collinear. 2023 data are from a single survey design and don't identify historical source inclusion causally. No delivered sewage/wastewater TN/TP, no land organisms or water-to-land nutrient flux. Disclose all results and stop further selection of response groups based on significance.
