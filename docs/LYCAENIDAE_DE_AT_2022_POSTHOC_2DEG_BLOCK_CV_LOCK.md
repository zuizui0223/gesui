# Post-outcome locked geographic prediction stress test — DE/AT Lycaenidae photo share

Date: 2026-11-08. **POSTHOC sensitivity** authored **after** viewing 2022 photo reporting regression coefficients, NOT new predeclared confirmatory evidence. The original preliminary positive in-sample OLS (44 country×1° tiles, 22 country×2° geographic blocks, 5,759 total photos, log-source-count beta +0.126) remains retained and unchanged. We cannot retroactively call this a prespecified prediction test.

## Fixed testing scheme (before calculating block-CV outcomes)

- Use exactly the previous archived [52 independently screened 2021-plant effort source cells and 2022 family photo count records](https://github.com/zuizui0223/gesui/blob/analysis/lycaenidae-de-at-2022-landscape-source-photo-20261108/results/lycaenidae_de_at_2022_macro_source_photo/2022_DE_AT_LYCAENIDAE_PHOTO_SHARE_VS_WWTP_SOURCE_EXPLORATORY.json). Source outcome sample remains **44** cells passing ≥20 public 2022 photo events and country-specific counts DE29, AT15. **No cell re-selection**.
- Freeze response `log((Lycaenidae_count + 0.5)/(Pieridae_count+Papilionidae_count+0.5))` (exactly equivalent to previous pseudo-adjusted log odds). Observation is iNaturalist *photo reporting*, never real abundance or puddling.
- Spatial validation groups are pre-existing 22 unique `countryCode|floor(1deg_lat/2)_floor(1deg_lon/2)` blocks. **Leave one 2° block out** in turn; train on the other 21. All transformations (numeric means/scales, within-country source log mass SDs) must be estimated from training data only. Do NOT leak test data into standardization or fold selection.
- Baseline M0 = intercept + z(log1p(2021 Plantae photos)) + z(lat) + z(lon) + country AT indicator. Extended primary M1 = M0 + within-country z(log1p(original 2022 both-positive measured N/P direct-FW outfall count)). Additional source P mass and N mass each separately, not coadjusted. Fit identical ordinary least squares, no tuning. Report total out-of-block **MSE** (unweighted cells), and `relative improvement = 100*(MSE_base-MSE_source)/MSE_base`. Negative values mean performance worsens.
- Compute all-44-cell MAE as secondary. Report by-country out-of-block SSE/MSE when support ≥10; do not select a winning country. Retain predictions per fixed cell and original SHA.
- One **fixed** source-specificity sensitivity: country-wise `log1p` source values independently permuted among 44 source-eligible 1° cells, seed 20261108, **399** permutations. This breaks physical grid-source correspondence but preserves each country's marginal distribution and all original iNaturalist counts/effort. Compare actual heldout MSE improvement to permutation distribution; report tail fraction and null percentile. Permutation does not account for regional urban structure and is not a randomized-treatment p-value.
- A further fixed negative control: randomly permute source values **within country×2° 2° blocks** where ≥2 cells, holding singleton groups fixed, seed 20261108, 199 repeats; if little variation, report uninformative. This more strongly preserves spatial cluster structure; its null is conditional on block-level source pattern.
- If any features/fold becomes singular, record failure, no optimization. OLS train/test fitting and model rows must remain deterministic. An impressive in-sample 2° cluster bootstrap CI **does not** guarantee out-of-region prediction.

## Factual interpretation

Positive OOS improvement supports source **geographical predictive information** about iNaturalist photo records beyond the fixed country/geography/previous-year Plantae reporting proxies. Nonpositive OOS change reduces confidence in transporting the observed exploratory source association. **Neither** identifies wastewater chemical nutrient effects, increased butterflies, direct adult nutrition, vegetation response or ant partner mechanism. Substantial source/plant reporting correlation in Austria (pre-2022 effort rho +0.898) is a critical confounder. Lack of city built fraction, exact land area per grid, observer identities, butterflies' host-plant maps and actual downstream environmental nutrient/substrate chemistry remains important even if the predictive stress test is positive.

Original 1 km / 5 km physical-proximity photo sample support failures, Norwegian/Swedish independent BMS site-coverage failures, and `chocho` 22/25 **potential** host resource expansion are retained as separate studies.
