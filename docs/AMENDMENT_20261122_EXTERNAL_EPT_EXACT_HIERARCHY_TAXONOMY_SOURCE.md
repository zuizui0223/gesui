# Amendment: hierarchy-aware exact original taxonomy repair, BEFORE any sediment–EPT association
**2026-11-22. This is a SOURCE-QA amendment, not a revised result-driven threshold or new fitted model.**

The first strictly machine-based GBIF match taxon source labeled 49 original headers UNKNOWN (source-only original workbook). The sample-level unknown mass exceeded fixed acceptance gates in every country (Australia 7.64%, Brazil 7.54%, NZ 17.29%, UK 8.40%). Original 6,491 relative taxon rows and original sediment percent were never correlated or regressed. Treating Oligochaeta (worms), snails and mites as potentially Ephemeroptera/Plecoptera/Trichoptera is scientifically unnecessarily imprecise.

- EPT exact order: `Plecoptera` is stonefly order ([ITIS TSN 102467](https://itis.gov/servlet/SingleRpt/SingleRpt?search_topic=TSN&search_value=102467)). The bare original order header should not become UNKNOWN merely because GBIF `species/match` returns HIGHERRANK.
- `Antipodoecidae` is an orthographic original spelling corresponding to published `Antipodoeciidae`, Trichoptera. Verify against St Clair et al. (2018) *Zootaxa* [doi:10.11646/zootaxa.4532.1.8](https://doi.org/10.11646/zootaxa.4532.1.8) and ITIS Antipodoeciidae [TSN 598174](https://itis.gov/servlet/SingleRpt/SingleRpt?search_topic=TSN&search_value=598174). Treat this precise original label as EPT with manual cited override, not a guessed family mapping.
- `Oligochaeta` is an annelid worm/clitellate, not an insect order ([NCBI Taxonomy 6381](https://www.ncbi.nlm.nih.gov/Taxonomy/Browser/wwwtax.cgi?id=6381&mode=Info); [ITIS Clitellata](https://itis.gov/servlet/SingleRpt/SingleRpt?search_topic=TSN&search_value=568832)), safe NON_EPT.
- `Mites` and `Hydracarina` are acarine arachnids, not EPT ([American Arachnological Society Acari](https://www.americanarachnology.org/about-arachnids/arachnid-orders/acari/); [USDA taxonomy of mites](https://idtools.org/invasive_mite/index.cfm?pageID=3549)), safe NON_EPT.
- `Neurorthidae` is **NOT Plecoptera**, despite a doubtful erroneous automatic GBIF match; orthographic `Nevrorthidae` in Neuroptera, non EPT. Exclude all DOUBTFUL backbone assignments and conservatively code precise original label as non-EPT only with evidence ([SANDRE Nevrorthidae](https://mdm.sandre.eaufrance.fr/node/250122)).
- Other source-level names are literal documented higher-rank groups known to lie outside the three EPT orders, e.g. Mollusca (Physidae, Planorbidae, Ancylidae, Bivalvia); Crustacea (Cladocera, Ostracoda, Copepoda), non-EPT insects Diptera/Megaloptera/Zygoptera, and annelid/platyhelminth worms. The repair script contains exact frozen memberships by group and retains a group-level cited provenance rather than using species-name guessing. **No names outside the 49 previously UNKNOWN may be modified.**
- `Insecta` spans all insect orders, possibly including EPT, so remains UNKNOWN and is included in the **upper EPT bound**, never silently excluded.
- Verify in final provenance both original strict and amended source-state counts and original 302 unique labels. Do not conflate the taxonomy-repaired normalized EPT share with raw counted EPA TOTAL300.
