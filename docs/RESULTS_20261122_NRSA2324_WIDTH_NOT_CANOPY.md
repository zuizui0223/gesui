# EPA 2023–24：物理生息環境の独立予測情報を、河幅と樹冠に分ける（2026-11-22）

**最終結論：物理環境の正の地域外予測情報を主として担うのは実測河幅であり、河畔樹冠密度ではない。** 河畔林の下水緩和効果という仮説は支持されず、下水特異的な実測曝露の観測体制も不足している。今回の解析は実測**河川内**TN/TPを用いる、明示的な事後的探索研究。

## ソースと解析鎖

1. 真の2023–24 EPA原本5表をSHA固定し、**2,139 common UID**・原本site/visit/date一致を確認：[Actions #45014068137](https://github.com/zuizui0223/gesui/actions/runs/45014068137)。
2. 下水放流口の採集前90日全リン **mg/L・C2/MK**は、全195候補訪問中42訪問/31独立SITE_ID、BERW5地点・BETB26地点と判明。先に設定した各方式≥40物理地点に未達、実測下水×樹冠の新しい生物係数は推定しない：[PR #139](https://github.com/zuizui0223/gesui/pull/139)。
3. 代替の**測定河川水TP** × 樹冠の交互作用4モデルは、BERW 1,165訪問/693 HUC8、BETB 725訪問/476 HUC8で完走。すべてwhole-HUC8 heldout MSE gainが−0.12%〜+0.42%でbootstrap95区間がゼロを含む：[Actions #45014519276](https://github.com/zuizui0223/gesui/actions/runs/45014519276)。
4. 同じ4群で独立予測情報を**N=原本河川TN/TP、H=河幅＋樹冠**に分けると、`H after N`は渡渉MMI +5.994%、舟型MMI +8.475%、舟型EPT +4.232%、いずれもHUC8 bootstrap95>0：[Actions #45014778716](https://github.com/zuizui0223/gesui/actions/runs/45014778716)。
5. そこで、H内部の**幅と樹冠だけを同じ原本・標本・流域foldで分解**。後出し変数探しを避け、予告した4つの固定入れ子モデルで全4群を報告：[Protocol](https://github.com/zuizui0223/gesui/blob/analysis/nrsa2324-ambienttp-canopy-benthos-20261122/docs/PROTOCOL_20261122_NRSA2324_WIDTH_VS_CANOPY_INCREMENTAL.md)、[Actions #45014998986 SUCCESS](https://github.com/zuizui0223/gesui/actions/runs/45014998986)、オリジナル集約JSON artifact ID **14751132780**。

全部で4アウトカム×4比較を提示し、選択的な正例の提示をしない。BERW EPTの樹冠単独 after N は**予測悪化**であり、CIがゼロ未満だが、幅調整後は消失する。いずれも新しい発見のための事後的解析、4×4探索的多重性、bootstrap区間は確証的有意性の代替ではない。

本分解ではB+N+W+Cの元の参照MSEを**4群すべてで元の交互作用解析結果に数値一致**して再現。5fold HUC8完全分離、fold内だけの連続量標準化、未知カテゴリを含む地域onehotのtrain-only fit、Ridge α10固定、2000回固定OOF whole-HUC8 bootstrap。方法を混ぜない。データは公開原本の数値のみを読み取り、成果物に生地点応答は保存しない。

## 正確な生態学的意味

- **重要なのは実測河幅**。粗い河川次数と地理・地域を調整しても、水際の物理的河川サイズの指標は底生群集の状態を予測する。河幅は流量、水深、水理・基質、攪乱、人為開発などの**複合代理変数**かもしれず、河幅それ自体の介入効果ではない。
- **樹冠の独立した普遍的な予測改善は見られなかった**。ただし日陰の機能がない／下水への耐性を高めない、と因果的に否定するものではない。特にBETBの`XCDENBK`は河岸密度、BERWの`XCDENMID`は河道中央密度であり、光量・河床温度とは異なる。
- **河川N/Pの独立予測情報は河川タイプ依存**：渡渉型ではMMI +5.26%、EPT +2.48%（いずれも after 樹冠＋幅のHUC8 bootstrap95>0）、舟型ではMMI +0.17%、EPT −0.19%（ゼロを含む）。
- 水→陸への栄養輸送（羽化昆虫）、植物・蝶とのリンク、汚泥経路、上下流の下水介入、および生態系サービス効果のどれも**この横断観測の係数だけでは同定できない**。

**投稿方針への提案**：`source-conditioned physical and nutrient environmental filtering of benthic communities`をより一般的な問いにする。ただし公表されている既存の水生生態学の「物理生息環境は重要」を繰り返すだけでは新規性は弱い。実際の新規性は、同じ広域群集での**河川型別・栄養塩別の予測寄与の対比**と、局所的な交互作用が流域外で再現しないことにある。下水や水陸の一本化はここでは無理に主張しない。
