## New Germany-only source-only secondary design — frozen before numeric concentrations

- Original population is **all 115** nationwide DE+AT source-only eligible same-directed-river candidate monitor pairs; new **DE-only** comparator is a distinct secondary geography with country constant, not the original cross-country hypothesis. Among original candidate original EEA FW WWTP-internal reach classification, there are 33 German pairs with ≥1 strictly intervening confirmed original source, and 40 German no-qualifying-source with no unresolved upstream/downstream monitor-reach ordering. 3+3 months/dates source support already frozen.
- Construct all ordered pair-of-pairs `(source-positive directed WISE monitor path, clean registered-source-zero directed WISE monitor path)` with **no repeated original 2022 WISE monitoring station hashes across four sites**. Both paths have original ≤50km and source-reach assignments fixed without TP concentrations. Unique candidate pair-of-pairs sorted ascending by **cost = abs(log1p(source reach path length km) − log1p(control reach path length km)) + 0.4 if the original country×2° *upstream monitoring block* differs**, then SHA256 of four original hashed station IDs for deterministic ties. Greedily choose first **8** pair-of-pairs (16 independent directed monitoring paths, 32 distinct monitoring stations), never reusing station. If fewer than 8 complete matches, STOP.
- Criterion for viable matching: 8 matched source-vs-control quartets, **≥4** pairs matched within same original country×2° upstream block, **≥6** distinct original German country×2° blocks in the full selected sample. Crucially, these objective functions and cutoffs are fixed before numerical TP reading, though built from the already observed source-only 115 candidate geometry.
- Strict original source exposure = EEA both positive measured N/P direct FW outlet source origin entering an **internal reach or tributary joining it** between station reaches; source-zero control = no qualifying registered source entering internal reaches and no uncertain same-reach/downstream-monitor joining source. Do not infer environment has no human wastewater from registered-source-zero, and note other nutrient inputs unknown.
- Record all original source-only candidate quartets, selected exact station hashes, path distances, 2° block matching status, source tonnes and ambiguity flags, source input SHA, no TP values; commit selected matching source before running independent numeric WISE6 TP source extraction.
- Water chemistry outcome after the gate: re-open original SHA-locked 2GB original WISE6 2026 individual 2022 TP ZIP and query only original 32 source-selected station hashes with original original TP code CAS_7723-14-0, matrix W, unit mg{P}/L, true 2022 dates, exclude all below-LOQ rows, exclude nonfinite/negative values, site-level median of dated replicate medians. Each site requires ≥4 valid distinct dates in ≥3 months and ≤50% belowLOQ original samples; no imputation. If any station not valid, report attrition; do not silently replace original pairs.
- 2022 TP within-pair difference is `log1p(TP_downstream in mg{P}/L) - log1p(TP_upstream in mg{P}/L)`, compared **source-only registered WWTP-between** versus clean registered-source-zero path differences, *matched within 8 pair-of-pairs*. This is a descriptive **spatial double difference across different rivers**, not causal difference-in-differences in time. Require ≥**6** complete TP-quality source/control quartets including ≥3 original same-2°-block quartets before calculating this descriptive comparison; fewer => STOP. Report number/LOQ sensitivity and 2° geographic block correlated errors; only 8 quartets, avoid pretending independent repeated river reaches have high power or reporting false precision.
- Source design remains observational and biased by original WISE station location, terrain/tributary flow, WWTP reporting, agricultural runoff and climate. Even positive paired TP differences cannot be turned into direct Lycaenidae benefit/abundance or adult puddling nutrient evidence.
