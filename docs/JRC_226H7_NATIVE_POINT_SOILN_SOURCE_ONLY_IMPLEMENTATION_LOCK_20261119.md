# 2026-11-19：全226 H7×5 JRCモデル源のSOURCE-only照合仕様

**元2018河川×2017–19植物のNUTS2版2×2は25地域/6国でSOURCE-STOPのまま。** 本件は格子由来のJRC元流域モデルを利用した、新しい地理的対応の技術・サンプル品質検証。生物EQR、植物NUTRI、蝶HNSの数値は読まない。

## 元対象
前期2017–19の植物EIV元品質合格226 H7を、元454行・451/454 EIV品質可否で固定。元GBIFリクエストの真正H7 WKTをSHA検証した2,808 facetから復元する。対象地域は生物結果の方向で選別しない。

## 元データと取り扱い
- JRC EMEP2015大気N沈着（native river basin layer5、mg N/m²/年）、DAYCENT2010–19鉱質・有機肥料N（layer10/15、kg N/ha/年）。生物N固定は副次。JRCが元10km/1km格子から計算した元流域モデル平均を、H7との重なり面積で再重み付けする。元数値ピクセルの直接再集計ではない。
- JRC GREEN 2014–18のモデル点源N（家庭＋産業を含む、t/元basin）は、元JRC AreaSqKmで除してt/km²密度とした後にH7で面積重み付けする。H7へ到達した実際の下水Nと呼ばない。
- SOIL側のBasin_3035_HydroIDとWATER側のBasinIDは違う名前空間であり、数値IDだけで結合しない。両方の元polygonをそれぞれ真のH7に重ねる。
- 元JRCのEsriJSON ringsによる直接解釈を用い、不正なring形状の修復が面積5%を超えるH7については独立したgeo QAを要求。旧12 H7でのGeoJSON invalidの多さと、修復不要1＋修復依存2 H7で3変換方式が一致した事実を保持し、未監査H7へ一般化しない。

## 厳格SOURCEゲート
元226×5＝1130セルすべての出所・欠測・真ゼロ・技術的エラーを12固定シャードで取得する。API取得に失敗した地域を黙って除外しない。元geometryを一意に扱えない場合もSTOPとする。

元パイロットの和集合カバー90%と異なり、**単一JRC native basin polygonが元H7面積の90%以上を覆うことを主ゲートとする**。大気・鉱質・有機Nと水点源Nの4主源についてこの条件を要求し、土壌3源の原HydroIDが一致することも確認。全4源の和集合カバー90%は別に報告するが、単一polygon条件の代用にしない。

独立SOURCE支持の下限は、厳格なH7 100以上、土壌native basin独立ID100以上、真正H6 40以上、国8以上、独立soil/point源が各3以上あり点源密度と大気沈着に国内変動がある国5以上、H6と元soil/point basinの連結成分を分けた5fold各4独立成分以上。これらは既存の凍結計画を実装した閾値。結果を見て緩めない。

**GOでも新しい生物検定を自動実行しない。** 元の国ラベルは実植物観測の独立国家群とは限らず追加地理監査が必要。2×2 SOURCE STOPの解除には使わず、完全な別研究として扱う。main・草稿PR124・PR125/126は変更しない。
