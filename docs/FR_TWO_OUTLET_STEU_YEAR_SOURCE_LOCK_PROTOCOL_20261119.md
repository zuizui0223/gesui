# 2026-11-19｜同一処理場の水出口と土壌出口をマクロ解析でそろえるSOURCE-lock仕様 v1

## 基本の推定単位

河川への処理水と農地への下水汚泥は、同じ排水処理システムから発する**別の出口**である。しかし、河川受水区と圃場は地理的に離れ、時期も栄養の物理的形態も異なる。河川EQR、植物NUTRI、蝶HNSの相関だけを後から並べても、同じ下水由来の栄養が生物間を移動したとは言えない。

最初に **STEU(SANDRE) × source year** を共通の一次キーとして、水側・陸側の元データを別々のsource recordに分ける。流域H6/H7や生物地点への展開は、真正な受水口・実際の施用圃場がSOURCEで確認できたときだけ。

### 出口A｜下水処理水→河川

STEU SANDRE、年、実際の排水口の位置、受水河川、放流TN/TPの年間実測**質量**(kg/年またはt/年)と欠測区分、処理水量、可能なら低水量時の放流／河川流量を要求。処理場の存在/近さだけ、処理**水量を栄養負荷と同一視**すること、別年の代入はSTOP。

### 出口C｜汚泥→実際に施用した農地

同一STEU SANDRE、実施用年、**bilan d'épandage réalisé**、圃場位置または実施用区域、実際の汚泥乾物量（石灰含む/除くの区分）、製品N/P測定値と栄養投入量、可能なら施用日・作付・他N肥料・家畜ふん尿。

計画 plan d'épandage、処理場の農業施用総量、候補自治体のリスト、GISの面積重複はFIELD EXPOSUREにはしない。未掲載も無施用=0にしない。

- **実際の汚泥施用**は**1,918 t湿重量／481.31 t乾燥重量（石灰含む）／161.53 ha／12農場**（p.5,15–17）。同じ処理場・年に属する**8自治体**が実際の施用簿に現れる。
- 原報告p.19の**平均農学的施用量**は**N total 146 unités/ha、P total 92 unités/ha**、初年度利用可能性の見積りはそれぞれ58、55 unités/ha。これらは植物の実同化量ではない。Pの化学形態の定義、面積加重、汚泥石灰補正など再検証まで**流域N/P総負荷へ換算しない**。
- **同年Feursの水出口TN/TP年間排出質量は未取得**。従って二出口の存在はSOURCE確認、**水と土壌の質量分配や生物への効果はSTOP**。

### 生物応答を開く前に固定するSOURCEゲート

1. 複数の独立施設×年で「実施用」の第三者記録を取得。2017–19と2020–22の両期間の存在を確認。既存最低条件の**実施用自治体30以上・独立親H6が10以上・実施用支持H7が20以上**を下げない。
2. 同一施設×年で水側の真正受水口/実測TN・TP排出質量、陸側の実際の施用位置/量/N・P投入量をそれぞれ取得。**NAを0にしない**。
3. 生物結果を見ずに、地理的独立性、農業・都市化・家畜ふん尿/肥料、観測努力と形質照合率、時間窓をSOURCE-onlyで監査。真の無施用対照は独立に施用履歴が確認できた場合だけ。
4. 合格後に河川水質/EQR、寄主植物NUTRI、蝶HNSの**別々の応答**を地域外予測と負の対照で検証。NUTRI/HNSの正の関係を汚泥Nの直接同化、昆虫の依存や生物間媒介効果と呼ばない。

### 質量収支の注意

処理場内の脱窒（気体N）、貯蔵・他の移送・流入Nがあるため、二出口（水と土壌）だけを足して閉じた100%のN収支とはしない。水量と水中TN質量、汚泥乾物と汚泥N質量は別の測定・換算。施設規模・処理方式・受水流量・施用距離を調整する。
