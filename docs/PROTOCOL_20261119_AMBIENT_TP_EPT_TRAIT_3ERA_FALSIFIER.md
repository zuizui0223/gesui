# 実測河川TP×EPT汚濁耐性：3期・分類群等重み・目内帰無・HUC8外部予測

**2026-11-19 / 事後探索 / 原本EPA 3期と旧PR #98の検証済みサイト集合を維持。確認的独立試験ではない。**
新しい解析は過去の XEMBED（河床埋没度）の成功をTP（同地点実測河川総リン）へ拡張する。**TPは下水処理場由来と同定されていない。**

## 検定対象と原母集団

- EPA NRSA 2008–09 BERWW、2013–14・2018–19 BERW、原TAXA_ID×TOTAL300計数と公式 PTV（0〜10、数字が大きいほど汚濁耐性高）。元分類群・州/eco9・HUC8・測定TN/TP・PHabのIDを固定。
- 先行PR #98が一次解析に使った原コホート：PTV 440/851/674地点、EPT固着性CN 462/918/719地点。全元観測2,648 UID、原rare200候補2,209 UIDは入れ替えない。
- **事後的な形質出現サンプル品質ストレス：** 元分類群3以上、出現分類群の80%以上に形質得点、計数EPT10個体以上。PTV n352/679/567、CN n377/767/624は以前の結果から固定済み。得点できない形質はゼロにしない。異なる期の個体数は同一地点の前後個体数ではなく別のフィールド調査で数えた個体数。
- 指標は CWM_count（EPT計数個体数で重み付け）と CWM_incidence（得点済みEPT分類群を等重み）、ならびにその差。出現のみの結果でも真の種交代（colonization/extinction）や現地個体数増減は直接測定できない。

## この追加解析で初めて判定すること

1. **TP固有形質ラベル帰無：** 真のsite×scored EPT taxon countsと環境・州・eco9を固定したまま、公式PTVラベルをEPTの3目それぞれの内部で999回置換。TPを条件付き残差化する際の説明変数からTP自身を完全に除き、TNと6 PHab、季節、河川規模・導電度、州/eco9を残す。実際のTP βと置換分布との両側距離を比較。目内置換は**厳密な系統樹／種数検定／測定誤差の補正ではない**。
2. **別期・別HUC8予測：** 1期を留保し、他2期の学習から留保期の元HUC8をすべて排除。B＝地理背景+6 PHab+実測TN、B+TPで、PTVの個体数重み付き／出現等重みCWMのHUC8均等MSE差を比較する。逆向きのB＝背景+PHab+実測TP、B+TNも対照として出す。全モデルRidge alpha10・train-only StandardScaler/OneHotEncoder・元HUC8均等training sample weight・固定test lossの2,000HUC8再標本化記述95を維持。
3. **形質と環境の特異性：** clinger習性CNについても同一分析を出し、PTVだけの選択的な肯定報告を避ける。TPの12検定（PTV/CN×count/incidence×3期）の回帰のBH12 q、TNおよびcount-incidence差の結果も保存する。

**判定**：PTV incidence が3期とも正でも、目内帰無または期外HUC8予測が失敗すれば普遍的な「栄養による勝者と敗者選別」を強い結論としない。3期であること、2018年のcount応答が不確実であること、リンと下水を混同しないこと、測定PHabが交絡だけでなく媒介/コライダーたり得ることを残す。
