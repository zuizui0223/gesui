# 2026-11-19｜点源N対陸域投入N：国内・面積を調整したSOURCE-only反証仕様

**区分：事後的探索、数値検証前にこの追加診断を固定。** 既知のSOURCE-only元結果は269 NUTS2地域・28か国、点源モデルN対大気沈着/鉱質肥料/有機肥料/生物固定の単純相関+0.051/+0.069/+0.011/+0.166。既存2018水×2017–19陸の共通2×2は25地域・6か国でSOURCE-STOP。いずれも変更しない。今回は生物応答EQR/NUTRI/HNSは一切開かない。

## 科学的な区別

H1：JRC GREEN 2014–18家庭＋産業由来の水へのモデル点源Nと、JRC EMEP2015大気N沈着およびDAYCENT2010–19鉱質・有機施肥/生物固定の陸へのモデル投入は、**同じ国内のNUTS2地域間でも**どの程度対応しているか。H2：「水は点源、陸は面源で生物が動く」は既存2×2のSOURCE-STOPのため本解析では判定しない。NUTS2の源構造が生態効果や栄養フラックスを証明することはない。

## 入力と結合

元269 NUTS2×6変数のSOURCE-only CSVと原本JSONは[GitHub Actions run 44290036470](https://github.com/zuizui0223/gesui/actions/runs/44290036470)のartifactから取得し、元JSON内CSVのSHA256で確認。公式GISCO 2016 1:100万、NUTS2 level2、正式GeoPackageからEPSG:3035面積を計算し、NUTS2国コードと厳密に一致させる。地域を選び直さない。負荷源欠測は0としない。地域面積を人口や農地面積と同義に扱わない。

## 固定する3段階の監査

1. 元のlog1p点源N総量[t]と陸N投入4種のraw Pearsonを再現。同じ269地域で点源Nを地域面積[km²]で割ったlog1p点源密度に替え、陸N投入4種のPearsonとSpearmanを全て表示。陸Nのmg/m²/年とkg/ha/年は各別の指標とし合計しない。
2. 国切片で中心化したPearsonを、地域等重みと国等重み（同国の各地域に1/n）でそれぞれ表示。国切片＋log1p地域面積＋地域重心の緯度・経度を残差化したpartial Pearsonも副次で記録。4陸N源すべて同時に報告する。
3. 点源N密度を従属変数とする源構造の予測可能性：背景＝国切片＋log1p地域面積＋重心緯度経度、追加ブロック＝大気N沈着＋鉱質・有機施肥N。残差平方和減少率partial R²、VIF=1/(1-partial R²)を計算。生物N固定も加える4源版を副次として併記。陸N入力間の相関とVIFを全て報告。

## 事後診断の判定

- 国単位有復元bootstrapを3999回、固定乱数種20261119で行い、**国等重み国内中心化r**の記述的95%区間を計算。国が繰り返し抽出されても擬似的な新国として扱わない。国1つ除外を28回行い、各源について元国内中心化rの符号/強度が変わるか報告する。
- **国内の弱い線形冗長性の支持**：主3陸源（沈着、鉱質施肥、有機施肥）の各国等重み|r|<0.30かつ全95%区間が[-0.30,+0.30]内、点源NのVIF<5である場合だけ。この条件を満たしても「源が物理的に別場所で生じる」「生態的に別々の原因」を意味しない。
- **強い共変動による反証**：国内等重みで|r|≥0.50かつ国除去の70%以上で|r|≥0.30かつ同符号の場合、「点源と陸域投入はほぼ無関係」と書かない。
- その他：**識別不確実**。とくにCIが広いなら元0.01–0.17の小さい相関を独立性と呼ばない。源の正負により国・年・標本・変数を再選定しない。

結果は全4陸源について欠測、国別r、LOCO、地域面積補正、国固定、部分相関、3/4源VIF、sourceとGISCO SHAを出力する。生物2×2の既存SOURCE-STOPは解除しない。未測定の水の実際の到達N、陸土壌・葉N、下水から蝶への移行や個体数の因果効果は未確定。
