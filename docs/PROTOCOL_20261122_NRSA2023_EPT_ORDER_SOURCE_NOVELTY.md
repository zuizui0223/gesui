# EPA 2023–24: do EPT orders explain failure of historical habitat signal transport to source-novel catchments?
Date: 2026-11-22. **Exploratory posthoc**; old 4-era EPT-transfer effects, grain/hydro matches and source-novelty outcomes were previously seen.

## Competing ecological explanations (not causes established)
P1 **Compositional filtering**: at otherwise environmentally similar source-novel 2023 HUC8, Ephemeroptera, Plecoptera and Trichoptera make different contributions to the whole benthic count. A change in composition can affect how a historically learned EPT-sum vs XEMBED predictor transfers.
P2 **Within-EPT substitution**: EPT total share may be similar even when its E/P/T fractions compensate in opposite directions.
Falsifier: neither E/P/T fraction nor EPT-conditional composition differs robustly after source-only environmental matching; broad order composition is inadequate to explain the earlier prediction gap.
Alternative remains source sampling/measurement, family/species pool, channel and substrate history, and nonrandom original source selection. No causal mechanism can be proven from this data.

## Primary compositional tests on the previously frozen 214 grain-matched HUC8 pairs
- For original each EPA UID aggregate counted `TOTAL300`: `N_total = Σ TOTAL300` of all nonnegative original taxon records; `N_E, N_P, N_T` based only on `ORDER = Ephemeroptera, Plecoptera, Trichoptera`. Check `N_total>0` and exact prior full-target source n1,165/693. Original EPT fraction `(N_E+N_P+N_T)/N_total` MUST reproduce exact `ept_fraction` from previous source-locked code within 1e-12 for all native UID. No taxon label is inferred from family/genus if ORDER is blank. Non-EPT and source-unknown orders remain in denominator.
- For all 693 target HUC8, first average original per-UID fractions *within each HUC8*, so each independent HUC8 contributes one vote. Do NOT pool raw abundances across a group (which overweights repeated surveys).
- Three fixed primary 2023 HUC8 outcomes: `E_total_share = N_E/N_total`, `P_total_share = N_P/N_total`, `T_total_share = N_T/N_total`. Target matched pairs: each 214 source-novel HUC8 vs 214 old-source-ever (but **never trained**) in same eco9 and matched by original site location/stream order/observed N/P/XEMBED/width and three *source particle distribution* metrics.
- For each order, report both matched HUC8 group means and **paired new-minus-ever mean difference** (percentage points of total benthic count), 2,000 paired-HUC8 bootstrap95 fixed-matching interval, and two-sided random sign-flip paired difference p using **10,000 fixed RNG flips**; Holm adjustment on only the three fixed E/P/T tests. Include no-significant outcomes, per eco9 group evidence descriptive only, no selecting a posthoc best order.
- Parallel sensitivity: same three order shares on independent-source **209 hydro/urban matched pairs** from source-only cohort, but don't call same-site overlapping pairs an independent replication. Two different outcomes stratified within source novelty, same signed historical environment matching.

## Additional prespecified descriptive, NOT confirming mechanisms
- Total EPT fraction in 214 and 209 paired groups, to test whether order reallocation can coexist with similar aggregate EPT.
- Conditional within-EPT shares E/EPT,P/EPT,T/EPT, only on HUC8 with EPT>0; explicit excluded HUC8 and matched-pair counts. Do not turn 0 EPT into a three-way composition.
- Count-sampling quality: original `TOTAL300` denominator distribution, zero-order counts per UID, EPT-zero HUC8 count, nonidentified taxonomic order fraction, raw taxon rows/UID and family metadata availability. These are potential measurement/coverage explanations, not ecological effects.
- Posthoc link to previous model: source fixed predicted EPT responses and their errors from 2008/13/18 on 2023, to verify the earlier +9.955 vs −1.778% grain matched XEMBED-added gain and +11.025 vs −1.489% hydro matched gain; if difference in order shares, state consistency only, **not mediation**. Avoid selecting outcomes based on order-composition p values.
