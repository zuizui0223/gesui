# Global wastewater-production positive association: country-transfer falsification (2026-11-10)

**The user priority is MACRO ECOLOGY, not more local butterfly detail.** This specifically addresses whether the existing 1,055-port, 42-country observed positive association is widespread enough to serve as a global hypothesis. The source WWp + candidate-host outcome positive was already known before this study. **ALL tests here are POSTHOC external-generalization and robustness checks, not a new pre-registered positive, an N/P experiment, or evidence that wastewater increases plants.**

## Three pre-fixed macroscale validation questions

1. **Country-deletion influence:** leave ONE original country out at a time, refit identical 1,055-port country-FE model on remaining countries, log all 42 coefficients and their country-cluster 95% intervals (no selecting only positive). This is INFLUENCE, NOT transfer to an unseen country. Report the number of positive coefficients, and the LOCO min/max.
2. **Within-country geographic prediction:** prepartition original WPI points into original `country × floor(lat/2°) × floor(lon/2°)` geographic blocks. Use exactly **5** deterministic folds by sorting these 2° blocks within each country and allocating folds cyclically, independent of WWp and plant results. Use country FE only when a country remains in TRAINING; score only source-fixed test ports of countries with >=2 separate 2° blocks and >=5 training ports. Fit baseline country FE + lat/lon/host-index + WWTP + WorldCover built/crop, and augmented same + WWp on identical test ports and folds. Report macro-country-equal and port-pooled heldout MSE improvement, 42-country country-block residual contributions; block grouping is within-country transfer of geographic photographic reporting, not causal effects. If too few matched test ports (<500 across >=20 countries), stop this subanalysis; do not change folds to chase positives.
3. **Strict unseen-country test without country FE:** hold out **each** of the 42 original countries in turn; train a country-agnostic baseline with lat/lon/host-index/WWTP/WorldCover built/crop, compare it to same predictors + WWp on EXACT same holdout ports. Report mean prediction improvement with countries weighted equally AND all ports pooled, country sign count, leave-one-country-out regional variability, descriptive 2,000 country-resampling 95% intervals of MSE improvement computed on fixed holdout residuals. A country FE model is **not** legitimately transferable to an unseen country, so no pretending that it was used for this test.

### Fixed observation-process negative controls / sensitivity

On identical original port source sample, compare the effect of WWp on alien and native log candidate species richness separately (not conditioning on their sum); does WWp correlate with both similarly? This is an observer/urban potential explanation, not a formal proof of bias. Explicitly include the earlier source report finding: both alien and native indexed candidate host richness rise with WWp, country-specific initial WWTP25 ranks are almost evenly positive/negative. No new outcome selections.

Do not convert positive regression beta or predictive gain into plants growing because of wastewater. All claims are bounded to the candidate-host catalogue/GBIF recording process; **the next independent biological endpoint must be all recorded Plantae (not just chosen butterfly hosts), with species ID, standardized 2001–2024 period and independent record-effort control; it cannot be fabricated from this original WPI host-only table.**

**Decision:** a positive global coefficient but failed unseen-country prediction still means a positive **pooled source-geographic association**, not a generalizable macroecological response. If both geographic and country tests add independent prediction and remain positive, treat that as new observational generalization support, not causal effluent.
