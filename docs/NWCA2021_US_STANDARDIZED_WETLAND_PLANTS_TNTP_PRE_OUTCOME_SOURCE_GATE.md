# USA NWCA2021 standardized wetland plant community × measured TN/TP, pre-response gate

2026-11-10. This is a **separate independent US-wide source** from the 1,055-port global GBIF data, not a redefinition of modeled 2015 wastewater generated. EPA 2021 National Wetland Condition Assessment (NWCA), official original site-level probability-sample wetland surveys, includes vegetation community diversity, site water TN/TP, wetland class and hydrologic water sources. Original 2021 water nutrients **MAY** be influenced by WWTP discharges but cannot automatically be called sewage-derived. Hypothesis of positive plant-diversity nutrient response is exploratory/posthoc; all signs will be reported.

## Original sources independently retrieved before response values

U.S. EPA NARS 2021 official public CSVs, fixed URL directory `https://www.epa.gov/system/files/other-files/2024-05/`: `nwca21_siteinfo-data.csv`, `nwca21_waterchem_wide-data.csv`, `nwca21_vegmetrics-data.csv`, `nwca21_hydrology_sources_wide-data.csv`. Official source metadata describe respectively: original sampled US sites/state/ecoregion, water `NTL_RESULT` in mgN/L and `PTL_RESULT` in **μgP/L**, plot-level vegetation Shannon `H_ALL`, `H_NAT`, `H_ALIEN`, richness/composition Floristic Quality `FQAI_ALL/FQAI_NAT`, sources of wetland water `INFLOW_PRESENT`, `GRDWATER_PRESENT`, `OVBK_FLOOD_PRESENT`, `OTHER_SOURCE_DESC`. These are U.S.-wide wetland plots, **not globally representative all-vegetation plots**, and do not measure the amount of effluent from any specific WWTP.

Stage 0 computes **only original column schema, site ID intersection and predefined eligibility from SITEINFO**. Do not open vegetation metric values or TN/TP result values until site opportunity and original source IDs have been SHA frozen. Prefer join key `(SITE_ID,VISIT_NO)` when present, otherwise `SITE_ID` only if site tables are demonstrably unique (duplicates are blockers).

Preselect sampled probability sites (SITETYPE=PROB), first visit if visit column provided, positive NWCA survey design weight `WGT_TP_CORE`, valid LAT_ANALYS and LON_ANALYS, and 2021 design year. Preserve ecoregion `AG_ECO9`, inland/tidal class `HYD_CLS`, wetland class `WETCLS_GRP`. Data readiness gate **≥300** original survey site visits with BOTH waterchem and vegetation metric source rows, ≥15 states, ≥4 ecoregions. Any missingness/duplicate site rows are not a biological zero. Do not relax gate after response values.

## Source-complete biological endpoints only after eligibility

- Outcome `H_ALL`, Shannon-Wiener native+alien plant cover diversity, `H_NAT`/`H_ALIEN` as components; `FQAI_ALL`, native FQAI as ecological condition. These are original **standardized NWCA survey plot measurements**, not GBIF opportunistic records. Only use `SAMPLE_TYPE=PLANT` table rows, duplicates handled by original site visit/sample TYPE, not averaging repeated different metrics without noting units.
- Actual water exposure `NTL_RESULT` total N (mgN/L) and `PTL_RESULT` total P (μgP/L -> mgP/L divide 1000). Require positive finite numeric measurements and appropriate original NARS quality flags; `ND`, `NR`, and QA issues must be recorded and excluded or explicitly analyzed as censored, never set to zero. Describe measured N/P as **water chemistry**, not wastewater/NPDES effluent.
- Primary fixed analysis on qualifying actual matched sites with ≥200 joint nonmissing H_ALL and TN/TP, ≥10 states, ≥3 NWCA ecoregions: `H_ALL ~ log10(TP_mg_per_L) + log10(TN_mg_per_L) + wetland class + ecoregion + hydro class + geographical latitude`, with state-cluster descriptive 95%CI. Additional one nutrient-at-a-time and H_NAT/H_ALIEN/FQAI_ALL alternate responses reported regardless of sign, not posthoc selected. Independent states are not true randomized effluent groups; even sign-consistent association cannot demonstrate wastewater-driven gains.
- Negative/control checks: observed `H_ALIEN` vs `H_NAT`, and observed `FQAI_ALL`: floristic richness/diversity may increase with nutrient concentration while quality decreases, so report both rather than selecting positive. Wetland hydrologic sources may include artificial drainage; a free-text `OTHER_SOURCE_DESC` cannot be taken as an independently measured WWTP discharge unless explicitly coded and independently validated.

If source/response support gate fails, STOP without a fitted coefficient. Keep all original source SHA, site counts and distinct state/ecoregion counts in a reproducible Draft branch, no main merge.
