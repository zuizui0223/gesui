# 2023–24 genuinely novel catchments: environment and transportability audit
2026-11-22 | original EPA NRSA four-cycle source | **posthoc** after apparent gain disparity

## Scientific question and status
The signed full target (n1,165/693 HUC8) yielded HUC8-equal six-PHab-after-NP +7.06% [2.45,11.58]. When the original EPA 2008/13/18 raw source membership separates the SAME 2023 target, 479 previously represented but *removed from training* HUC8 had +10.50%, and the 214 never represented had −1.76% (CI crosses zero). Both used exactly the same model fitted solely to 1,185 past-cycle original observations in 551 non-target HUC8. This study asks whether source environmental domain coverage and study-region composition help explain the difference. This is a **diagnostic** (not a preregistered hypothesis, not an intervention effect).

## Failure/selection and inference limits
2023 target is from the same EPA NARS design, but historical 2008/13/18 source sets were preselected on benthic count, chemistry and in later cycles periphyton source opportunity. Source-membership novelty is therefore *not synonymous* with hydrological novelty, geological novelty, taxonomic novelty, or "genuinely never observed anywhere in the US". Analytic unit is original HUC8; older EPA source coverage is incomplete and not random among all rivers. Group mean matching is not a treatment-control causal test. Using data-driven matches and 7 source features after seeing a discrepancy is exploratory. Exact original 2023 site IDs and source-derived environment only; results exported aggregated, no original site coordinates or outcomes in repository.
