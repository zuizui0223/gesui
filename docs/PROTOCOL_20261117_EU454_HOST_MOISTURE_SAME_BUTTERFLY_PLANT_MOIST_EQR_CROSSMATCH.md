## Two independent numeric biological units + source normalization

Reconstruct all 303 species from actual GBIF family counts, then calculate both host trait means using **exact same 180 ACCEPTED both-N+MOIST butterfly species** at every H7×period. Define `Bfly_hostN_incidence`, `Bfly_hostMOIST_incidence` as means of the fixed species N/F scores over **observed species with positive source GBIF counts**; and source `Bfly_hostMOIST_record` as GBIF-record-weighted mean sensitivity (not abundance). Numerically scored butterflies and GBIF-record coverage are tracked; no missing trait imputation, and original `trait_coverage` is a nitrogen host coverage proxy, not full F coverage. Require at least 2 co-scored observed species, source GBIF records ≥10 and both numeric scores on each H7×period for provisional model; retain all failed rows in source QA. Need ≥**200** H7×period, ≥**40** parent H6 and ≥**5** original country-majority groups to authorize observational models. This is a posthoc source gate and not a primary pre-analysis confirmatory registration.

**Critical:** The physical GBIF butterfly sample is observational occurrence counts not abundance, its host trait scores describe preferred habitat environment, not true locally fed plants. Paired mean N/F in an individual butterfly can summarize *different scored HOST species*; before any credible independent N and F trait **mechanism** or ecological inference, reconstruct original butterfly×host plant edges and double-scored EIV N/F on exactly the same host taxa. Do NOT interpret provisional H7 numeric score associations as an actual trophic link.
