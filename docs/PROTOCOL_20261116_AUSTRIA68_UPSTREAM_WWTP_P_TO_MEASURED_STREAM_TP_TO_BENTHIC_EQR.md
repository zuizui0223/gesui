Same original **68** site cohort for every model. Source background B: log1p(original river Q), log1p(original river drainage area), original lat/lon (train-only standardization). Outcome first **ln(real stream total-P annual mean mg P/L)** and separately original normalized benthic EQR.

1. **Source→chemistry**: real logTP ~ B (M0); B+log1p(UPSTREAM reported annual outlet P tonnes/year) (M1); B+log1p(DOWNSTREAM reported P tonnes/year, placebo) (M2); B+both source variables (M3). All four use genuine 5 source geographic blocks and EXACT same heldout field stations, standardized in the training fold, Ridge alpha=10 with intercept unpenalized; block-equal MSE improvement (plus each block MSE) and raw Spearman reported load↔TP (descriptive only). If upstream P not more predictive than same downstream placebo, stop any source-specific pollutant delivery narrative.
2. **Source→biotic condition**: original EQR ~ B (M0), B+upstream P (M1), B+downstream P (M2), B+measured logTP (M3), B+logTP+upstream P (M4); same 5 geography-heldout source blocks and exact original 68. Compare original P information before/after measured TP; **do NOT call the change in coefficient causal mediation**, with only one-year source and no measured source-specific chemical fraction.
3. **Flow-normalization sensitivity**: replace raw log1p(annual reported upstream P tonnes/year) with log1p(0.03170979 × annual P_tonnes/year / original mean Q_m3_s) in both models. This is a calculated *potential full-delivery receiving-stream concentration equivalent* in mg P/L, not measured P or claimed total delivered P. Report sensitivity separately from primary, and no regional cherry-picking.
4. Full-sample adjusted standardised coefficient for upstream reported P in true logTP model and in EQR model with/without stream logTP, plus original regression R² only descriptive. No conventional significance p-value claims, because only FIVE geographical block groups, model search in original project, no causal exogeneity. Fold-by-fold direction is key.
5. Additional source-specific sensitivity: leave-one-region-out full-sample partial slope sign and Pearson residualized source↔TP after river Q/area/geography; no source-positive vs no-report causal contrast. Do not reselect 53 positive source-only subset for main claim.
