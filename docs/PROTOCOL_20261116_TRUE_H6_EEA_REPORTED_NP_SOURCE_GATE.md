## 問いと対象

「下水に特有の植物―蝶形質群集変化」を立証するには、**河畔植物と蝶の生物観測と同じ空間位置・時期に実際に到達する放流由来のN/P**の違いが必要。既存のモデル排水地理Wにはその確証がない。

既存の原本で以下の三つを厳密に分ける。
1. **源報告の有無**：EEAへ報告され、上流に位置するN/P年間報告負荷が元H7×期間に正の値として照合されたかどうか。照合なしは **非曝露・清浄対照ではない**。
2. **年報告量／モデル流量の仮想濃度相当**：報告源のN/P質量を元EEA地点のモデル河川流量で換算した値。**河道・河畔の実測TN/TPではない**。
3. **現地の曝露・栄養媒介**：受容河川の同一地点/年の実測TN/TPと、土壌N・葉N、現地植物被度・幼虫摂食・蝶個体数。**この原本では検証不可**。

## 生物応答を見る前の数と成立条件

- 固定183 H7のうち、元232 H7に属する173 H7の**2期間**のみで報告質量の生物源サイトに相当する旧indexへ完全照合する。新10 H7については元PR90 sourceは未取得であり、**源報告情報はUNKNOWN**、源報告なし(0)ではない。新10を欠損補完や母集団の再選択で埋めない。
- 地理source QA：旧173×2=346件は`H7×period`完全一致、真正H6 parent一致、EEA N/P >=0、source-positive flag=1のときN/P両方正、元PR90 454行total source positive56。元PR92 up positiveとPR90 positive source flag完全一致を求める。不一致があればゲートSTOP。
- 主たる**報告源あり群内での真の強度比較**の最低ソース母集団を結果を見ずに固定：≥30報告源正のH7×期間、≥20異なる報告源正H7、≥10真正H6でそれぞれ**異なる2つ以上の報告源正H7**（期間を2独立H7に数えない）、≥5元country群。さらに両年で報告されたH7が5以上存在することを要求。いずれか未達なら **`STOP_SAME_H6_REPORTED_INTENSITY_REPLICATION`**。理由は、報告源のない流域を真の未曝露の独立対照として使わず、報告正の流域間で真の投下量に差があるかを推定するため。
- ソースの有無だけを比べる補助指標：same H6で「報告源正のH7」と「正の源報告が照合されなかった別H7」を両方含むH6数、国数。これは**報告と照合の構造**であり下水曝露 vs 非曝露ではない。
- Source-only gateを通過しても、同一河川・同一年の実測水質と河畔GBIF植物／蝶パッチの原記録がなければ、`W→Plant→Butterfly` SEMや因果媒介は**STOP**。強度や流量が正でも観測個体数、葉Nや放流水到達の実測として扱わない。
- H7×期間の報告の変化は施設稼働や環境変化ではない（過去PR90/93が示すとおりレポート状態変化を含む）。2018 vs 2022 source yearとGBIF 2017–19/2020–22窓の非一致も明記。
