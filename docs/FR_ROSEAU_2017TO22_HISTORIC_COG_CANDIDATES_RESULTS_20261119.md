# 2026-11-19｜経路C：フランスROSEAU 2017–2022年の汚泥施用先候補を歴史的INSEEで検証

**結論：元政府CSV6年分・各年の公式INSEE COGと元コード＋名称の照合を完走。130の異なる施用先候補（コード・地名一致）が得られた。ただし施用圃場・自治体別実施用イベント・施用N量は未確定であり、生物NUTRI/HNS/EQRの新規解析は未実施。 SOURCE-GOはまだ出さない。**

## 公式元sourceと最終検証

- フランス政府ROSEAU/SILLAGE「Boues urbaines épandues」：[公的輸出ページ](https://www.assainissement.developpement-durable.gouv.fr/pages/data/basededonneeboue.php)。正式元JSの公開POST controller・年・フィルタから元CSVを各年取得。元SHAと元行数を再照合。
- 対象年2017–2022。INSEEの各年の公式COG (Code Officiel Géographique) 本物のCSV/TXTをそれぞれ取得し、元汚泥CSVの文字列CODE|NAME・複数自治体カンマ区切りを1処理場につき一度だけパースした。
- 元処理場の「Quantité épandage agricole (tMS/an)」が**正**で、当該処理場の「Commune d'épandage」リストに名前があり、該当年の**INSEE CODEと地名をともに一致**できた自治体のみの候補コードを採用。元の処理場農業施用総量を自治体数倍したり、1分析行1施用イベントと数えたりしない。
- 元public CSVには汚泥ロット・採取日・分析パラメータが混ざる。元「Année du prélèvement」は**試料採取年**であって各自治体の実施用年月日とは限らない。
- [全6年・6ジョブ＋統合の最終GitHub Actions #44465289468](https://github.com/zuizui0223/gesui/actions/runs/44465289468) SUCCESS。2019/2020の最初の失敗は公式COG CSVの小文字列名（com/ncc）であり、元の列名を正規化して修正。政府接続タイムアウトの途中STOP履歴も保持。
- [全年度の候補自治体元コードとSOURCE-only判定](https://github.com/zuizui0223/gesui/actions/runs/44465289468/artifacts/14501751936) は元政府CSV個別行・圃場情報を含まない。原フランス政府CSVのSHA・元INSEE COG ZIP/CSV SHAと個別年出所は同runの年別各成果物に保存。

## 新しい次の接続先：施用実績の元圃場記録

フランスSILLAGEには二種類の行政データがある。**plan d'épandage** は施用予定圃場と適地、**bilan d'épandage** は特定期間に**実施された**汚泥施用・圃場。フランスの1998年汚泥農業施用令・2020年改正Article20は、処理場汚泥を農業利用した際の施用キャンペーン情報を SILLAGE/VERSEAU で行政側に送付することを要求する。[政府の施用計画運用説明](https://assainissement.developpement-durable.gouv.fr/pages/data/page.php?idPage=24)、[Légifrance第20条](https://www.legifrance.gouv.fr/loda/article_lc/LEGIARTI000042419149)。

元ROSEAUで得たSTEUs・自治体候補を行政に照会するための**研究候補の名寄せ資料**には使える。ただしSILLAGEの圃場単位の記録が公衆に自由公開されていることは確認できておらず、行政または土地管理者の許諾が必要な可能性がある。自治体コードに対応する現存の地理ポリゴンは別途取得可能だが、そこにGBIF蝶・植物の位置を重ねるだけでは圃場での施用履歴の直接証拠にならない。

## 論文1と論文2

- 論文1：汚泥由来肥料が河川を通らない別の下水起源N経路となりうることを、**独立した生物効果未検証の仮説**として考察に置く。元ROSEAUの130候補は、本論文の効果量・媒介の新しい結果ではない。
- 論文2：SILLAGEの**実際に施用した圃場・量・日付・寄主植物位置**を元行政／生産者から確認できる地点で、Rumex–ベニシジミの幼虫や他の寄主–蝶のN同位体・化学トレーサーと処理水経路Aを比較する。マメ科は窒素固定依存性を測る機構対照。δ15N単独で汚泥と処理水を識別しない。
