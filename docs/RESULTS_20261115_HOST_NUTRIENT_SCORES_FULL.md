# 科から種の寄主栄養選好へ：蝶のHNS表

作成日：2026-11-15。探索的な資料統合。**今回、下水の効果・上下流差・個体数変化は推定していない。**

## 結論

種ごとの寄主栄養選好を連続変数として扱い、成虫の資源摂取を別軸にする方針は実装できた。gesuiの元の303種キーのうち190キー、chochoの凍結原名230件のうち147件で、少なくとも一つの寄主のEllenberg型N値から平均を計算した。**これは増加・減少・無関係の3群を発見したことではない。** 全303行／230行を残し、未対応をゼロ・無関係・行動不在にしなかった。

Ellenberg型Nは、植物が生育する場所の栄養条件への選好を示す。葉内窒素含有率、幼虫が摂るN量、成虫の吸塩、下水曝露量は測定していない。したがって本表の名称は「寄主栄養選好スコア（Host Nutrient-affinity Score; HNS）」とした。

## 1. 原本と照合範囲

| 資料系統 | 全行 | 数値HNSあり | 寄主N数値対応率80%以上 |
|---|---:|---:|---:|
| gesui・元の種キー | 303 | 190 | 63（ACCEPTED分類のみ） |
| chocho・凍結原名 | 230 | 147 | 25 |

この2表を足して独立した533種とはしない。名称が一意に対応した76組のうち、69組で両表に数値がある。両目録はHOSTS由来情報を共有しうるため、独立な生態学的再現ではない。

植物側はgesuiの990受理済み寄主キー中348に数値Nが対応し、chochoは1,677のWCVP寄主概念中253に数値が対応した。地域外の植物、名称の不一致、集約分類群、x（栄養条件に無差別）、NAを区別して記録した。対応率で全データを切り捨てず、感度診断に使う。

原本はTichý et al. (2023) の欧州統合EIV、Zenodo v2、CC BY 4.0。版を固定した。公開MD5 `3519d41639647dde8d80042fc98b2ef5` を検証し、SHA256は `b3fa7c3a6e9d356e52a45472549f807967bd0c3189e58e7e8a22e0389c29cc4e`。既存gesuiの624個の数値NUTRIと新原本は全件一致（最大絶対差0）。

原本v2には8,908分類群行、数値Nは7,195行ある。論文の要約にある7,193との差をメタデータ上の不一致として保存した。勝手な2行削除はしていない。上記624個の一致は保持される。

## 2. 指標と不確実性

蝶sについて、既知寄主のうち数値Nがある重複除去済み植物を等重みで平均する。

`HNS_s = sum(N_h over scored distinct hosts h) / number of scored distinct hosts`

`coverage_s = number of scored hosts / number of documented host concepts`

gesuiの未解決の寄主名28リンクは分母に残した。現流域の植物記録量で重みづけしない。現在の曝露・植物群集を使って種の性質を定義すると、下水による群集応答を調べる段階で循環が生じるためである。

平均、中央値、標準偏差、寄主内最小・最大、対応率、原出典を保存した。未数値の既知寄主を仮にN=1または9とした感度範囲も出力した。この範囲は95%信頼区間ではなく、まだ目録に載っていない寄主を含むものでもない。xは本来数値的な最適値を持たないので、この置換は最悪条件の感度確認に限る。

スプレッドシートの低側（<=3）、中間（3超7未満）、高側（>=7）は表示用の便宜的な帯。自然な3クラスを推定したわけではない。**中間を「関係なし」としない。** 回帰では連続量を主とし、非線形性も検討対象とする。

## 4. 平均値より先に確認すべき目録差

69組の両目録スコアがある蝶で、平均差の最大絶対値は1.35だった。Aglais urticaeはgesui8.20（2/2）に対しchocho7.90（2/4）。Lycaena disparはgesuiでは7.15（2/3）だが、chochoの凍結目録では寄主がRumex japonicusのみで欧州EIVに数値対応せず、スコアが付かない。

さらにAglais ioの今回のgesui抽出にはHumulus lupulusだけが残り、その1/1から7.90となる。主要寄主Urtica dioicaは一次研究で確認できるが、固定した目録抽出に含まれていない。**目録内対応率100%でも、生態学的な寄主知識が完全とは限らない。** 今回は代表種だけ都合よく手で足さず、文献証拠表に記載し、地域別主要寄主による別スコアを次の補強対象とする。

元GBIF303キーには非ACCEPTED13キーがあり、別名・歴史的分類概念を要注意列に残す。使用していない古い異名の重複は情報フラグにとどめる。実際に使用した寄主照合名が複数の蝶キーに割り当てられた例は0、全1,565辺の蝶科は照合元と一致した。現段階で種キーを独立した受理種数に読み替えない。

## 5. ユーザー案を文献に照らした調整

### 好栄養生育地・葉内N・成虫資源は異なる

好窒素性寄主があることと、窒素を増やせば幼虫が得をすることは同じではない。Aglais ioとA. urticaeでは施肥イラクサによる生存・成長の改善が報告されている。一方、Rumex acetosellaまたはPoa pratensisを用いた6チョウ目種の実験では施肥で幼虫生存が低下した。種・処理・温度・化学組成で応答が異なる。

シジミチョウのアリ随伴と葉内Nに関する研究もあり、幼虫の栄養戦略はEIV Nのみでは表現できない。とくに植物食からアリ資源へ移る種では、初期寄主のN値は生活史全体の栄養獲得を表さない。

成虫の吸水にはNa摂取・K排出などの機能が確認されており、寄主生育地のNとは別列が必要。本表の成虫証拠は整理の開始段階で、303キーのうち301は未整理、1は日本の実験からの別地域証拠、1は北米で報告された旧分類概念の転用保留。成虫資源利用の完全な種別分類は未完了であり、未整理を「吸水しない」としていない。

### 先行CNIと今回のHNSは同じ指標ではない

WallisDeVries & van Swaay (2017) はオランダの1990–2015年の蝶群集窒素指数（CNI）の上昇を報告した。ただし、その蝶の種別N値は蝶が多く記録される植物群落のEllenberg N最適値に基づく。今回の「既知寄主だけの平均」とは推定対象が異なる。HNSを既存CNIと呼ばず、将来それぞれ比較する。

### 河畔性は輸送経路の候補であり、曝露の証明ではない

河畔にいるだけでは下水のNが根・葉・蝶に届いたと断定できない。現行H7×期間は、放流口上下流の局所観測ではない。既知の放流口、流れ、浸水・地下水接続、土壌または葉内化学を別に確認し、湿潤な非下水対照と比べる必要がある。樹木食・移動性の種も無効果対照として先に固定しない。

## 6. 次の検定設計（今回未実行）

まず地域で実証された主要寄主・野外記録を統合し、種のHNS、寄主の水分・光要求、成虫のNa利用／有機資源利用、アリ依存、移動性を独立に定義する。形質完備な種だけに母集団を縮小しない。形質ごとに対応率を報告し、未対応種を残した観測・欠測モデルを比較する。

主要仮説は「下水の多い場所で全蝶が増える」ではなく「曝露と種のHNSの交互作用により記録組成が高HNS側へ変わるか」。成虫資源利用は別の交互作用として検証する。上下流の検証には実際に結合された水文的曝露を使い、H7出口の静的モデル水量を蝶個体の曝露濃度としない。

## 7. 再現と検証

数値表の再計算にはPython標準ライブラリのみを使用した。XLSX原本はXMLの保存済み数値を読み、改変・再計算していない。新規納品XLSXはartifact_toolで作成し、平均・対応率・感度限界等を式として保持。533行の平均・対応率の式結果がCSVと一致、式エラー検索は0件。13単体テストと別集計による平均再計算が通過した。独立の生態学的サンプルを追加したわけではない。

GitHubでは `analysis/host-nutrient-score-source-20261115` に公開原本取得用のワークフローのみ追加。実行43663192859の原本取得・MD5照合は成功。スコア計算・Excelはローカル実行で、mainやchochoには変更・マージしていない。

数値再現：
```bash
python -m unittest discover -s tests -v
python scripts/build_scores.py
python scripts/annotate_and_validate.py
```
ZIPは元のユーザー接続寄主資料を含む私用再現パッケージ。chochoの原寄主一覧を公開リポジトリへ転載しない。EIVの再利用にはTichý et al. (2023)およびZenodo DOIを引用する。
