# 2026-11-15：EPAs三時期の実測環境×EPT分類群×形質のFourth-corner型再解析

## 問い

河床の埋没度と、固着習性の少なさ／汚濁耐性型の相対的多さの関連は、**分類群の出現（incidence）構成の交代**なのか、記録個体数による相対優占の変化なのか。それとも原データの科/目や固定した形質名札が作る見かけの関連なのか。

元PR #83で2008/2013/2018の「個体数重み付きEPT clinger割合低下、PTV上昇」は既知。**すべて事後探索であって新しい独立検証・先験的登録ではない。**

## 実際の同一データの3行列（R/L/Q）

- **R（環境・地点）**：米国EPA NRSAの元UIDサイト：実測河川TN/TP、埋没度 `XEMBED`、物理環境5項目、川のサイズ・緯度経度・州・生態地域・季節・導電度。
- **L（地点×分類群）**：2008–09 BERWW、2013–14・2018–19 BERWの公式`TOTAL300`カウントを真正原本SHAから再構築した、UID×EPA元TAXA_ID表。EPT3目だけを選び、正のカウントのみ、同一UID×TAXA_IDを集約。
- **Q（分類群×形質）**：EPA原`TAXA_ID`・`TARGET_TAXON`・`ORDER`整合によって生態形質（HABIT=CN固着、PTV汚濁耐性、FFG=SCスクレイパー）を付与。複数機能コードは分数割当て、未確認をゼロ扱いしない。

元のEPA原本と source-only QAを既存PR81–83スクリプトで再構築、元m200の**2209 UID**／3時期のサイト及びEPA本来の形質カバー率80%以上を保持する。元PR83個体数CWMと厳密に一致しなければ停止。元の形質別サイト数：固着462/918/719、耐性440/851/674、スクレイパー454/892/701（2008/2013/2018）。

## 新しい独立した比較（完全に同一の観測サイト）

同じ標本内で**二つのCWM（群集加重形質平均）**を作り、係数を差し引く。

1. `CWM_count = Σ_taxon(N_i,s * trait_s) / Σ_taxon N_i,s` （計数個体数による相対優占を反映）
2. `CWM_incidence = Σ_taxon(1[observed] * trait_s) / N_scored_taxa` （分類群の記録出現だけ、同一UID内で出現した各分類群に等重み）
3. `D = CWM_count − CWM_incidence`（個体数重み付けでの差；純粋な種内適応や個体変化の指標ではない）

同じEPA source cohort・同じHUC8等重み、州・生態地域・河川環境と実測NPを調整し、主要説明変数`XEMBED`当たりの3種の回帰係数・HUC8クラスタ記述95%を検定する。TP/TNの係数も保持。**主要はclingerとPTV×3時期×count/incidence = 12検定**、BH-FDR 12補正を併記。スクレイパーは探索的負の対照で、非有意でも消さない。

## 環境–形質アラインメントの置換検証

同一地点の観測カウント・環境・分類群出現は動かさず、**EPT各目内で数値スコアが確定しているTAXA_ID間のみ形質ラベルを399回置換**。本当の個体記録・正式な元の分布を変えない。WLS Frisch–Waugh残差で算出したXEMBED条件付き係数を比較。

- 問うのは「**同じ目内で trait と分類群の対応が無作為なときよりXEMBED勾配が顕著か**」であり、完全なFourth-corner二側置換検定や進化・因果効果の検定ではない。
- 同一目の形質がほぼ同じ場合、ランダム化は実質無情報であり、その場合はその限界を報告。
- 目間の出現差、群集組成の空間自己相関、未測定土砂/水質交絡、分類群の共通系統は取り除けない。
- 元のposthocな結果からの発想なので、p値を確認的有意と呼ばない。

## 時期をまたいだ外挿検証

1期全体を留保して別の2期で学習する。ただし**ターゲット期に存在するHUC8は全て学習データから除去**。対象2形質×2 CWM×3期、元source n≥250/150 HUCとtrain ≥300/200 HUCを要件化。train-only OneHotEncoder+StandardScaler、Ridge α10、HUC8均等MSEと固定保持誤差ブートストラップ記述95%。比較は共通観測サイトの(B+NP) vs (B+NP+PHab)。

中心の反証条件：**個体数重み付きの正負は強いのに分類群出現等重みでは消える**場合、種の環境選別を強く主張せず、主に相対優占の偏りと表現する。両者が同方向かつ再現すれば、個体数構成だけでない分類群の構成選別と整合する。ただし両者は数学的に関係があり、独立した再現実験ではない。

## 元研究との統合境界

米国EPA: **河床・河川NPとEPTの機能形質の対応**。欧州PR #95/#96: **モデル下水関連地理Wと蝶幼虫の寄主植物の好窒素HNS記録組成**。米国と欧州では環境量、形質、地理粒度が異なる。両係数を一つのSEMに接合、下水由来Nとして解釈、実際の栄養フラックス・生産・送粉などの生態系サービスを推定してはいけない。
