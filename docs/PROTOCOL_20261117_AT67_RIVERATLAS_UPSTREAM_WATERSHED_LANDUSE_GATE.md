## Why this is necessary

The previous Austria67 2022 observed in-stream annual unfiltered P + original EEA benthic EQR + eligible 2022 UWWTD upstream reported annual N/P/Q signal remained predictive after local **1km circular** ESA WorldCover2021 crop, built, tree and grass fractions. That only describes scenery NEAR the water sampling station. The WWTP source indicators span an upstream river network of **up to 50km**; a 1km circle cannot control the wider upstream agro-urban landscape contributing nutrients. If true *upstream watershed* land cover removes the WWTP-reporting P/Q or N/Q predictive gain, then the prior apparent source signal is consistent with landscape confounding. If it survives, other habitat/morphology/reporting confounds remain and causal sewage effects are STILL unidentified.

## Candidate published *whole-upstream-basin* covariates

HydroATLAS RiverATLAS version1 (Linke et al 2019, CC BY 4.0; official https://www.hydrosheds.org/hydroatlas) shares original **HYRIV_ID** with HydroRIVERS, and includes **whole upstream contributing watershed** columns:
- \`crp_pc_use\` cropland percent upstream watershed, from EarthStat circa **2000** (NOT 2021 land cover)
- \`urb_pc_use\` urban extent upstream watershed, based on GHS Settlement Model circa **2016**
- \`for_pc_use\` forest extent upstream watershed, based on original RiverATLAS attribute source
- optional \`pop_ct_usu\` upstream population count, \`ppd_pk_uav\` upstream density/pressure only if official field meaning independently verified.
The suffix **use** denotes watershed UPSTREAM of river reach pour point, not the local catchment (*cse*). This is a useful watershed-scale anthropogenic baseline despite temporal mismatches. Official data catalogue and provenance:
- https://www.hydrosheds.org/hydroatlas
- https://doi.org/10.1038/s41597-019-0300-6
- source field descriptions in official RiverATLAS catalog https://data.hydrosheds.org/file/technical-documentation/RiverATLAS_Catalog_v10.pdf (do not assume variable scales without checking).

For source availability, a public ArcGIS service derived from RiverATLAS, item **8ee1b502377541f0ae45f3cf4842d0d8**, publishes a **geographically clipped** subset and filters \`DIS_AV_CMS>=1\`, so it is not the full official dataset. Test its ACTUAL source coverage of our 67 original Austrian native HYRIV_IDs with public ArcGIS REST metadata and exact ID query before using it: https://www.arcgis.com/home/item.html?id=8ee1b502377541f0ae45f3cf4842d0d8 . If this feature service does not cover AT station IDs, emit \`STOP_THIRD_PARTY_RIVERATLAS_AUSTRIA_SOURCE_NOT_COVERED\`; never falsely treat unavailable values as zeros and don't expand to alternative sites based on ecological results.
