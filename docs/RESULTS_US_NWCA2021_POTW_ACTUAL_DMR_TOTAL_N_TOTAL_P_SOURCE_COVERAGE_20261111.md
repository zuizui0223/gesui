# 下水と植物多様性：米国2021年の実際の排水監視記録を照合して、機構推定の上限を確認

**2026-11-11、SOURCE-ONLY全国監査・独立数値監査完了。** 研究の焦点は27州・240湿地で見つかった「下水処理施設への近さ × 標準化植物Shannon多様性」の面積加重**正の観測相関**を、2021年の実排水にどこまで結び付けられるかである。既に検証された2021年の**等地点重みでは負**（H_ALL β −0.12043、95%CI [−0.25058,+0.00971]）、**NWCA設計面積重みでは正**（H_ALL β +0.18062、95%CI [+0.01038,+0.35087]）という両方向の結果は保持した。正方向だけを選ばず、2021年実排水監視源の独立した条件を確かめる。

## 1. 下水の行政上の存在から、2021年の実際の監視報告へ

元の全国EPA NWCA2021の確率標本 **568湿地**（植物群集H_ALLと実測湿地TN/TPの同一SITE_ID+VISIT_NO）、ECHO NPDESの2026-11-08更新全国登録放流口源（原本ZIP SHA256 `f0d1310b1c07085c42527e2ede5cf97ab83d517d50548b7dadb7621a44aa6160`）。下水処理業種 **NAICS221320/SIC4952**、`LATLONG_TYPE=Permitted Feature`、許可日が2021年に存在した可能性のある登録放流口だけを採用。固定した568湿地のうち、そのような放流口**10km以内の128湿地、行政許可160件**は植物多様性の今回の近接/遠隔比較を見る前にSOURCE-ONLYとして選定した。対象地点は変更していない。

新たに公式のEPA ICIS-NPDES DMR実測報告から **FY2021** と **FY2022** の両ZIPを取得。米国の財政年度を暦年に読み替える誤りを防ぐため、**FY2021の2021年1〜9月、FY2022の2021年10〜12月**を`MONITORING_PERIOD_END_DATE`で厳密に抽出した。元のEPA FY2021 ZIP SHA256 `2a28acdd4e98cc8cfee7a4ee8bfcc71a6aa266477d7898599a3297d6482c2c10`、FY2022 ZIP SHA256 `2bf892143d6f95afa2b0246c8b6ce028b4bf107a2e2c665a06367c32dcc8bc0d`。両方は2026年公表時点での2021年の歴史的報告データであり、未報告の源まで完全に復元できるものではない。

## 2. 元の160近接NPDES許可に、2021年の監視報告はどの程度存在するか

| 2021年暦年の公式DMR報告条件 | 対応する近接湿地数（元の128湿地中） | 対応する源の数 | 対応州数 |
|---|---:|---:|---:|
| 同じ行政許可に何らかのDMR報告 | **121** | **149許可** | 32 |
| 行政許可に数値報告あり（対象化学種は不問） | 117 | 138許可 | 31 |
| **同じ許可でEXO外部放流口の数値報告あり** | **109** | **129許可** | 29 |
| **湿地近くの同じ登録放流口番号（EXO）の数値報告** | **104** | **149放流口feature** | 29 |
| 同じ近接放流口で**全窒素**（EPA code `00600`）の数値報告 | **31** | 34放流口feature | 17 |
| 同じ近接放流口で**全リン**（EPA code `00665`）の数値報告 | **66** | 83放流口feature | 25 |
| **同じ近接放流口featureで全窒素・全リンの両方** | **26** | **31放流口feature**（31許可） | 16 |

**重要な非同一性：** 「行政許可にDMR報告がある」場合でも、湿地に近い登録放流口とは**違う施設内放流口**からの報告かもしれないため、そのまま曝露と見なさない。`PERM_FEATURE_TYPE_CODE=EXO`（外部放流口）、`MONITORING_LOCATION_CODE`が`1/2/EG`（排出水）、有限の`DMR_VALUE_NMBR`、空欄`NODI_CODE`を用いた。NODI=no dischargeや欠測を実測ゼロに置き換えていない。TN/TPのほかの化学形（硝酸、アンモニア、オルトリン酸など）を同じ全窒素・全リンへ機械的に加算していない。今回、報告数値の大小は取得資料にあるが**種々の濃度・質量単位が混在するため一切合計せず、実測値の有無だけを解析**した。

## 3. 先に定めた機構検証ゲートの結果

| 原本から確認するもの | 事前に決めた最低数 | 実数 |
|---|---:|---:|
| 2021年の実測EXO排水報告を持つ行政許可 | 30 | **129** |
| そのような許可の10km以内にある元の湿地 | 60 | **109** |
| 対応する州 | 10 | **29** |
| **同じ近接放流口feature**の排水数値報告を確認できる湿地 | 40 | **104** |
| そのような独立feature | 20 | **149** |
| 全TN・全TPを両方報告する許可 | 15 | **31** |
| 全TN・全TPを両方報告する同一feature | 15 | **31** |
| **TN・TP双方の同一featureに対応する近接湿地** | **30** | **26（不足）** |
| そのような湿地を含む州 | 8 | **16** |

**結論：** 2021年の数値を伴う実排水監視が存在する下水源を全国で確認できた。広い「排水報告機会」ゲートはPASS。しかし、**TN/TPの双方を測定した特定の放流口と、湿地近接地点が十分に重なるか**という固定ゲートは**FAIL**。この26地点をさらに増やすために地理半径、化学形、行政施設全体を恣意的に追加してはならない。なお正しい数は**26地点**であり、個々の報告行や放流口数を調査地点数として水増ししない。

さらに重要な上限として、仮にすべての監視報告源が足りても**2021年の実排水が湿地の受水域に到達したという流下経路・流量・湿地での下水由来負荷の証明は一切ない**。10km以内の源は物理的な排水到達の必要十分条件ではない。源から湿地までのNHDPlusネットワーク接続と独立受水域の同定前に、植物Shannonへの下水効果のβやp値を新規推定しない。

## 4. 全球の下水肯定結果との位置づけ

既存の全球1,055港・42か国のモデル下水発生量とGBIFの植物記録件数β+0.3156、未希薄化植物記録種数β+0.2288という**正の観測相関は維持**する。しかし、50記録希薄化種数のWWp係数は小さく、Animalia/Fungi記録もWWpと正に対応している。これは**記録機会集中と真の植物群集多様性を区別する必要性**を示す。今回のNWCAは実際の植物調査区を使える点で進展したが、調査重みで符号が変わり、2021年の実排水監視源との源→受水域接続も未確認。**正の相関そのものは捨てず、まだ因果機構として一般化しない。**
