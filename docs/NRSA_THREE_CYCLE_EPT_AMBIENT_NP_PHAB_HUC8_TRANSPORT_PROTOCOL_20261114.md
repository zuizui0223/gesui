# Three original EPA NRSA cycles: frozen *before transfer results* cross-period, fully HUC8-disjoint EPT benchmark

**2026-11-14, exploratory macroecological predictive transport, not a wastewater causal study.** This third-stage hypothesis follows positively signed within-survey gradients in existing [PR #80](https://github.com/zuizui0223/gesui/pull/80) and the *failure of riverbed–periphyton Chla interaction to replicate in unshared HUC8* in [#79](https://github.com/zuizui0223/gesui/pull/79). Neither sign nor significance can be assumed to generalize. All source panels and primary model comparisons below are frozen BEFORE looking at their new transport MSEs.

The source field taxa account for >=95% original counted individuals in each included original UID. The missing taxon-order fraction remains unknown: source upper-bound EPT share calculated as EPT known + all unknown counted; test as a source-only sensitivity. Original [#80](https://github.com/zuizui0223/gesui/pull/80), source verification runs [#43563366026](https://github.com/zuizui0223/gesui/actions/runs/43563366026) and [#43563980256](https://github.com/zuizui0223/gesui/actions/runs/43563980256).
- **2013–14:** EPA original SiteInfo, WaterChem, PCHL, PBIO, PHab, true BERW wadeable original TOTAL300 EPT counted fraction, source-strict **1,116 native visit UIDs /706 HUC8/48 states**, original study [#79](https://github.com/zuizui0223/gesui/pull/79), [#43561313134](https://github.com/zuizui0223/gesui/actions/runs/43561313134).
- **2018–19:** EPA original SiteInfo, WaterChem, Chla, PHab, true BERW counted EPT fraction, **946 native visit UIDs /603 HUC8/47 states**, original source [#77](https://github.com/zuizui0223/gesui/pull/77), source/numeric independent [#43529245688](https://github.com/zuizui0223/gesui/actions/runs/43529245688).
- Each source is independently reconstructed **within one GitHub Actions job** from original EPA pinned source SHA, signed pre-outcome UID manifests, and original frozen quality flags. Row-level ephemeral files NEVER uploaded, only source group hashes and aggregate results. Assert the exact 586/437, 1116/706, 946/603 cohorts and source site/UID uniqueness before testing new transport predictions.

Numeric source total N and P are measured **ambient instream**, not POTW-origin sewage loads.

## Target variable, six *genuinely common* physical predictors
Primary response is original **EPT counted individual fraction** (0..1), NOT EPT species richness, aquatic adult emergence, dry mass or ecosystem service. Original 2008 lower-bound source unknown taxon fraction is bounded by an upper-case sensitivity.

Field predictors common across the 3 original original EPA cycles (do NOT substitute 2013 XGV for 2018 XGVEG):
- XEMBED (riverbed embeddedness, reported percent); XCDENMID (mid-channel canopy density, reported %); XPCAN (riparian canopy presence, source fraction); XFC_OHV (overhanging vegetation fraction); W1_HALL (human disturbance proximity index); original wetted width **log10(XWIDTH)**.
- Actual original total N and total P source-aware log10 **mg/L**: 2008 CHEMW NTL/PTL originally ug/L→/1000 each; 2013 NTL mg/L and PTL ug/L; 2018 NTL mg/L and PTL ug/L; all positive, source strict CHEM flags. Field conductivity log10 positive source microS/cm. 
- Baseline B: source lat, lon, native Strahler order (source 2008 category `1st`→1 through `7th`→7, `8th+` excluded due lack of exact order), source field sampling season sin/cos, original source state (uppercase normalized) and aggregated ecological region eco9, measured field log conductivity. **Survey year omitted from primary cross-era predictive model**, since an unseen target cycle cannot have a fitted categorical effect and linear year extrapolation can dominate environmental differences. Year/cycle still reported as source metadata.
- Models **B**, **B+NP**, **B+PHab**, **B+PHab+NP**: original measured TN/TP and six PHab variables. All models fitted and compared, no posthoc adding/removing predictors to improve a favorable result.
- Fit Ridge alpha=10 fixed, *train only* mean/sd standardization, one-hot state and eco9 learned **only on training cycles**, unknown test categories all zero, stable input columns. **Train catchment-equal weights** (one HUC8 has same total fit weight as another), normalized to mean 1, in every model. Secondary equal-visit fit allowed as precommitted sensitivity, never selected based on output signs.

## Primary external validation: three leave-one-cycle-out tests with zero shared HUC8 in training
For each target original cycle (2008, 2013, 2018), fit models on the other TWO cycles after **removing ALL original training visits from any HUC8 appearing in the entire held-out target cycle** (not merely heldout visits). No test outcome used to select training, tune alpha or scale features. Evaluation includes **all original eligible target-cycle sites**, even at HUC8s that appeared in other surveys but were completely excluded from training. Report counts of target original UID visits, target distinct HUC8, train remaining visits/HUC8 and how many training visits/catchments were removed.

**Primary performance estimand: equal weight per held-out HUC8:** mean of within-HUC8 mean squared errors; each catchment counts once. Secondary UID-visit-weighted MSE and source fraction MAE. Report MSE of B, B+NP, B+PHab, B+PHab+NP, and always an intercept-only catchment-weighted **training mean** reference, plus heldout-cycle centered descriptive R². Report **NP added AFTER PHab** and **PHab added AFTER NP** performance improvements; negative predictive changes are meaningful. For each target cycle bootstrap 2,000 unique HUC8 test blocks of **fixed OOS squared errors** (not refits) to produce descriptive 95% on improvements, and whether it includes zero.

Predeclared gate per target: train >=400 visit UIDs and >=200 HUC8, target >=300 UIDs and >=150 HUC8, all four source columns valid and no duplicate native within-cycle UID. If a cycle fails, mark gate FAIL without weakening thresholds or borrowing 2013/2018 periphyton observations as substitutes.

As secondary stringent transfer, report performance on target-cycle **HUC8s never present in either other original cycle** with >=150 target visits and >=100 original HUC8, otherwise mark insufficient. Main transfer already excludes any overlapping HUC8 from *training*, and is not a pseudoreplication leak. Within-cycle 5fold HUC8-grouped holdout on each fixed original panel is an **additional contextual benchmark**, not a replacement for external period transfer.

### Before claiming a multi-era mechanism
- If nutrients improve inside cycles but hurt other-cycle HUC8 transport, say **site-specific nutrient co-gradient does not transport**, not that measured nutrients have no ecological effects.
- A positive or negative predictor gain does not establish a direction or mechanism of wastewater pollution. No source-matched historical effluent N/P overcame precommitted gates in [PR #74](https://github.com/zuizui0223/gesui/pull/74); no periphyton in 2008, and neither benthic EPT counted share nor AFDM is realized pollination/water-purification or adult insect emergence flux.
- Repeated HUC8 across source cycles is not independent river geography; report union distinct HUC8 and pairwise shared groups. Never report sum of source basin counts as independent.
- Preserve **all** positives, negatives, nulls, method changes, source missingness, external-fit degradation and cross-survey domain shifts. No eBird. No main branch merge.


## Pre-prediction original source ID normalization repair (never saw any transport result)

[Initial original-source-only Action #43566251241](https://github.com/zuizui0223/gesui/actions/runs/43566251241) detected **authentic NRSA2008/09 HUC8 CSV strings stored with 7 digits when their leading geographic zero was omitted**, e.g. source string `2040205` for an eight-character watershed identifier. This is a source text encoding/identity issue, *not* an ecological null or basis to change heldout samples. Before any external predictive fitting, the source harmonizer was fixed to accept only original decimal **7 or 8 digit HUC8 strings**, restore exactly one leading zero for original 7-digit strings and preserve an auditable per-cycle count of repairs. Any non-decimal, shorter or longer code, or any collapse of formerly distinct original basin labels, is a hard ERROR. A correctly normalized original HUC8 is used consistently in training exclusion, target grouping, source overlap and fixed heldout HUC8 folds. **No new geographic coordinates or nearest watershed inferred.**


### Second pre-prediction source identity QA: EPA 2013 H-prefixed HUC8

[Source-only rerun #43566381734](https://github.com/zuizui0223/gesui/actions/runs/43566381734) disclosed the official 2013 NRSA original source **H-prefixed eight-digit basin code** (e.g. `H10270102`), in contrast to the unprefixed or leading-zero-omitted 2008 HUC8. This is a *literal source identifier prefix*, not an extra watershed digit. Before seeing any new cycle-transport coefficient or prediction, the fixed harmonizer was extended to accept ONLY exact `H` followed by eight ASCII digits, or raw seven or eight ASCII digits. It removes the `H` and restores a missing leading zero if necessary, then tests that canonicalized identifier counts remain unchanged (no originally different HUC8 strings collapsed). Prefix and zero restoration counts and source HUC8 set hashes are retained separately for all 3 periods. All other invalid geographic strings stop the job; never use proximity to guess catchment membership.
