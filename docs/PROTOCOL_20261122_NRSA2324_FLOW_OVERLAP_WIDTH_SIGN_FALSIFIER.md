# Source-fixed common hydrological support falsifier of method-specific width sign reversal (2026-11-22)

The previous [9-region holdout observed-width study](https://github.com/zuizui0223/gesui/actions/runs/45016047883) showed **opposite signed observational adjusted width coefficients**: BERW MMI +0.305 / EPT +0.218, BETB MMI -0.442 / EPT -0.376, with regional transport positive for BETB but uncertain for BERW. **These contrasts do NOT identify an ecological threshold** because BERW and BETB were sampled from very different river-size distributions, and protocol defines a different survey context. This validation is an explicitly **posthoc adversarial test**, NOT a confirmatory replication and not sewage-dependent.

## Before looking at subset biological outcomes
- Freeze original SiteInfo and PhysicalHabitat sources and source-only NHDPlus `MEAN_FLOW` (modeled cfs), `WSAREASQKM` (km²), original `FLOW_SIZE` size class and original field `XWIDTH` width values, exact UID/SITE_ID/VISIT_NO/DATE_COL.
- Original EPA survey [design documentation](https://www.epa.gov/system/files/documents/2025-08/nrsa-2023-24-survey-design-documentation-20220209_0.pdf) defines `RV` as nominal modeled mean annual flow >100 cfs, though the source may include exceptions and design-specific values. Do not infer field-measured discharge or depth from NHD-modeled flow.
- Prespecified subset P1: records originally labelled **`FLOW_SIZE == RV`**, without outcome-based exclusions. Keep BERW/WADEABLE and BETB/BOATABLE separate.
- Prespecified subset P2: P1 records whose source `log10(MEAN_FLOW)` falls in the **intersection of each original survey method's 5th–95th percentile range within P1**. Freeze the intersection endpoints in source-only JSON, then use unchanged numeric cutoffs for all outcome analyses.
- Prespecified subset P3: P2 additionally restricted to the **intersection of the two methods' source 5th–95th percentile `log10(XWIDTH)` ranges**. This strongest overlap subset is reported even if unfit for ecological prediction.
- Source GO per cohort: >=100 valid field visits and >=70 independent HUC8 (P1); >=80 field visits and >=50 independent HUC8 (P2); >=60 visits and >=40 HUC8 (P3). If fails, output STOP and no coefficients. For exact complete-case numeric cohort, same criteria apply. Don't change cutoffs to rescue a sign or significance.

## One unchanged ecological model
For each source subset, original full same-visit QA and HUC8-grouping. Same four outcomes (BERW MMI/EPT, BETB MMI/EPT), measured original TN/TP, original midchannel vs bank canopy definitions, original physical width, log modeled flow, log upstream area, urban label, latitude, longitude, stream order, state, eco9 and season. Compare one no-width and one width-addition Ridge10 model, identical rows and deterministic HUC8-disjoint folds, 2,000 whole-HUC8 bootstrap of heldout MSE gain. Report actual numeric sample and descriptive standardized log-width slope with HUC8-cluster 95%; small cohorts may produce unstable OLS with many regional categories, which should be reported as analysis failure rather than changes to covariates.

The ecological test targets **whether the sign reversal remains within source-defined overlapping river hydrology, not whether width can be made significant**. A negative BETB slope could reflect broad, shallow, dredged or altered channels *or simply protocol selection and residual confounding*. A positive BERW slope could reflect more available habitat *or sampling frame*. None of these mechanisms is demonstrated by observational width. No wastewater source delivery, macro-multitrophic transfer or ecological service effect is inferred.
