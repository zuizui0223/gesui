# 2021 ESA WorldCover × DE/AT 2022 Lycaenidae photo reporting: independent land-cover falsification

**Date 2026-11-08. POSTHOC**, because original 2022 Lycaenidae photo association and heldout positive P source improvement are already known; cannot claim preregistered confirmation. This is a fixed, independent environmental source update before WorldCover class fractions are obtained, and before a new outcome model is computed.

## Why
The verified 2022 German/Austrian original 53-country×1° source-positive regions yield 44 eligible Lycaenidae/Pieridae/Papilionidae photographic reporting regions. Existing posthoc country/latitude/longitude/2021 Plantae photo effort adjusted block-heldout 2022 EEA reported annual P source-MSE improvement was **17.82%**, N +6.75%, WWTP source count +2.10%, but source reported P and N covary, land-use/country border confounding unresolved. Source P is **not** independently measured substrate P and photographs **are not** true butterfly abundance, puddling or larval success. This update asks whether the positive *recording geography prediction* persists after independently measured 2021 land cover and country-specific terrestrial land area are included.

## Stage 1 independent WorldCover raster, NO butterfly outcomes

Use **ESA WorldCover 2021 v200 original categorical Cloud Optimized GeoTIFFs** hosted on the publicly documented, anonymous AWS open bucket `https://esa-worldcover.s3.eu-central-1.amazonaws.com/v200/2021/map/ESA_WorldCover_10m_2021_v200_<3degree_TILE>_Map.tif`. Original map class 40 cropland, 50 built-up, 10 tree, 30 grassland, 80 open water, 0 NoData (original product classification), *not WMS RGB imagery*. The WorldCover producer explicitly notes WMS image tiles are unsuitable for categorical quantitative analysis; use COG native class values. Source credit: © ESA WorldCover project 2021 / Contains modified Copernicus Sentinel data 2021 processed by ESA WorldCover consortium (doi:10.5281/zenodo.7254221).

- Original 53 geographic source-positive WGS84 1° regions from previously committed `EEA2022_DE_AT_ORIGINAL_FW_OUTFALLS_IN_ONE_DEGREE_SOURCE_TILES.csv`, SHA-pinned to original 1,156 WWTP both measured N/P unique FW outfalls. Do not choose regions based on WorldCover or butterfly responses.
- Source polygon mask: original **Natural Earth 1:50m admin-0 country boundaries** from the original [Natural Earth project repository](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_50m_admin_0_countries.geojson), countries identified by verified ISO_A2 DE/AT. This separates Germany/Austria inside 1° border cells, consistent with official iNaturalist original country-place filters. Download and SHA-pin exact polygon source, no country border approximated by cell bbox.
- For each country×1° cell, choose appropriate original **3° WorldCover COG** solely from preexisting cell bbox (floor(lat/3)*3, floor(lon/3)*3). Use Rasterio HTTP-range window reads from COG resampled with **nearest-neighbor** categorical classes, **512×512** regularly spaced within original 1° cell (around ~150–400m pixel spacing), not a full 10m census. All 53 cells require a valid original raster COG read; record full original COG URL and TIFF header/raster shape/CRS and per-cell class counts and source receipts. Approximate within-country land area via pixel-center WGS84 cos(latitude) weight and Natural Earth 50m mask.
- Fractions computed with cos(lat) weighted centers among nonwater `Map != 0` and `Map != 80` **inside matched country**. Exposures: built-up/terrestrial land (`Map==50`), cropland/land (`Map==40`), tree cover/land (`Map==10`), grassland/land (`Map==30`), plus country land valid fraction and country land km². No-data fraction separately reported. `Open water` is not land even though it has code 80.
- **Secondary resolution-sensitivity:** 256×256 nearest neighbor same exact original source; record absolute difference of class fractions versus 512, no tuning. For any 1° cell with original country terrestrial land fraction below **0.05** (5% of cell) or valid terrestrial country pixels below **512** at 512×512, flag as *insufficient land coverage* (exclude only from prospective landcover-adjusted comparison, retain original 44-cell outcome cohort unchanged). Require ≥**36** of the 44 originally 2022 photo-eligible cells with valid 2021 WorldCover, DE ≥**20**/AT ≥**10** and ≥**12** 2° blocks, and valid-cell max built/crop fraction 512 vs256 difference ≤**0.10** for ≥**90%** of those cells. Missing COG/API source ≠ 0 built-up.
- Save original all-53 country-locked landcover class counts and full source/QC files to new branch **BEFORE** merging any 2022 butterfly photo responses; no biological outcome queried. Original 2022 response files already exist on branch, so chronological provenance labels must explicitly say landcover test developed posthoc after inspecting response.

## Stage 2 fixed geography-heldout comparison (only if Stage1 source coverage gate passes)

- Exact original 44 eligible photo-reporting cells and 22 country×2° geographic group identifiers remain fixed as the *primary target*, with a separate sensitivity restricted to QC-valid WorldCover cells. Do not retroactively recode the initial +17.82% result or claim a new independent outcome.
- Baseline land-cover model M0: intercept, country indicator, training-only standardized 2021 Plantae public photo reporting effort, training-only z(latitude), z(longitude), z(ESA WorldCover country land built fraction), z(cropland fraction), z(log1p valid country land area km²). Compare M1 = identical M0 + **training-only country-centered/scaled log1p 2022 reported P effluent mass**; separately M1(N) and M1(facility count). Fixed ordinary least squares and **leave-one whole original 2° country+region spatial block out**; no hyperparameter tuning, no filtering based on observed Lycaenidae signal.
- Country-specific heldout-MSE and MAE, source incremental MSE improvement, baseline and source predictions per cell, training full-rank diagnostics. Additionally report original 44-cell no-landcover heldout +17.82% P for clear sample consistency only (not imply identical 44 if landcover missing).
- Primary *falsification*: if adding P provides no consistent improvement after built/crop/land-area adjustment, describe earlier P prediction as compatible with land-use/settlement confounding. If positive, treat only as geographically predictive *photo-reporting* information, not sewage-specific effects. Avoid claims about a mechanism until direct water, sodium, organic protein, host-quality, ant, and standardized butterfly observer counts are measured.
