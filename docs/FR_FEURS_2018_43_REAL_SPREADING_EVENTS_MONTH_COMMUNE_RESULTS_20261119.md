# 2026-11-19｜Feurs 2018：汚泥の実施用43台帳行を自治体×月に匿名化した独立SOURCE監査

## 結論

**水と陸の両方へ出口を持つ同じFeurs下水処理場のうち、陸側は「候補自治体」から「実際の施用時期・面積・湿重量」に進んだ。** 2018年の[Feurs汚泥実施用報告書（公式DREAL PDF）](https://www.auvergne-rhone-alpes.developpement-durable.gouv.fr/IMG/pdf/10_step_feurs_cas_par-cas_annexe9_epandage_2018bilan.pdf)、印刷p.15のTableau 6とp.16–17のTableau 7に基づく。

- **43台帳行**を個人・農家名・圃場ID・正確な日付を除いて再入力した。台帳行は**43独立圃場でも43独立処理場でもない**。
- 8 INSEE自治体、**20自治体×施用月**の組み合わせ（2018年の計6施用月）。
- Tableau 7の43行を合計すると**実施用面積161.53 ha、湿重量1,918 t**。元の年間合計と両方一致。
- Tableau 7から集計した**月別湿重量**は、別表Tableau 6の独立月別値と6か月すべて完全一致。
- よって「自治体×月×実際の湿重量」の**機会データ**として再現可能になったが、匿名化抽出には実圃場座標はなく、同じ自治体内のどのH7に属するかは未特定。N/Pの月別実測ロット組成を結合していないため、**月別のN/P施用量ではない**。

## 次段マクロ仕様（他処理場への横展開）

1. **処理場STEU×年**を共通起点とし、河川排水口は位置座標＋同年の実測TN/TP年間負荷、土壌出口は各実施用イベントの圃場位置・日時・量で別々に記録する。
2. 期間（月）を保存し、陸側の湿重量・乾物・全N・元素Pを区別する。P₂O₅を元素Pと同じ数値で結合しない。上流/下流と他の排出源・農業栄養源を負の対照に使う。
3. 原流域H6/H7に**正しい地理**で接続できたもののみ独立地域として数え、自治体の一部がH7に重なっただけでそのH7が施用曝露されたと扱わない。
4. 元のSOURCEゲートで定めた独立親H6≥10、実施用支持H7≥20、実施用自治体≥30は変更しない。真の未施用対照がない場合は処理対非処理の効果推定をSTOP。
5. 初めて十分なsourceがそろった後に、水域EQRと陸域植物NUTRI/蝶HNSの別々の地域外予測・交互作用を行う。生物間の移送には個体の摂食/同位体等を別途必要とする。

**判定：実施用の自治体×月SOURCE opportunity = GO（Feurs 1処理場のみ）；水・陸同年N/P質量ペア = STOP；生物応答経路と因果効果 = STOP。**

このSOURCE監査は既存の14 H7候補／6 H6の曝露確証を増やす結果ではない。main・原稿PR #124は変更しない。
